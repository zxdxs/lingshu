> **本站內容僅供在有帶教資格的執業中醫師指導下使用；不得代替就診，不得據以自行診斷、處方或用藥。**

> 只能當作隨師學習時的對讀材料；自行照書判斷或施治，可能造成傷害。內容未經臨床驗證。

把《黃帝內經·靈樞》八十一篇整理成可查、可練、且**知道自己哪裡不可靠**的自學材料。

底本：四部叢刊初編景明嘉靖趙府居敬堂刊本《黃帝素問靈樞經》（Kanripo `KR3e0002` 數位轉錄）。
見證本：《太素》、《類經》。

---

## 範圍

**本專案只做《靈樞》八十一篇。** 素問、難經、後世醫家，只在「對照」時引用，不納入主體。
凡文件中標明『不在靈樞』者，是提醒邊界，不是要擴張範圍。

## ⚠ 先讀這個

本專案的**能力邊界、已知錯誤、未驗證項目**，集中在：

- **`docs/42_能力邊界與問題標注.md`** — 34 條，含 6 條『AI 無能為力』
- **`data/能力邊界.csv`** — 同內容，可過濾

最重要的一條：**本專案所有臨床主張皆未經驗證，不可據以施治。** 另：底本為數位轉錄本，作者未見任何一頁原書影印。

## 檔案結構

```
底本/       L0 原文、經文、正規化、音釋、異體字表、素問經文（對照用）
data/       題庫、模組、表格、校勘記錄、能力邊界、發布資訊（站名／授權／聯絡）
docs/       159 份說明文件
scripts/    產線腳本（解析、抽取、生成、校準、匯出）
export/     Anki 牌組、全題表、實體索引（可直接用）
vendor/     見證本與來源（SBCK、太素、類經、素問）
```

### 產線順序

```
build_base_text.py        底本解析（含音釋剝離、補頁）
  → apply_punctuation.py  句讀轉移
  → build_module_*.py     各模組
  → build_zhujia.py       類經注解析
  → generate_items.py     題目生成
  → link_zhujia.py        註家配對
  → calibrate_items.py    先驗校準
```

`link_zhujia.py` 是最後寫入者，改動 `generate_items.py` 的輸出結構時須同步。

## 三條原則

1. **L0 原文絕不由模型生成**，每條都要能回溯到原文 span。
2. **不編造**：找不到依據時，寫「找不到」，不補一個看起來合理的。
3. **能力邊界寫在成品裡**，不寫在心裡。
