## 一、總結論（先講結論）

**這份 docx 不能直接當作蒸餾底本。** 它看起來『81 篇齊全』，但實際上是 **兩份不同來源的數位文本拼接而成**，並且在中段發生錯位，導致：

- **缺 2 篇**真正的《靈樞》篇章
- **混入 1 篇《素問》**文章，卻標為《靈樞》篇
- **重複收錄 1 篇**（同文兩次）
- **7 處篇序錯位**
- **至少 1 篇正文被刪去約半**（《病傳》缺 370 字）

若直接餵進蒸餾管線，會產生一個『看起來很完整、實際有結構性缺陷』的學習系統——這是自學訓練最危險的失敗模式：學習者無法察覺自己背的是錯的篇序，也永遠學不到那缺失的兩篇。

## 二、證據鏈

### 發現 1：文本由兩份來源拼接，「於／于」用字斷層即接縫

統計每章的「於」與「于」出現次數後，出現一條**極其乾淨的分界線**：

| 章節範圍 | 用字 | 判讀 |
|---|---|---|
| 第 1–43 位 | 一律用「於」，無「于」 | 來源 A（繁體轉錄，保留「於」） |
| 第 44–81 位 | 一律用「于」，無「於」 | 來源 B（簡轉繁或另一套轉錄，將「於」作「于」） |
| 少數例外（如第 77 位『九宮八風』於 7／于 11） | 混用 | 拼接處附近 |

其他佐證來源不同的痕跡：

- **異體字不同**：來源 A 作「滎」（滎穴），來源 B 作「榮」。
- **校勘符號不同**：來源 B 出現「〔岐伯曰〕」這類**方括號校補符號**，來源 A 完全沒有。
- **虛詞不同**：來源 A 作「是謂」，來源 B 作「是為」。

### 發現 2：拼接處正是第 43／44 位的重複篇章

第 43 位與第 44 位**同為『順氣一日分為四時』**。以去標點正規化後比對：

- 相似度 **93.4%**，長度 582 vs 585 字
- 差異僅在：`違天之時不可與期` ↔ `順者為工逆者為麤`（實質異文）、`滎`↔`榮`、`謂`↔`為`、`〔〕`符號、「于」字

**這不是兩篇，是同一篇的兩個版本。** 兩份來源在此篇重疊，拼接者未察覺，於是同一篇被收錄兩次並各自編了號。

### 發現 3：缺 2 篇、誤收 1 篇《素問》

對照史崧本目錄後：

| 狀態 | 篇名 | 說明 |
|---|---|---|
| **缺失** | 五癃津液別第三十六 | 全文 0 次命中『五癃津液別』「津液別」 |
| **缺失** | 五閱五使第三十七 | 全文 0 次命中『五閱五使』「五閱」 |
| **誤收** | 血氣形志（docx 標為第 39 位） | 內容為**《素問·血氣形志篇第二十四》**，非《靈樞》篇目 |

《素問·血氣形志》誤入的內容，開頭為「夫人之常數，太陽常多血少氣，少陽常少血多氣……」——與《素問》該篇逐字相同。它甚至與《靈樞》第 78 篇《九鍼論》有 17 個共享 12-gram，屬內容近親，因此錯誤極難靠肉眼發現。

### 發現 4：篇序錯位 7 處

| docx 位置 | docx 篇名 | 應為 |
|---|---|---|
| 36 | 血絡論 | 第 39 篇 |
| 37 | 陰陽清濁 | 第 40 篇 |
| 39 | 血氣形志 | 非《靈樞》篇目 |
| 40 | 陰陽繫日月 | 第 41 篇 |
| 41 | 病傳 | 第 42 篇 |
| 42 | 淫邪發夢 | 第 43 篇 |
| 43 | 順氣一日分為四時 | 第 44 篇 |

也就是說：**1–35 位與 45–81 位篇序正確**（共 74 篇），錯位集中在中段 36–44 位這個拼接縫隙周圍。

### 發現 5：章題是現代編者後加的，用字與正文不一致

- 正文用「**鍼**」270 次，「針」僅 19 次
- 但**所有章題都用「針」**（例：章題作『九針十二原第一』，正文作「九鍼」）

結論：章題為後人用現代通行字改寫，**不可視為原文的一部分**；蒸餾時必須把「章題層」與「原文層」分開標記，否則會把現代用字當成經典原文背誦。

### 發現 6：docx 的『大量重文』是假象——換底本後即消失

> **本節為更正。** 先前對 docx 做 12-gram 掃描，得到『2,124 個跨章共享片段、7 個重複群』。改用四部叢刊本重掃後，同一方法只得到 **31 個共享 12-gram、9 對篇章、無任何聚類**。**原本的『大量重文』絕大部分是壞底本造成的假象。**

| 指標 | docx（舊） | SBCK（權威本） |
|---|---:|---:|
| 相異 12-gram | 60,997 | 63,412 |
| 跨章共享 12-gram | **2,124** | **31** |
| 重疊篇對 | 25 | 9 |
| ≥15 的聚類 | 7 群、21 章 | **0 群** |

權威本中重疊最強的前 6 對（全部是零星短語，無大段平行文）：

| 共享 12-gram | 篇章對 | 性質 |
|---|---|---|
| 13 | 腸胃第三十一 ↔ 平人絕穀第三十二 | 腸胃容積數字重出（同一組數據） |
| 7 | 九鍼十二原第一 ↔ 小鍼解第三 | **「經—解」關係**：小針解引經文短語作解 |
| 3 | 九鍼十二原第一 ↔ 九鍼論第七十八 | 九針形制語重出 |
| 3 | 論勇第五十 ↔ 五味論第六十三 | 套語 |
| 3 | 行鍼第六十七 ↔ 官能第七十三 | 套語 |
| 1 | 邪氣藏府病形 ↔ 官能 | 單一短語 |

**docx 的重複從何而來？** 已查證兩例：
- docx《寒熱病》比權威本多出約 500 字，而其多出的內容正是《終始》的段落（「必先調其左右，去其血脈」一語在權威本中**只見於《終始》**，不見於《寒熱病》）。
- docx《九鍼十二原》含有《小針解》的解文（「言邪氣之中人也高」等語在權威本中**只見於《小針解》**）。

→ 舊底本在彙編時把甲篇內容複製進了乙篇。

**設計意義（修正後）**：《靈樞》本身的逐字重複極少，「去重」不是蒸餾的主要價值。真正有價值的是：**模組化重排**（依學習依賴關係而非原篇序）、**分層**（原文／註／白話）、以及**「經—解」對照教學**（《九鍼十二原》與《小針解》應成對讀，先經後解）。

### 發現 7：分段品質尚可，但有一章完全未分段

- 1,277 個正文段落，中位長度 40 字
- **63%（804／1,277）段落以人物名開頭**，即對話輪換處 → 段落邊界大致等於問答輪，**可直接作為卡片切分單位**
- 反例：**《小針解第三》全章僅 1 段、1,165 字**，完全未分段，需人工重建結構
- 僅 15 個段落內部含 ≥2 輪對話（切分不足）

### 發現 8：《病傳》被刪去近半——正文本身有缺漏

這是比篇目錯亂更嚴重的問題。對照史崧本卷十三，《病傳第四十二》開頭有一大段對話：

> 黃帝曰：余受九針于夫子，而私覽于諸方，或有導引行氣、喬摩炙熨、刺炳飲藥之一者，可獨守耶？將盡行之乎？……（中略）……岐伯曰：要乎哉問道。昭平其如且醒，窘乎其如夜瞑。……黃帝曰：何謂且醒？岐伯曰：明於陰陽，如惑之解，如醉之醒。黃帝曰：何謂夜瞑？岐伯曰：瘏乎其無聲，漠乎其無形。折毛發理，正氣橫傾，淫邪泮衍，血脈傳溜，大氣入藏，腹痛下淫，可以致死，不可以致生。

**docx 的《病傳》直接從『黃帝曰：大氣入藏奈何？』開始**，上面這整段約 370 字全部不存在。逐詞查證：

| 檢索詞 | docx 命中 |
|---|---|
| 余受九針 | 0 |
| 守一勿失 | 0 |
| 昭平其如且醒 | 0 |
| 如惑之解 | 0 |
| 血脈傳溜 | 0 |
| 折毛發理 | 0 |
| 正氣橫傾 | 0 |

這些詞在全書 64,718 漢字中**一次都沒有出現**，也排除了『被挪到別篇』的可能（已檢查全 81 篇，僅《官能》《上膈》出現「導引」「行氣」，屬不同文脈）。

**影響**：《病傳》是《靈樞》討論疾病傳變規律與「守一」思想的核心篇章。被刪掉的正是『何謂且醒／何謂夜瞑』這組著名對答，以及『導引行氣、喬摩炙熨、刺炳飲藥』這份早期治療手段清單——對自學者而言是觀念性損失，不只是字數損失。

### 發現 8b：《本輸》缺「手太陽小腸」整段——刪節不是孤例

同樣以史崧本卷一對照，權威本《本輸第二》在「三焦」與「大腸」之間有一整段「手太陽小腸」五輸：

> 手太陽小腸者，上合于太陽，出于少澤……溜于前谷……注于後谿……過于腕骨……行于陽谷……入于小海……爲合。手太陽經也。

**docx《本輸》直接從「三焦」跳到「大腸」，整段不存在。** 逐詞查證：

| 檢索詞 | 全書命中 | 說明 |
|---|---|---|
| 前谷 | 0 | 小腸滎穴 |
| 後谿 | 0 | 小腸輸穴 |
| 手太陽經 | 0 | 該段結句 |
| 少澤／陽谷／小海 | 各 1 | 僅見於《根結第五》，非《本輸》文脈 |
| 委陽、三焦下腧 | 0（「三焦下腧」） | 三焦下腧整段亦缺 |

此外，權威本《本輸》篇末的「轉筋者，立而取之，可令遂已。痿厥者，張而刺之，可令立快也」——「可令遂已」「立快」在全書**各 0 次**，同樣缺失。

**結論**：**刪節是系統性的，不是《病傳》的單一意外。** 這使『修補底本』的成本大幅上升，因為缺漏無法用肉眼掃描發現——只有逐句對校才會暴露。此發現直接影響第四部分的底本決策。

### 發現 9：註釋層幾乎是空的

全書只有 **4 處**編輯加註（1 處「註：」＋3 處「按：」）：

1. 第 2 位《本輸》：『註：此段原文實述手厥陰心包經之穴，古人以心包代心受邪。』
2. 第 21 位《寒熱病》：『按：天容今屬手太陽。』
3. 第 28 位《口問》：『按：此段與前文重複，歷代注家多認為係傳抄衍文。』
4. 第 34 位《五亂》：『接（按：或作『按』）手以呼』

**這代表：這份 docx 幾乎是純原文，不含可供自學者跨越古漢語障礙的注釋層。** 而第 2、3 處按語恰好證明加註者已察覺「重文」與『歸經爭議』——但只處理了 4 處，其餘 2,100 餘個共享片段全未處理。

## 四、對蒸餾專案的三個選項

**選項 A：換底本（建議）**
以史崧本或四部叢刊本為唯一權威底本重新取得全文，docx 僅作比對用。優點是從根上解決篇目、用字、忠實度問題；缺點是需要一次性取得可靠全文。

**選項 B：修補底本**
以現有 docx 為主，補入缺失 2 篇、刪除誤收《素問》篇與重複篇、重編篇序、統一用字，並建立『改動清單』。優點是不必重找來源；缺點是改動本身需再校驗，且無法排除其他未被發現的異文。

**選項 C：雙底本對校**
保留現有 docx，另引一套獨立全文，逐篇做 diff，凡不一致處皆標為「待校」。優點是能同時交出「異文表」這項高價值副產品（古典學習的核心訓練素材之一）；缺點是成本最高。

> 無論選哪一項，**都必須先產出一份『權威底本 + 逐篇校勘紀錄』**，否則後續的卡片、圖譜、題庫都建在流沙上。
