# 《靈樞》蒸餾方法論
### 為中醫自學訓練而設計

---

## 序：蒸餾不是『翻譯加出題』

多數人做古籍自學材料的直覺是：把文言翻成白話，再把條文挖空做成填空題。這個做法會產出一種**看起來很完整、實際上有結構性缺陷**的系統。理由有三：

1. **文獻學層的錯誤會被永久化。** 使用者無從察覺自己背的篇序是錯的、背的句子是被刪節的。本專案已證實現有底本存在此類問題（見下文第四部分）。
2. **知識工程層的錯誤會製造假連結。** 一句『某穴主治某病』若來自後世註家的推衍，卻被當成經文呈現，學習者建立的是錯的知識圖譜。
3. **學習科學層的錯誤會製造「假懂」。** 讀得順 ≠ 記得住 ≠ 用得上。看得懂白話翻譯產生的流暢性錯覺，在文言材料上比白話材料嚴重得多。

因此本方法論的基本架構是**三層對齊**：

| 層 | 要回答的問題 | 主要方法 | 失敗的後果 |
|---|---|---|---|
| 文獻學層 | 這字是不是原文？ | 版本校勘、異文、字形規範 | 教錯字、教錯句讀，錯誤永久化 |
| 知識工程層 | 這句在講哪個實體、什麼關係？ | 實體抽取、關係抽取、本體、分層 | 知識圖譜錯誤，題目張冠李戴 |
| 學習科學層 | 大腦能否形成可提取、可遷移的表徵？ | 提取練習、間隔重複、交錯、雙編碼、負荷控制 | 記住碎片、誤以為懂、無法遷移 |

### 三條不可協商的紀律

1. **原文層（L0）永不由生成式模型產生。**
2. **一切衍生材料必須逐 span 可回溯到原文。** 做不到就不得入庫。
3. **可信度分層寫進資料結構，而不是寫在 UI 文案裡。** 『這是原文』『這是後人註』『這是現代解釋』必須是資料欄位。

## 第一部分：傳統研讀方法論——歷史上真正有效的做法

蒸餾《靈樞》不是新問題。古人已為『讀不懂、記不住』奮鬥了兩千年，累積出一套方法。直接採用它們，比憑空設計可靠。

### 1.1 經—註—疏：三層分工

傳統注疏體系本身就是一套分層蒸餾架構：

- **經**：原文，不可動。
- **註**：解釋字詞、名物、制度（如王冰註《素問》）。
- **疏**：解釋註，並串講義理（如《十三經注疏》體例）。

**可轉化為數位機制**：這正是現代『原文層／註解層／白話層』三層分離的雛形。古人早已知道三層必須分開——夾註混排會造成閱讀災難。

### 1.2 歷代對《靈樞》的「蒸餾」嘗試

《靈樞》古稱《九卷》《針經》，南宋史崧校定為二十四卷八十一篇，是今日通行系統的來源。

> **考訂更正**：『《九卷》』出自《傷寒論·序》，「《針經》」出自皇甫謐《針灸甲乙經·序》；《漢書·藝文志》只記『《黃帝內經》十八卷』，並無「九卷」之名。教學材料若寫成『《漢書·藝文志》稱《九卷》』是錯的。
>
> 另需澄清：**滑壽沒有《靈樞》專著**。他的貢獻在《十四經發揮》——以十四經統穴並配仰人／伏人明堂圖，圖＋歌的體例，解決的正是『經絡記不住』。歷代處理方式可分四類，恰好對應四種蒸餾策略：

| 策略 | 代表 | 做法 | 對自學的價值 |
|---|---|---|---|
| **保留早期面貌** | 楊上善《黃帝內經太素》 | 分類編排，保存大量《靈樞》早期文本 | 校勘他校的主要來源；可看出後世傳抄的改動 |
| **按實用主題重編** | 皇甫謐《針灸甲乙經》 | 以《素問》《靈樞》《明堂孔穴針灸治要》按病證、部位分類改編 | 最早證明『按臨床需求重編』可行且有效 |
| **以類相從（最成功的蒸餾）** | 張介賓《類經》 | 打破原書篇序，按攝生、陰陽、藏象、脈色、經絡、標本、氣味、論治、疾病、針刺、運氣等類重編，共 32 卷 | **這是本方法論最重要的歷史先例**：證明『重排順序』比『逐篇順讀』更符合學習邏輯 |
| **為初學做節選** | 汪昂《素問靈樞類纂約註》、李中梓《內經知要》 | 大幅精選，只留核心條文 | 承認『不是每一篇都同等重要』，與現代難度梯度設計同構 |
| **逐篇全註** | 馬蒔《靈樞注證發微》、張志聰《靈樞集註》、黃元御《靈樞懸解》 | 逐篇逐句注解 | 註釋層的來源；蒐集歷代詮釋 |

**《類經》的啟示最直接**：它證明《靈樞》的主題天然交錯——同一概念散見多篇，逐篇順讀會讓學習者反覆碰到卻不自知，因此張介賓寧可打散原書重編。

> **注意**：此處不可用『重文比例』當論據。本專案改用權威底本實測後，全書跨章逐字重複僅 31 個 12-gram（見 4.3 節）——**《靈樞》本身幾乎不重複**。重編的理由是『學習依賴關係』與『主題交錯』，不是「去重」。

#### 《類經》的十二類骨架（可直接借用）

張介賓自序所定的十二類為：**攝生、陰陽、藏象、脈色、經絡、標本、氣味、論治、疾病、鍼刺、運氣、會通**。全書三十二卷，約 390 目，**全錄經文並標出處**（如『靈樞衛氣失常篇○十八』）後加註，另附《類經圖翼》。

其中**「會通」類是關鍵的兜底設計**——專收無法硬歸入單一類目的條文。任何分類系統都必須有這一類，否則分類者會被迫把內容塞進不合適的類別，製造錯誤連結。

方法論上有兩句可直接轉為設計原則：
- **『以類相從』**——本專案 4.2 節的 11 模組即此原則的實現。
- **『不拾以圖，其精莫聚』**——凡涉及循行、分寸、形制、度數者，一律先出圖再讀文。

> ### ⚠ 關鍵更正：《類經》的分類單位是「條」，不是「篇」
>
> 張介賓自序『盡易舊制，顛倒一番，從類分門』，全書 32 卷 390 條。因此**一部《類經》裡找不到任何一篇完整的《靈樞》原篇**——〈九鍼十二原〉的十二原入經絡類、九針之義入針刺類；〈經脈〉的循行入經絡類、十二經病入疾病類。反之，想讀某篇全文，必須跨數卷檢索。
>
> **對本專案的意義**：不可宣稱『依《類經》將 81 篇分類』。本專案 4.2 節的 11 模組是**自擬的工作性分類**（揉合教材主題與針灸學科分工），既不是《類經》分類，也不是任何官方大綱。此點必須在學習材料上標明，否則會誤導學習者以為學界有『81 篇逐篇分類』的共識——**實際上並沒有**。學界所謂「分類」至少混雜四種不同性質的東西：版本卷次分群、教材的學說專題分類、類書式按條重編、以及教學工作性分類。

#### 其他類纂傳統

- **李中梓《內經知要》**（1642）分八類：道生、陰陽、色診、脈診、藏象、經絡、治則、病能。**這是『最小可用版本』的歷史先例**，可作為速通路線。
- **汪昂《素問靈樞類纂約註》**承《類經》而大幅刪繁——「類纂」是分類編纂，「約註」是註解從簡。**這是『承認篇目重要性不等』的明確表態。**

**設計建議**：採**雙層目錄**——8 類速通（李中梓式）／12 類完整（張介賓式），讓學習者可依時間預算選擇路線。

### 1.3 傳統記憶技術

《靈樞》內容可粗分為『可推導的義理』與『必須背死的定額』。後者古人用專門技術處理：

- **歌訣／口訣**：把穴位、經脈、分寸編成有韻的短句。主要來源是《針灸大成》的歌賦系統（標幽賦、金針賦、百症賦、玉龍歌、通玄指要賦、席弘賦、馬丹陽天星十二穴歌、四總穴歌、行針指要歌）與五輸穴歌、十二原穴歌、十五絡穴歌、十四經穴分寸歌。**歌訣只作索引用，必須能雙向還原**（歌→穴表→體表），否則只是背了另一串字。
- **圖像化／銅人**：北宋王惟一《新鑄銅人腧穴針灸圖經》（1026）與天聖銅人（1027）是**最早的國家級腧穴標準化教具**。操作採『讀→畫→指→點』四步：先讀文，再自繪，再在標準圖上比對更正，最後在體表指認。
- **分寸折量**：骨度分寸法把絕對長度轉為**相對比例**，不論男女老少高矮胖瘦皆用同一標準——這是最早的「標準化」思維。後世補充中指同身寸與一夫法。**落地形式**：把《骨度》做成可填空的分寸表，取穴前先報分寸。
- **以經解經**：用本書他處的說法解釋此處，避免引入後世理論。操作順序是**先同篇、再他篇、最後才查註家**；並建『術語—篇目』反查表。史崧原序即以《本輸》校正《難經》第六十五篇之誤，是此法有效性的早期證據。
- **本校／他校／理校**：陳垣《校勘學釋例》四法。**成本控制原則**：只校必背篇與字義分歧處，不做全書校勘。

**可轉化為數位機制**：歌訣 → 韻律化卡片與音檔＋歌訣↔表格雙向測驗；圖像化 → 可點擊經脈圖／自繪圖與標準圖疊合比對；分寸折量 → 參數化取穴練習器（報分寸自動判分）；以經解經 → 全書互文檢索與引用網絡圖。

### 1.4 術語歧義：最隱蔽的失敗模式

古漢語經典最危險的不是生字，而是**同一個詞在篇內義、他篇義、後世義三者不同**。三個已確定的實例：

| 術語 | 篇內義 | 後世義 | 風險 |
|---|---|---|---|
| **十二原** | 《九針十二原》指五藏原（太淵、大陵、太衝、太白、太谿各二）＋膏之原鳩尾＋肓之原脖胦 | 十二經脈各一原穴 | 學習者會把兩者混為一談 |
| **心出於中衝** | 《本輸》以心包經穴表述手少陰心 | 後世心經五輸為少衝、少府、神門、靈道、少海 | docx 原註已指出『古人以心包代心受邪』，但多數材料不提 |
| **俞／輸／腧** | 三字古通而各有專用 | 「俞」為古字、「腧」為現代規範、「輸」用於五輸穴 | 檢索與卡片會互相漏接 |

**解法（強制）**：每個術語必須填『篇內義／他篇義／後世義』三格，三者不一致即自動生成一道辨別題。這與 3.5 節的字形正規化是同一件事的兩個層面。

**實測印證**：本專案在《經脈第十》與《本輸》的自動抽取中，正是靠『五藏無原穴、六府有原穴』的一致性約束才發現《本輸》缺了小腸一段——**術語與結構的完整性約束，本身就是校勘工具**。

### 1.5 自學者的七個典型失敗模式

| 失敗模式 | 症狀 | 對策 |
|---|---|---|
| 古漢語障礙 | 讀不下去，逐字查字典後仍不知句意 | 先白話通讀再回原文；訓詁三欄卡；優先攻高頻字（氣、脈、經、俞、輸、腧、節、機、神、寫、補） |
| 術語歧義（最隱蔽） | 以為懂了，實際套用後世義 | 見 1.4 節：強制三義對照，不一致即出題 |
| 逐篇順讀 | 讀到第 20 篇已忘第 3 篇；不知同一概念已重複出現 | 改模組化閱讀（第四部分），先讀經—解對照 |
| 只讀不練 | 產生流暢性錯覺，以為懂了 | 強制提取練習；『讀→畫→指→點』驗收；每週閉卷默寫 |
| 貪多求全 | 81 篇全讀，每篇都讀不深 | 採雙層目錄（8 類速通／12 類完整），承認篇目重要性不等 |
| 脫離臨床 | 能背不能辨 | 每篇強制產出一條可執行臨床命題＋一條操作紅線（刺禁）；病證模組（M6）與刺法模組（M4）交錯練習 |
| 被註解淹沒 | 一次看到原文＋歷代註＋白話＋現代機理，認知超載 | 分層呈現，一則一屏，初學期只開原文＋白話 |
| **版本陷阱** | 背了錯字、錯篇序、被刪節的句子 | **先篇目校定，再只對必背篇做多版本對校**（本專案已在 `docs/01` 證實此風險） |

## 第二部分：學習科學方法論

標記說明：**【A】**強實證／多重複驗證；**【B】**中等實證；**【C】**理論或領域共識；**【D】**實務推論（尚未在中醫古籍上驗證，須自行 pilot）。

### 2.1 提取練習（retrieval practice）【A】

**做法**：把「閱讀」改造成『先答後看』。低階是挖空、cue→默寫；高階是先給病證情境，讓學習者提取對應經脈與刺法。

**為何對文言特別有效**：文言沒有現代母語直覺，重讀時的流暢性錯覺遠比白話嚴重。提取強制暴露「假懂」。

**為何容易失敗**：文言一詞多義，卡面線索不足（只給「氣」「陰陽」）會產生合法多解 → 錯誤評分與錯誤記憶。**每張卡必須帶語境錨點**（篇名＋前後半句）。

**參數【D】**：提取成功率維持 80–90%；古漢語建議**立即回饋**（錯誤一旦固化極難改）；新手前 2–3 次先『閱讀→遮蓋→提取』，不要一上手裸考。

### 2.2 間隔重複（SRS）【C】

**SM-2（Woźniak, 1987）**：逐卡獨立，狀態只有 ease factor。`EF' = EF + (0.1 − (5−q)(0.08 + (5−q)·0.02))`，下限 1.3；間隔 `I(1)=1天`、`I(2)=6天`、`I(n)=I(n−1)×EF`。本質是啟發式規則，不預測回想機率，會出現「ease hell」。

**FSRS**：基於 DSR（Difficulty / Stability / Retrievability）機率模型。`R(t,S) = (1 + factor·t/S)^(−w20)`，以 `R(S,S)=90%` 校準。成功複習後穩定性增幅隨 D↑ 而降、隨 S↑ 而降、隨 R↓ 而升——這是它內建 spacing effect 的方式。以個人複習史擬合 19–21 個參數，可設定 desired retention。

| 維度 | SM-2 | FSRS |
|---|---|---|
| 模型 | 啟發式規則 | DSR 機率模型 |
| 可調參數 | 每卡 1 個 EF | 全域 19–21 個 + 每卡 D/S |
| 逾期處理 | 線性懲罰 | R 下降 → 成功後 S 增益上升 |
| 目標控制 | 無 | 可設 desired retention |
| 個人化 | 幾乎無 | 由歷史資料擬合 |

**對《靈樞》的建議參數【D】**：術語／腧穴／循行卡 desired retention 0.90–0.93；長條文卡 0.88–0.90（古籍錯誤成本高於複習時間成本）；新卡每天 5–15 張；學習步驟 `10m` 或 `15m`。

**禁忌**：程序性技能（進針手法、角度、力度）不可只用 SRS，需動作訓練或影片示範。SRS 只獎勵「能複述」，不獎勵「理解」——理解型目標必須走練習題管線。

### 2.3 交錯練習（interleaving）【B】

**做法**：同一時段混合不同經脈／證候／篇。臨床辨別最需要的是『相似證候的區辨』（各種厥、脹、痺），這正是交錯最強的場景。

**但順序很重要**：新手在尚未建立基本圖式前就交錯，會使認知負荷爆表（expertise reversal）。**先小範圍塊狀建立圖式（一次專攻一條經脈），再轉交錯辨別題。**

### 2.4 精緻化提問（elaborative interrogation）【B】

**做法**：對每則條文追加「為什麼」與『與已知如何連結』。例：為何手太陰肺經「起於中焦」而非起於肺？九針形制為何對應不同淺深病位？

**為何對古籍必要**：文言高度壓縮，省略主語與邏輯連接詞，elaboration 是補回隱含邏輯的主要手段。

**失敗模式**：初學者會產出『流暢但錯誤』的自圓其說，且記得特別牢。**必須提供專家範例答案**，或建立核對機制。

### 2.5 雙編碼（dual coding）【B】

**做法**：經脈循行圖、腧穴體表定位圖、臟腑—經脈關係圖、子午流注時鐘、九針實物圖、骨度分寸圖。

**為何對《靈樞》特別有效**：大量條文是**空間性描述**（循行、骨度、體表定位），純文字解碼負荷極高。

**失敗模式**：圖文分屏造成來回掃視；裝飾性插圖反而降低學習；自製圖未標依據會固化錯誤定位。

### 2.6 認知負荷控制【A/B】

《靈樞》同時觸發三種負荷：**內在**（文言解碼＋高元素互動性）、**外在**（版本註解混排、術語不一致）、**有效**（建立圖式）。

**做法**：分層呈現（不在同屏混排原文＋註＋白話＋現代機理）；漸進式揭露（一則一屏）；新手期用 worked example，再過渡到 problem solving。

**最常見錯誤**：一次呈現『原文＋歷代註＋白話＋現代機理＋英文術語＋西醫對照』——教科書式超載，也是坊間古籍 App 的通病。

### 2.7 合意困難（desirable difficulty）【A】

拉長提取間隔至『有點吃力但還能答對』；變式練習；先嘗試生成再看答案。

**古籍陷阱**：文言本身已提供『免費難度』，但**難度不等於有效難度**。若學習者連字都不會讀、斷句都不會，那是純挫敗而非合意困難。**需要一個前備門檻測驗來分層**。

### 2.8 認知層次與題型對映

| 目標 | Bloom | 對應題型 | 載體 | 自動評分 |
|---|---|---|---|---|
| 記住條文與術語 | remember | 填空／默寫、條文配對 | SRS | 高 |
| 理解機理與關係 | understand | 循行排序、關係圖補全 | 練習題 | 高 |
| 能用於辨證 | apply | 證—治配對、腧穴定位 | 練習題 | 中高 |
| 能分析複雜醫案 | analyze | 醫案辨證、跨篇整合 | 案例庫 | 中 |
| 能批判錯誤解釋 | evaluate | 錯謬辨識 | 對抗題庫 | 高 |
| 能自行重述 | create | 生成式複述 | 開放題＋rubric | 低 |

**推薦配比【D】**：remember 40% / understand 25% / apply 20% / analyze+evaluate+create 15%。**若 remember 超過 60%，這個系統在訓練背誦機而不是中醫。**

**最大陷阱**：用背誦冒充應用。每個高階目標都必須有獨立的評量題型，不能靠 SRS 統計推論。

## 第三部分：蒸餾管線工程

### 3.1 十階段管線

```
S0 底本選定 → S1 篇章切分 → S2 正規化（字形／標點）
→ S3 實體抽取 → S4 關係抽取 → S5 本體映射
→ S6 分層蒸餾 → S7 題目生成 → S8 品質閘門
→ S9 排程派發 → S10 遙測回饋
```

### 3.2 分層蒸餾（L0–L7）

| 層 | 內容 | 產生方式 | 可信度 |
|---|---|---|---|
| L0 | 校勘定本原文 | 人工＋OCR＋校對 | 最高 |
| L1 | 異文／校記 | 人工校勘 | 高（標為 variant） |
| L2 | 歷代註解 | 引用，標註家與朝代 | 高（屬詮釋） |
| L3 | 現代白話 | LLM＋回譯驗證 | 中（需驗證） |
| L4 | 術語／腧穴／條文卡 | LLM 輔助＋人工定稿 | 中高 |
| L5 | 關係三元組 | LLM＋規則＋人工 | 中高 |
| L6 | 臨床案例層 | 後世醫案／教材 | 中（明確非原文） |
| L7 | 題目層 | 派生 | 依題型 |

### 3.3 防護生成式模型的四類系統性錯誤

1. **幻覺**：L0 永不由模型產生；白話層強制回譯檢查（白話→文言，與原文做雙向蘊含比對）；span 級引用並自動驗證引文確實存在於底本。
2. **張冠李戴**：每條陳述帶 `{chapter, char_start, char_end, text_hash}`。跨篇聲明（『某穴主治某病』）須同時引原文與註家來源，避免把註家推衍當經文。
3. **後世理論倒灌**：建立術語年代詞典（「溫病」『衛氣營血辨證』屬清代；『命門學說』成熟於明；『奇經八脈』理論化在《難經》之後）。凡白話或題解出現年代不符的術語，標為 `modern_interpretation` 或直接攔截。
4. **忽略異文**：採『底本＋校記』結構，禁止 silent emendation。有異文處的卡片必須標示。

### 3.4 可信度標註（強制寫入資料結構）

```yaml
epistemic_layer: [canonical_text, textual_variant, historical_commentary,
                  modern_translation, modern_interpretation, clinical_case, exam_item]
assertion_type:  [attested, paraphrased, inferred, extrapolated]
```

UI 規則：不同層不同視覺處理；任何 AI 生成內容必須標示，且不得與 `canonical_text` 同字重同版面。

### 3.5 簡繁與異體字：不可機械轉換

**本專案的底本已出現此問題**（第 1–43 位用「於」，第 44–81 位用「于」；「滎」與「榮」並存；「鍼」270 次與「針」19 次並存）。

**中醫專有高風險字對**：

- **藏／臟**：古籍作「五藏」「藏象」，不可無腦轉「臟」
- **俞／腧／輸**：三者不可互轉。「俞」為古字，「腧」為現代規範，「輸」用於「五輸穴」
- **府／腑**：古籍作「六府」「藏府」
- **寫／瀉**：古籍「寫」通「瀉」
- **滎／榮**；**齊／劑**；**募／幕**；**支／肢**；**鍼／箴／針**

**對策**：絕不執行機械簡繁轉換。以『詞級映射表＋字形規範表＋不可轉換白名單』處理，資料結構保留 `original_glyph` 欄位，永不覆寫；檢索層另建同義索引。

**實測教訓**：本專案用『名句存在性』抽樣查核全書時，以「皆上注**於**目」與「五十周**於**身」檢索，兩者皆 0 命中，一度誤判為篇章缺失；實際是這兩篇位於「于」區，原文作「皆上注**于**目」「五十周**于**身」。**若不做字形正規化，連『這句話在不在書裡』這種最基本的查核都會出錯**——這是分層架構必須先做 S2 正規化的具體理由。

### 3.6 ID 與切分紀律

- 層級：篇（81）→ 段 → 條文 → 句。
- 穩定 ID：`LS-{篇號3碼}-{段2碼}-{條2碼}`，例 `LS-010-02-004`。
- **關鍵紀律**：段落邊界優先沿用既有文本的既成段落，**不要讓模型自由切分**——模型重跑會漂移，導致卡片與引文對不上。本專案實測《經脈第十》的段落邊界與知識單元邊界高度吻合（63% 段落以人物名開頭，即對話輪換處），可直接沿用。

#### 三個必須避開的陷阱

**1. 經穴代碼是 `TE` 不是 `TH`。** WHO 標準用 Triple Energizer（TE），文獻常見的 TH（Triple Heater）不是標準寫法。代碼無分隔符：`ST36` 而非 `ST-36`。

**2. ICD-11 的 TM1／TM2 前綴範圍，與常見假設不同：**

| 模組 | 內容 | 代碼範圍 | 條目數 |
|---|---|---|---|
| **TM1**（中國傳統醫學） | disorders / patterns | **SA00–SJ1Z** | 472 |
| **TM2**（阿育吠陀等） | disorders / patterns | **SK00–ST2Z** | 648 |

不是「TM1＝SA、TM2＝SB」。**SB 屬 TM1**；TM1 涵蓋 SA、SB、SC、SD、SE、SF、SG、SH、SJ。

**3. 命名空間衝突（最危險）。** `ST`、`SP`、`SI`、`BL`、`KI`、`LR`、`GB` 等針灸經脈縮寫，與 ICD-11 TM2 的代碼前綴**部分同形**。資料庫若不分 namespace，`ST` 會同時指向「胃經」與『TM2 某證候』。**必須以 namespace／Foundation URI 隔離**。

> 另需注意：WHO 2022 術語為 CC BY-NC-SA（禁商用），ICD-11 為 CC BY-ND（禁改作）。若本專案日後要商業化或公開發布改編版，這兩項的使用方式必須重新評估。

| 重疊篇對 | 25 | 9 |
| ≥15 的聚類 | 7 群 / 21 章 | **0** |

權威本中重疊最強的篇章對：

| 共享 12-gram | 篇章 | 性質與教學處理 |
|---|---|---|
| 13 | 《腸胃》↔《平人絕穀》 | 同一組腸胃容積數據重出。**合併為一張數據表**，不重複教 |
| 7 | **《九鍼十二原》↔《小鍼解》** | **「經—解」關係**：《小鍼解》引經文短語作解。**成對教學，先經後解** |
| 3 | 《九鍼十二原》↔《九鍼論》 | 九針形制用語重出，合併為一張九針表 |
| 3 | 《論勇》↔《五味論》／《行鍼》↔《官能》等 | 套語，不需處理 |

明細見 `data/重文與經解對照.json`。

**修正後的設計意義**：《靈樞》本身的逐字重複極少，**「去重」不是蒸餾的主要價值**。真正的價值在三處：

1. **模組化重排**——依學習依賴關係重編，而非原篇序。
2. **分層**——原文／註／白話／正規化分離。
3. **「經—解」對照**——《九鍼十二原》與《小針解》必須成對讀（這是全書唯一明確的經解關係），先讀經文、再讀解文，並可出『哪一句對應哪一句』的配對題。

> 這個更正本身也有方法論意義：**任何『古籍統計發現』都必須先確認底本可信**。同一套演算法換一個底本，結論可以從「2,124」變成「31」。

### 4.4 已被實證的重複樣板

《經脈第十》的驗證（見 `docs/03_可行性驗證_經脈篇.md`）顯示：12 條經脈的「治法」欄中，**11 條是完全相同的 36 字樣板**（「盛則寫之，虛則補之，熱則疾之，寒則留之，陷下則灸之，不盛不虛，以經取之」）。

**處理原則**：抽為**全域規則卡**（學一次），而非 12 張重複卡。這正是「蒸餾」與「搬運」的差別。

同時，這段重複本身是**天然的間隔重複素材**：初學用樣板卡，複習用『找出哪一條經脈的循行被打亂』的辨別題。

### 4.5 學習迴路

```
建立圖式（塊狀，單一主題）
   → 提取練習（SRS，條文／術語／腧穴）
   → 理解練習（循行排序、關係補全）
   → 應用練習（證—治配對、腧穴定位）
   → 交錯辨別（混合不同經脈／證候）
   → 醫案推理（跨篇整合）
   → 錯謬辨識（對抗題庫，防後世倒灌）
```

對應的每日節奏建議【D】：新卡 5–15 張、複習卡全部清空、每週一次交錯測驗、每月一次延遲後測。

## 第五部分：品質與成效評估

### 5.1 蒸餾品質指標

| 指標 | 目標值 |
|---|---|
| 篇章覆蓋率 | 100%（81/81） |
| 引文有效率（引文可在底本定位） | ≥ 0.99 |
| 支撐率（原文 ⊨ 白話） | ≥ 0.95 |
| 無支撐聲明率（白話含原文外新增） | ≤ 0.02 |
| 實體抽取 F1 | ≥ 0.88 |
| 關係抽取 F1 | ≥ 0.80 |
| 術語一致性 | ≥ 0.98 |
| 異文保留率 | 100% |
| 可重複性（兩次輸出一致率） | ≥ 0.98 |

### 5.2 學習成效指標

- **真實保留率**（首次作答正確／到期複習數）：0.88–0.92
- **延遲後測**：1 週、1 個月、3 個月——**只測當下毫無意義**
- **遷移測驗**：未在 SRS 出現過的醫案辨證題
- **可讀性遷移**：81 篇中能自行讀懂的比例
- **卡片成熟度分佈**、leech 卡比例（連續 ≥4 次答錯 → 進入人工修卡隊列）

### 5.3 最小可行驗證（單一學習者也能做）

不必等大規模 RCT。先量三個核心指標即可：

1. 引文有效率（自動，pipeline 側）
2. 新卡首答正確率（應落在 0.70–0.85）
3. 一週延遲後測保留率

**若首答正確率 > 0.95，表示卡片太簡單；< 0.60，表示切分過難或先備不足。**

N-of-1 設計即可提供可行動的訊號：以 A-B-A 交替比較『模組化＋SRS』與『逐篇順讀』，各 2 週，比較延遲後測。
