### 為什麼不用 ctext.org

`ctext.org` 雖收錄《靈樞》全文，但其 API 文件明示**禁止自動化取用**，並聲明會對爬蟲**間歇性故意回傳損壞資料**。對一個以『原文可查證』為前提的專案，這是不可接受的來源。本專案全程未使用 ctext。

### 與其他版本的關係（供日後三源互校）

```
史崧家藏舊本（9 卷 81 篇，1155 年）
   └─ 史崧校定 24 卷（增修音釋）
        └─ 元重刊、明熊宗立點校重刊（24 卷併為 12 卷）──→ 四庫全書本
        └─ 明趙府居敬堂本（12 卷）──────────────→ 四部叢刊本（本專案底本）
```

四庫全書本〈提要〉已明言：『目録首題鼇峰熊宗立點校重刊，末題原二十四卷，今併爲十二卷，是此本爲元時重刊所併。』此點可作日後校勘版本關係的一手依據。

## 三、建置流程

可重現：`python3 scripts/build_base_text.py`

```
S0  取得權威全文（Kanripo/KR3e0002，12 卷）
S1  剝離卷末題、頁碼、行末標記
S2  剝離「音釋」——每篇篇末之反切與異文，獨立保存為 L2
S3  目錄定篇（81 篇）→ 正文定位篇首 → 切分
S4  夾註分離（底本小字校注如『(遊/一作)』）→ L1 經文
S5  字形正規化（異體／日式碼位）→ 檢索層
S6  對話輪分段（黃帝曰／岐伯曰…）→ 穩定 ID
S7  輸出 JSON / Markdown / 對照表
```

### 三層分離（對應方法論 3.2 節）

| 層 | 內容 | 用途 |
|---|---|---|
| **L0 原文** | 含小字夾註，逐字保留 | 校勘、引用、異文比對 |
| **L1 經文** | 剝離夾註與音釋 | 閱讀、背誦、出題 |
| **L2 音釋** | 史崧音釋（反切、異文） | 古音、異文研究；亦可作「難字」教學素材 |

另出**正規化層**，僅作字形規範，供全文檢索。

### 已處理的字形問題

## 五、與舊 docx 的逐篇比對

79 篇可比（缺 2 篇、1 篇為《素問》誤收）。

**比值中位數 1.000，平均 1.018。**

這個結果很重要：**舊 docx 並非整體刪節，而是局部差異。** 它在中段錯位、缺兩篇、誤收一篇的同時，其餘篇章的篇幅大致正常。換言之，缺陷是「點狀」而非「面狀」——這也正是它難以用肉眼察覺的原因。

## 六、句讀層（新增）

工作區另存有一份**已加現代標點、依文意分段**的《靈樞》正文（`灵枢经正文_一至八十一篇/`，81 篇齊備，同為趙府居敬堂本系統）。實測其與 SBCK 底本：

- 字數幾乎相同（如第 1 篇：1,578 vs 1,577 字）
- 相似度均值 **0.9616**
- 差異絕大多數是字形（於／于、脉／脈、荅／答、粗／麤、税／稅）

因此**不需要從頭標點**——可直接把標點「轉移」到權威底本上。

做法（`scripts/apply_punctuation.py`）：兩側先做對齊用正規化 → 字元級對齊 → 把標點本每個字之後的句讀，掛到 SBCK 對應字之後。

### 結果

- **81／81 篇成功轉移**
- 平均相似度 0.9616
- 標點密度約每 5.7 字一個句讀

### 需人工複核的 5 篇

| 篇 | 相似度 | 說明 |
|---|---:|---|
| 論疾診尺 | 0.679 | 兩本分歧大 |
| 寒熱病 | 0.836 | 舊 docx 亦在此篇異常（多出《終始》內容） |
| 癰疽 | 0.849 | 舊 docx 亦偏短 |
| 終始 | 0.890 | 與《寒熱病》糾纏 |
| 逆順肥瘦 | 0.895 | — |

> 這 5 篇與第五節『顯著異常』的篇章高度重疊，**不是巧合**——它們正是兩本之間有實質異文的地方。應優先做版本對校。

### 定位

句讀層是 `modern_punctuation (transferred)`，**屬詮釋層，未經人工逐句複核**。使用規則：
- 可作閱讀與卡片生成的**草稿**
- 不可在未複核前當作『原文標點』引用
- 與 L0 原文層分離存放，不得混用

## 七、已知限制（必須明示）

1. **新底本沒有句讀。** 四部叢刊本是白文，句讀屬詮釋，本專案**未**自行施加標點。現有分段只依『黃帝曰／岐伯曰』等對話輪切分（553 段），**不是句讀**。句讀層必須另行建置並標記為『現代標點』。
2. **錄文依賴單一來源。** 目前僅 Kanripo 一套錄文。方法論要求三源互校（四部叢刊本 × 四庫本 × 史崧本），此步尚未做。
3. **音釋剝離採啟發式規則**（括號＋斜線＋殘文長度），可能誤刪或漏刪極少數行；已用尾部抽查與全書殘留掃描驗證，結果為 0 殘留，但不等於逐行確認。
4. **未與《太素》《甲乙經》對校。** 這兩部是判斷《靈樞》異文早晚的關鍵旁證。
5. **授權**：底本為公有領域，但若日後要公開發布，仍應註明錄文來源（Kanripo）與所據版本（四部叢刊本）。
6. **一處已修補並覆核**：《論疾診尺》缺頁已補（`data/補頁記錄.json`），並經**史崧本卷二十一**覆核，文字相合。
