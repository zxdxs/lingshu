## 二、『只加標點、不改字』的保證

補標最容易出錯的地方，是『順手改字』——把異體改成通行字、把可疑字改成想當然的字。本專案的處理方式是：

1. 只提供『已加標點版』；
2. 腳本剝除所有標點，與底本原字串做**逐字比對**；
3. 完全相同才套用，否則報錯拒絕。

因此補標後的文字與底本**一字不差**。已驗證：81 篇的『去標點文字』與底本正規化層完全一致（唯一差異是《》《》書名號，屬正常標點）。

## 六、重建流程（三個腳本，順序不可顛倒）

```bash
python3 scripts/build_base_text.py            # 底本 + 補頁（含 data/補頁記錄.json）
python3 scripts/apply_punctuation.py          # 標點轉移
python3 scripts/apply_editorial_punctuation.py # 編者補標（含 data/補標點.json）
```

若只跑前兩步，第 3 步的 1,267 字會退回無標點狀態。**三步必須連跑。**
