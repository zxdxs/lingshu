### 設計要點

- **腧穴詞典來自《本輸》五輸表 + 十二原**，共 63 條。這不是全書腧穴辭典（《靈樞》他篇另有穴名），但這 63 條是**有明確歸經與五輸分類依據**的部分，可信度最高。

### 題目 schema

```json
{
  "item_id": "Q-LS010-XUN-肺手太陰",
  "type": "error_identification",
  "bloom": "evaluate",
  "stem": "《靈樞·經脈》所述「肺手太陰」，其循行起點為何？",
  "answer": "起于中焦",
  "distractors": ["起于小指之端", "起于胸中", "起於鼻之交頞中"],
  "source": {"篇序": 10, "篇名": "經脉"},
  "note": "循行起點；干擾項取自他經原文",
  "auto_grading": "exact"
}
```

### 關鍵設計：干擾項不是編的

C 類題的錯誤選項，全部是**他經原文的循行起點**（例如問肺經，干擾項取小腸經「起于小指之端」、心包經「起于胸中」）。這樣的好處是：

1. 干擾項本身也是真知識，做錯時順便學到；
2. 不存在『編造一個似是而非的說法』的風險；
3. 符合方法論要求的『錯謬辨識』題型——考的是**分辨**，不是**記憶單一答案**。

## 四、過程中修正的三個錯誤（都是實測暴露的）

| 錯誤 | 現象 | 修正 |
|---|---|---|
| 『起於／起于』只搜前者 | 十二經脈只抓到 1 條循行起點 | 改為 `起[於于]` |
| 題幹動詞用錯 | 所有五輸穴都寫「出於____」，但原文滎作「溜於」、輸作「注於」、合作「入於」 | 按五輸分派動詞 |
| 「大淵」與「太淵」分裂 | 同一穴被算成兩個實體，高頻榜同時出現 | 建異名表，以規範名為主鍵 |

第三個錯誤特別值得記：**它不是程式 bug，而是資料層的『同名異形』問題**。任何古籍知識圖譜都會遇到，必須在建圖之前先做異名對照，否則統計與檢索全部失真。
