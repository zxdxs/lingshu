# 100 發布前檢查：還差什麼

把「可發布」定義為：**別人拿到這包資料，不必問維護者，就能判斷它是什麼、怎麼用、能信到什麼程度。**
用這個標準檢查，結論是：**內容已經夠，只剩兩件需要人／環境的事**（聯絡方式、Anki 實機）。
授權已於審閱時定案（CC BY-NC-SA 4.0），安全提醒已進全站與卡片（見 `docs/114`）。

**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。
