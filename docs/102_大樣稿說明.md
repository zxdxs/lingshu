# 102 大樣稿：八頁，與要審的四件事

用現有資料排的一份樣書，目的不是完成品，是**讓版面與取捨被看見**。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

## 三、要審的四件事（頁 8 也列了）

1. **授權**：CC BY-NC-SA 4.0／CC BY-SA 4.0／保留所有權利。目前留白。
2. **書名**：《中醫典籍導讀﹣靈樞經》／《靈樞：可練的讀本》／其他。
3. **樣張篇目**：現用第 40 篇（短、有校記）；可換〈本輸〉（五輸穴）或〈經脈〉（最長篇）。
4. **案例題比例**：維持 6 道樣板，或找人寫到 20–30 道再發布。

## 四、我自己看到的問題（不必等你指出）

1. **第 3 頁的音釋被截斷**：`卷六音釋節錄：…` 取了 70 字，讀起來像殘句。正式版應整段列或改放頁邊。
2. **第 4 頁的圖是 PNG**，在紙上可能偏灰；正式版建議重排為向量或提高對比。
3. **第 5 頁只有三題**，看不出題庫的量；正式版可加『本頁示例，全庫 1031 題』。
4. **第 2 頁的三分法**（練／讀／查）與 `docs/101` 重複；若兩者都留，要決定哪個是主入口。
5. **封面偏素**。若要像書，可加一卷首題跋或底本牌記；若要走工具書路線，現在這樣剛好。

## 五、一份必須寫下來的限制

**我沒有看到這八頁的樣子。**

環境的視覺模型回傳 429（額度不足），本模型也不能讀圖。八頁 PNG 是由瀏覽器確定性渲染，尺寸與分頁都驗過（每頁 1188，無溢出），但**字有沒有擠、斷行漂不漂亮、圖灰不灰，我無法判斷**。

所以這份大樣稿需要你看；我給的「問題」是從 HTML 結構與內容推的，不是看出來的。

## 六、怎麼改

改 `scripts/make_proof.py`（版面在 `CSS`，內容在各 `page()`），重跑：

```
python3 scripts/make_proof.py --split
```

再截圖即可。數字、引文、題目都從 `data/` 與 `底本/` 即時取，不會與題庫脫節。
