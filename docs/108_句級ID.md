## 一、編號規則

```
篇序-段-句        例：40-6-1
```

- **段**＝句讀層的一行（對話的一輪、或一段敘述）。
- **句**＝行內以 `。！？` 切分；**；不斷句**（分號是句內停頓）。
- 段與句都從 1 起算。

全書 **3,289 句**（81 篇）。

例（第 40 篇第 6 段）：

```
40-6-1  岐伯曰：受穀者濁，受氣者清。
40-6-2  清者注陰，濁者注陽。
40-6-3  濁而清者，上出于咽；清而濁者，則下行。
40-6-4  清濁相干，命曰亂氣。
```

## 四、一個必須寫下的限制

句 ID **不穩定**：它由句讀層的切分決定。只要有人改了一個標點（把逗號改句號、或把一句拆成兩句），後面的編號全部位移。

這和傷寒的條文號不同——條文號有古本依據，我們的句 ID 是本專案自加的。所以：

1. 書介與「關於」必須寫明『本編號為本專案所加，非古本原有』；
2. 句讀層若改動，必須重跑 `build_sentence_ids.py`，並在 `CHANGELOG` 記錄『句 ID 位移』；
3. 對外引用時，**句 ID 與原文一起引**，只引 ID 會在改版後失效。

〔歸〕這是拿穩定性換精確度的交易。值得做，但要記帳。
