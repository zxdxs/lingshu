# 109 以主題重排：靈樞講的是身體與病變，不是八十一篇

這一輪不是加功能，是改入口。原來的站以「篇」為第一層，讀者要先知道篇名才進得去；這一輪改成先講**靈樞怎麼看身體、病怎麼進來、怎麼傳、怎麼表現、怎麼判斷**。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、為什麼要改

『八十一篇』是**書的結構**，不是**知識的結構**。一個初學者面對篇名，看不出：

- 靈樞對「身體」的想像是什麼（不是器官清單，是通道與空間）；
- 病是怎麼一步步進來的（皮膚→絡→經→輸→伏衝→募原→積）；
- 同一個證候為什麼要分位與時；
- 診斷為什麼分『看得見的絡』與『看不見的經』。

〔歸〕以篇為綱，適合校勘與出題；以主題為綱，才適合**讀懂**。兩者不衝突：主題頁往下連到篇，篇頁往上回到主題。

---

## 二、五個主題

| # | 主題 | 一句話 |
|---|---|---|
| 1 | 身體：通道、層次、空間 | 身體不是器官清單，是一組腔隙與通路 |
| 2 | 氣血：兩條路線、一個時間表 | 營衛不是兩種物質，是同一股氣的兩種走法 |
| 3 | 病從外入：一條有站點的路 | 病不是突然進來，是一站一站傳舍 |
| 4 | 病的表現：位置與時間 | 同一個證候，換了位與時，就是另一種病 |
| 5 | 判斷：看不見的用氣口，看得見的是絡 | 能看見的都不是經脈 |

每個主題包含：一句主張、一段說明、**3–4 條原文（附句 ID）**、對應篇、圖、以及**邊界**（原文沒說或未定的地方）。

例（主題 3）：

```
66-5-1  虚邪之中人也，始於皮膚
66-5-2  留而不去，則傳舍於絡脉
66-6-1  或著孫脉，或著絡脉，或著經脉，或著輸脉，或著於伏衝之脉
66-4-3  兩虚相得，乃客其形
```

邊界：「輸脉」「伏衝之脉」原文未定義；傳變用「或」，是舉例而非固定路徑。

## 四、這一輪沒有做的

1. **主題頁沒有連到題**：應該在每個主題下列『這主題有幾題、從哪題開始』，現在只有原文與篇。
2. **圖只有 3 張**（三焦、營衛、血、血絡），『病從外入』沒有圖——那正是最需要圖的一條。
3. **主題是我選的**：五個主題不是原文自帶的分類，是編者的歸納（比照 `docs/49` 的〔歸〕標記）。若要更嚴謹，應在頁面上標『本分類為編者所加』。

## 五、一句話

篇是書的目錄，主題是書的**問題**。**讀者不是來查目錄的，是來問『人體怎麼運作、病怎麼走』的。** 這一輪把首頁從目錄改成問題。
