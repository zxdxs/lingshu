# 110 主題連到題，與一張『病從外入』的路線圖

續 `docs/109`。補兩件：主題頁連到題庫、把〈百病始生〉的傳舍次序畫成路線。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、主題 → 題

每個主題卡現在有：『這個主題有 N 題 →』，點進去是 `#/items?theme=<id>`，題庫只顯示該主題所涉篇目的題，並在最上方標明主題與主張。

例：主題 3（病從外入）→ 146 題（主要是〈百病始生〉與相關篇）。

〔歸〕主題頁若不連到題，它仍只是一篇文章；連到題之後，讀者可以『讀完就練』，不必自己回題庫找。

---

## 二、病從外入：七站

〈百病始生〉把邪氣入身的次序寫成同一段：

| 站 | 證候（原文） | 句 |
|---|---|---|
| 皮膚 | 毛髮立則淅然，故皮膚痛 | 66-5-1 |
| 絡脉 | 在絡之時，痛於肌肉，其痛之時息，大經乃代 | 66-5-2 |
| 經脉 | 在經之時，洒淅喜驚 | 66-5-3 |
| 輸脉 | 在輸之時，六經不通，四肢則肢節痛，腰脊乃强 | 66-5-4 |
| 伏衝之脉 | 在伏衝之時，體重身痛 | 66-5-5 |
| 腸胃 | 在腸胃之時，賁嚮腹脹 | 66-5-6 |
| 募原→積 | 留而不去，傳舍於腸胃之外募原之間……息而成積 | 66-5-7 |

**七站是同一段連續原文**（66-5 的七句），不是拼貼。原文用「留而不去」四次串起來，這就是靈樞的病程語法。

頁面上以路線圖呈現：圓點＋虛線串連，每站右側是句 ID，可點回原文。

## 四、還沒做

1. **路線圖只有一條**：其他主題（身體、氣血、表現、判斷）沒有對應的「圖」，因為原文不是以路線形式寫的。硬畫會變成編者的發明。
2. **「或著孫脉、或著絡脉……」那一句**（66-6-1）沒有畫進路線——它是『或然路徑』，與主線不同，混在一起會誤導。
3. **主題卡仍未標『編者所加』**。

## 五、一句話

一張好圖不是把文字搬成方塊，是**證明這段文字本來就有次序**。七站之所以能畫，是因為原文自己用「留而不去」把它們串好了。
