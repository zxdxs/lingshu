# 111 把『編者所加』標出來

`docs/109` 的五個主題、`docs/110` 的路線圖，都是編者的歸納，不是原文自帶。這一輪把這件事寫在頁面上。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、標什麼、不標什麼

| 東西 | 誰的 | 標記 |
|---|---|---|
| 原文、句讀、句 ID 的切分規則 | 底本＋本專案 | 句 ID 標『本專案所加』（`docs/108`） |
| 五個主題的劃分與命名 | **編者** | 主題頁首說明＋每卡 `編者歸納` |
| 『病從外入』七站的選取與畫法 | 站名取自原文，**串連方式為編者** | 路線下方註『七站都在同一段』 |
| 概念卡的「分層」 | **編者整理** | 概念頁首說明 |
| 每條引文、每個句 ID | 原文 | 不標（它就是原文） |

---

## 二、頁面上的樣子

- **主題頁**開頭一張卡：「先說清楚——以下五個主題的劃分與命名是編者所加……讀者可以不同意這個分法，直接讀原文。」
- 每張主題卡右上角一個黃色 pill：`編者歸納`。
- **首頁**『五個主題』標題下加一行：主題的劃分與命名為編者所加。
- **概念頁**首句改為：每張卡的分層方式與命名是編者整理；各層原文與出處則逐字取自底本。

---

## 三、為什麼要標

不標的話，讀者會把『身體／氣血／病從外入』當成靈樞自己的分類，然後拿它去套原文——這正是 `docs/49` 一直避免的事：〔歸〕與〔原〕混在一起，久了就分不清哪一句是書上說的。

〔歸〕**歸納不是錯，冒充原文才是錯。** 標記的成本是一行程式，代價是讀者少了一次誤解。

---

## 四、還沒標的

1. **案例題的「情境」**：目前只用原文證候，沒有加原文沒有的臨床資料；但『把哪幾句放進同一個案例』仍是編者的選擇。
2. **五個主題的排序**（身體→氣血→病從外入→表現→判斷）：這是一個教學順序，不是原文順序。
3. **覆蓋表的分級**（題少／已讀／正確率）：指標本身是編者選的。

## 五、一句話

一份材料的可信度，不只看它引對了沒有，也看它**有沒有承認哪些話是自己說的**。
