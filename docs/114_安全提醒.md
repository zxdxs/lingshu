# 114 安全提醒：把『誰可以用』寫成不可繞過的一行

新增全站最高優先的提醒，措辭由你指定，我只補了後半句（不得代替就診、不得據以自行診斷／處方／用藥）：

> **本站內容僅供在有帶教資格的執業中醫師指導下使用；不得代替就診，不得據以自行診斷、處方或用藥。**

原文分兩句存：`安全提醒`（完整句）與 `安全提醒短`（頂欄用），都在 `data/發布資訊.json`。
和授權、聯絡一樣走單一來源，不另外硬寫。

## 1. 為什麼不是『寫在關於頁就好』

一份自學材料最危險的失敗模式，是讀者在**沒有指導者**的情況下，把書上的證候—治法直接套到自己或家人身上。
所以提醒不能只放在需要主動點開的頁面，必須**擋在入口、且每一頁都看得到**：

| 位置 | 形式 | 為什麼是這裡 |
|---|---|---|
| 頂欄 `#stripe` | 紅底一行，貼在 sticky header 下 | 每一頁都在視線內，關不掉、點不到「略過」 |
| 首次確認頁 | 紅框＋整句，按鈕文字也改 | 不按就不能進站；按鈕寫『我已了解，且在有帶教資格的執業中醫師指導下使用』，不是隨手可按的「我同意」 |
| 首頁 | 紅框，另加一句『不提供劑量、療程或操作步驟』 | 第一次進站看到的第一個區塊 |
| 限制頁 | 紅框置頂 | 這裡本來就在講不能做什麼，提醒與內容同一主題 |
| 關於頁 | 表格新增「安全」一列 | 要轉載、要引用的人會看這一頁 |
| 頁尾（靜態 HTML） | 粗體一行 | 即使 JS 沒跑、只看到原始 HTML 也看得到 |
| `<meta description>` | 附在描述尾 | 分享連結時預覽就看得到 |

## 2. 走出網站的四個出口也一併改

閱讀器不是唯一的出口，只改網頁等於只擋了一半：

- **Anki 牌組說明**（`export/anki模板/deck_description.txt`）：新增檔，`build_anki_deck.py` 會
  檢查它與 `安全提醒` 是否一致，不一致直接 `SystemExit`——不讓卡片帶著舊措辭流出去。
- **每張卡背面**：`.warn` 紅框，在『待專家核』說明之前。708 張卡都會印。
- **大樣稿**：封面、限制頁、封底各一個紅框（`.alert` 樣式，沿用閱讀器同一組顏色）。
- **README**：放在標題正下方、對外名稱之後，在任何目錄之前。
- **LICENSE.txt**：範圍說明第 3 條改成完整句——授權講『誰可以散布』，這裡講『誰可以使用』。

## 3. 讓它不會再被改弱

`check_all.py` 新增指標 **`安全提醒缺漏`**：掃 7 個出口（`data.js`、`index.html`、`大樣稿.html`、
卡片背面、牌組說明、README、LICENSE），任一份缺少核心句『在有帶教資格的執業中醫師指導下使用』就 +1。
現況 **0**。

`check_reader.js` 新增 safety 段：

- 頂欄文字必須**等於** `安全提醒短`（不是「包含」——頂欄被截短或改弱都要抓到）；
- 首次確認頁（另起一個未同意狀態的 context 跑）、首頁、限制頁、關於頁都必須含完整句；
- 確認頁按鈕文字必須含『帶教資格』。

負向測試（確認真的會紅）：把 `安全提醒` 改成『內容僅供參考。』→
`✗ safety 安全提醒本體沒有『帶教資格』`，`node` 退出碼 1；
還原後 `check_reader` 全過、`安全提醒缺漏` 回到 0。
注意：這條測試故意用『全域改弱』而非『刪掉某一頁』，因為前者才是真實的退化方式——
措辭被溫和化時，若只比對「有出現」是抓不到的。

## 4. 措辭邊界：我改了什麼、沒改什麼

- 你給的句子**原樣保留**在前半段，一個字沒動。
- 後半段『不得代替就診，不得據以自行診斷、處方或用藥』是補的，理由：原句管『使用場合』，
  沒管『拿去做什麼』；自學材料最常見的誤用正是後者。若你要刪成只留原句，改 `安全提醒` 一欄即可，
  七個出口與兩項檢查會一起跟著改（`check_reader` 只驗『帶教資格』四字，不驗後半句）。
- **沒有**加『本文可作為臨床參考』之類的軟化語，也沒有在案例題加『可照此辨證』的暗示。
