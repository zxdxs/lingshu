# 117 靈樞與素問的異同：能算的都算，算不出來的不寫

你要『靈樞與素問的異同加進去』。這件事有一條紅線：本站主體只有靈樞（見 `docs/1`、README 範圍），
素問只能當對照。所以做法不是『寫一篇兩書比較』，而是**把比較做成可驗證的量測**，再讓它只出現在一頁。

## 1. 先建一份乾淨的素問經文

`vendor/KR3e0001_素問` 是 SBCK 轉錄，正文與王冰注、林億新校正混排，注全在括號內，
另有卷首目錄、卷末篇名音釋、頁碼標記。不清乾淨就沒法算。

`scripts/build_suwen.py` 做四件事：去頁碼（`<pb:…>`）、去括號注、去卷首目錄行、去卷末音釋；
再以`X篇第N`的行切篇名。結果：

| 項目 | 結果 |
|---|---|
| 卷 | 24 |
| 篇名 | 77（今本 81：**刺法論第七十二亡**，第 26、46、50 篇的篇名行在這份轉錄裡缺） |
| 經文 | **78,396 字**（靈樞 65,085 字） |

缺篇名的那 3 篇，位置不硬猜，只記到卷——並寫進輸出的 `缺篇名` 欄，讓下游知道哪裡不完整。

## 2. 四種算法，四種證據

`scripts/compare_suwen.py` 產出 `data/素問對照.json`：

### ① 規模與篇名結構（直接計數）

素問 77 個篇名裡 **67 個以「論」結尾**（其餘是「篇」字前另有名目）；
靈樞 81 個篇名裡只有 **7 個**以「論」結尾。靈樞的篇名多為具體名目：九鍼十二原、本輸、骨度、脈度、五十營。
篇名本身就是兩種寫法的證據。

### ② 用字密度（每萬字）

異體先合併（鍼／針、剌／刺、脉／脈、隂／陰），否則差異會假性放大。差距最大的十項：

| 詞 | 靈樞 | 素問 | 讀法 |
|---|---|---|---|
| 鍼 | 39.8 | 13.6 | 三倍。靈樞是談操作的書 |
| 寫（瀉） | 22.7 | 2.2 | 十倍。補寫對舉是鍼法的語言 |
| 補 | 19.9 | 6.5 | 同上：靈樞講手法，素問講道理 |
| 血 | 58.6 | 38.8 | 血絡、營衛、血氣 |
| 人 | 80.3 | 52.9 | 從形體、腔隙、氣道講起 |
| 天 | 22.0 | 54.2 | 兩倍半。五運六氣是素問的主場 |
| 運氣 | 0 | 0.9 | **靈樞一次也沒有** |
| 五運 | 0 | 2.4 | 同上 |
| 病 | 82.8 | 121.0 | 素問談病更多，多在陰陽標本運氣的框架裡 |
| 寒／熱 | 39.0／39.8 | 72.8／69.5 | 素問的寒熱是氣化語言，靈樞的寒熱多與經脈、營衛綁在一起 |

這一段讓『靈樞重鍼刺、素問重氣化』從一句印象，變成可查的數字。

### ③ 重出句（逐字，≥8 字）

把靈樞 3,289 句逐句正規化後丟進素問經文裡找，完全相同的有 **9 句**：

- 靈樞〈九鍼十二原〉「知其要者，一言而終，不知其要，流散無窮」→ 素問卷 21〈六元正紀大論〉
- 靈樞〈根結〉「太陽為開，陽明為闔，少陽為樞」→ 素問卷 2〈陰陽離合論〉
- 靈樞〈病本〉四句（先病後逆、先寒後病、病發有餘、病發不足）→ 素問卷 18〈標本病傳論〉
- 靈樞〈九鍼論〉三句（形樂志苦／形苦志樂／形樂志樂）→ 素問卷 7〈血氣形志〉

只有 9 句，比多數人以為的少。兩書大量的是『同一個題目、兩套寫法』，不是逐字重出——
這一點值得說清楚，因為它正好說明為什麼不能拿素問的文字去補靈樞的洞。

### ④ 平行篇（四字串覆蓋率，雙向）

不靠印象配對，把 81×77 對篇兩兩算四字串覆蓋率：

| 靈樞 | 素問 | 覆蓋靈樞 | 覆蓋素問 | 共用四字串 |
|---|---|---|---|---|
| 病本 | 卷18〈標本病傳論〉 | **74%** | 23% | 115 |
| 九鍼論 | 卷7〈血氣形志〉 | 6% | **29%** | 95 |
| 九鍼論 | 卷7〈宣明五氣〉 | 4% | 13% | 57 |
| 歲露論 | 卷10〈瘧論〉 | 10% | 7% | 108 |
| 病傳 | 卷18〈標本病傳論〉 | 8% | 7% | 36 |
| 淫邪發夢 | 卷5〈脈要精微論〉 | 8% | 2% | 28 |

靈樞〈病本〉四分之三的文字見於素問〈標本病傳論〉；反過來素問〈血氣形志〉近三成見於靈樞〈九鍼論〉。
**誰抄誰，本站不判斷**——那是版本學與成書史的問題，`docs/117` 這一頁只提供量測。

## 3. 引文怎麼守

新增 `scripts/audit_cross_quotes.py`：一份語料表（靈樞／素問／類經），同一張異體字表，
逐條驗 `data/異同_敘述.json` 裡的引文是否真在所標來源。現況 2 條，不符 0。
`check_all.py` 增列指標 **`跨書引文不符`**，現在是 0。

名實那兩條取自《類經·類經名義》（張介賓）：

- 『兩經者曰靈樞曰素問，總曰內經』
- 『平素所講問是謂素問，神靈之樞要是謂靈樞』

第二條順帶解釋了書名，但我沒有把它當成內容定義——『樞要』二字是否概括全書，是讀者的判斷，不是我替他下的定義。

## 4. 頁面與入口

- 新增視圖 `#/suwen`（導覽「異同」，第 6 項）：名實 → 規模 → 用字 → 重出 → 平行篇 → 怎麼用 → 〔空〕沒做的事。
- 首頁多一張卡『靈樞與素問，差在哪』，把三個數字（鍼三倍、寫十倍、天兩倍半）先亮出來。
- 全頁開頭一段『先說立場』：素問不進題庫、不進通讀、不佔任何一篇的位置。

檢查：`check_reader` 增 `suwen` 路由與 `quote` 樣式類別（8 個視圖）；`smoke_browser` 增該路由，
導覽項數由 13 改 14，現為 17 條路由＋2 情境全通過。

## 5. 仍沒做的事（〔空〕）

- 逐篇對校：只算四字串覆蓋率，沒有做逐句異文的版本對照。
- 素問注家（王冰、林億新校正）未系統整理，本站只取經文。
- 運氣七篇沒有讀，也不假裝讀過；`運氣`／`五運` 的計數只是詞頻，不是理解。
- 兩書成書與篇卷分合屬版本學問題，本站不處理。

## 6. 重跑順序

```bash

python3 scripts/compare_suwen.py      # 四種算法 → data/素問對照.json
python3 scripts/audit_cross_quotes.py # 跨書引文
python3 scripts/build_reader.py && node scripts/check_reader.js
python3 scripts/smoke_browser.py
python3 scripts/check_all.py --write && python3 scripts/check_all.py
```
