## 二、抽取方法

這三篇的句式高度規律：**『證候描述，取之X』**。因此可用規則抽取，不需生成式模型：

```
切句（以。！？分） → 找第一個治法動詞 → 前為證、後為治
                   → 自「治」抽腧穴、經脈、治法類型
                   → 保留原句與字元位置
```

### 抽出的關係樣式

| 樣式 | 例 |
|---|---|
| 證 → 取穴 | 「厥心痛，腹脹胸滿，心尤痛甚，胃心痛也」→ 取之大都、太白 |
| 證 → 取經 | 「厥頭痛，面若腫起而煩心」→ 取之足陽明、太陰 |
| 證 → 針具＋部位 | 「熱病先膚痛，窒鼻充面」→ 取之皮，以第一鍼，五十九 |
| 證 → 放血 | 「厥頭痛，頭脉痛，心悲善泣，視頭動脉反盛者」→ 刺盡去血，後調足厥陰 |
| 證 → 禁忌 | 「心痛不可刺者，中有盛聚，不可取于腧」 |

## 四、抽取過程中的四類誤判（與修正）

| 誤判 | 例 | 修正 |
|---|---|---|
| 「不治」被當成治法 | 「嘔多沃沫，氣下泄，不治」 | 排除，改列預後 |
| 「取之處」被當成處置 | 「祭其所當取之處」 | 排除該匹配 |
| 比喻被當成處置 | 「痛如以錐鍼刺其心」 | 動詞前為「鍼／錐」則跳過 |
| 異名漏抓 | 底本「大抒」＝規範「大杼」 | 建異名表 |

**這四類都不是程式 bug，而是古籍語言的特性**：否定詞、虛指、比喻、異體字。任何要從古籍抽知識的方法，都必須先處理這四件事，否則圖譜會混進大量假關係。

---

## 五、回答那個問題：可行，但有邊界

**可行**：在句式規律的篇章（病證各論類，如《熱病》《厥病》《癲狂》《雜病》），規則抽取可以得到乾淨的證—治關係，且每一條都能回溯到原句。

**邊界**：

1. **只適用於『方證對應』型篇章。** 《經脈》《營衛生會》這類論述性篇章沒有「證—治」結構，抽不出來。
2. **「治」的粒度不齊。** 有的給穴名，有的給部位（「取之皮」），有的給針具（「以第四鍼」），有的給經脈（「取之足陽明」）。要做成可練習的配穴題，只有 11/34 夠明確。
3. **證候名稱不統一。** 「厥頭痛」「真頭痛」「頭半寒痛」是不同層級的概念，需要人工建層次，規則做不到。
