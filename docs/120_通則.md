# 120 通則：把散在八十一篇裡的規矩抽出來

你要的是『探賾索隱，鉤深致遠』——不是再講一遍內容，而是把靈樞**反覆在講的判準**抽出來。
網站在這一輪新增 `#/law`（導覽「通則」）：十六條、六組，每條掛句ID，可以回原文對。

## 1. 一條憑什麼算「通則」

判準寫在頁面上，也寫在腳本裡：**至少要有兩篇支持**。只在一篇出現的寫法，留在那一篇的模組裡，不升為通則。
所以十六條裡，每一條都至少掛兩段引文（少數一條，因為那句話本身就是全書總綱）。

## 2. 六組、十六條

| 組 | 條 |
|---|---|
| 一、結構：先量，再談氣 | 1 尺寸先行（骨度、脉度）／2 如環無端（經水） |
| 二、診斷：看得見的是標 | 3 司外揣內（外揣）／4 知一為工，知二為神（邪氣藏府病形）／5 粗守形，上守神（九鍼十二原、小鍼解） |
| 三、治則：方向與次序 | 6 虚則實之，滿則泄之（九鍼十二原）／7 在於知調陰與陽（根結）／8 標本先後（病本、九鍼十二原） |
| 四、時間：日與月 | 9 五十營：常數不失（五十營、順氣一日分為四時）／10 月滿月空（歲露論、陰陽繫日月） |
| 五、禁忌：過與不及 | 11 十二禁（終始、五禁）／12 中而不去，不中而去（寒熱病）／13 上工平氣（根結、九鍼十二原） |
| 六、傳承：技藝給誰 | 14 得其人乃傳（官能）／15 割臂歃血（禁服、終始）／16 著之玉版（玉版） |

每條四欄：**原則（歸）→ 引（原，句ID）→ 推演（歸）→ 用（歸）→ 界（空／歸）**。

## 3. 引文不可能漂移

`scripts/build_law.py` 只寫『原則／推演／用／界』與句ID，**引文由腳本從 `底本/靈樞經_句索引.json` 取出**。
所以引文與索引不可能不一致——打字錯誤在結構上就不存在。

腳本另做一道：敘述層的「」也當引文驗。第一次跑就抓出 **20 處**把自撰詞寫成「」的地方
（一晝夜五十周、病從外入、能力邊界、誰可以用…），全部改為『』。規則仍然只有一條：
**「」只給靈樞原文，其餘用『』。**

## 4. 幾條值得單獨說的

**『知一為工，知二為神』**（邪氣藏府病形）：靈樞把醫者分三等，標準是**命中率**——上工十全九、中工十全七、下工十全六。
它是我們『能力邊界』頁的古典依據：先說會錯多少，再說會什麼。

**「粗守形，上守神」**（九鍼十二原）：看起來玄，但〈小鍼解〉自己下了定義——**守的是血氣有餘不足、可補可寫**。
所以「守神」不是跳過形的藉口；原文先講持鍼、先講診脉。

**「中而不去則精泄，不中而去則致氣」**（寒熱病）：把技術定義成**時機判斷**，不是動作難度。
靈樞對「何時停」的著墨多過「如何進」——這一條改變我讀全書的方式。

**『月滿則血氣積，月郭空則氣血虛』**（歲露論）：用潮水解釋人體，是類比推理，原文沒給數據。
頁面照收，但標明『這是類比，不是可驗證的規律』。

## 5. 傳承：靈樞自己怎麼講這件事

這是你要的『傳承作者希望流傳下來的技藝』，原文講得比多數人以為的嚴肅：

- **〈官能〉**：「得其人乃傳，非其人勿言」；「各得其人，任之其能，故能明其事」。
- **〈禁服〉**：「此先師之所禁，坐私傳之也，割臂歃血之盟也。」——私下傳授是要治罪的。
- **〈終始〉**：「傳之後世，以血爲盟：敬之者昌，慢之者亡，無道行私，必得天殃。」
- **〈玉版〉**：「請著之玉版，以為重寶，傳之後世，以為刺禁，令民勿敢犯。」

四句合起來是一個態度：**知識可以傳，但必須在負責的關係裡傳，而且要寫下來、留給後世。**

本站照著做，方式是（頁面底部列了同一份）：

| 靈樞的規矩 | 本站的對應 |
|---|---|
| 得其人乃傳 | 每頁標『僅供在有帶教資格的執業中醫師指導下使用』 |
| 不私傳、要立約 | 授權 CC BY-NC-SA 4.0：可教可改，但同樣開放、不得商業使用 |
| 給對的人 | 給理解，不給劑量、療程、進針深度與手法步驟 |
| 著之玉版、傳之後世 | 每句掛句ID、每個判斷標來源、限制與矛盾公開列出 |

最後一項是這批材料真正的用途：不是替代師授，是把師授之前的功課做完。

## 6. 沒做的（〔空〕）

- 十六條沒有做成題目。它們是判準，硬出成填空會變成背句子；要不要出，等你判斷。
- 只抽了『反覆出現』的原則；單篇的獨特論述（如〈本神〉的神魂魄、〈癲狂〉的診法）留在各篇模組。
- 注家對這些原則的討論（張介賓《類經》多處呼應）尚未系統納入，只在異同頁用了兩條。
- 「用」欄寫的是閱讀提問，不是操作指引——這一界線是刻意的。
