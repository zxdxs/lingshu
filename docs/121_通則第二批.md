| 小鍼解 | 43 | 逐句解釋〈九鍼十二原〉，等於作者自己下定義 |
| 官鍼 | 26 | 十二節、五刺，每一節一個條件 |

## 3. 幾條真正撐起「精髓」的

**『六名一氣』**（〈決氣〉）：精、氣、津、液、血、脉不是六種東西，是同一股氣在六個階段的六個名字，
每個名字綁一個動作——宣、泄、注、變、壅遏。分得越細，越能說清『哪一步不順』。

**「兩虛相得，乃客其形」**（〈百病始生〉）：「風雨寒熱，不得虛，邪不能獨傷人」。
發病需要兩個條件同時成立。這是靈樞發病學的總公式，也是為什麼它談病第一句常是「虛」不是「邪」。

**『邪舍於不堅』**（〈五變〉）：同樣受邪，發病位置取決於哪裡本來就弱——把體質從『性格分類』
拉回『發病預測』。二十五人、五態人不是相術。

**『氣之在脉，三層分居』**（〈九鍼十二原〉＋〈小鍼解〉）：邪氣在上、濁氣在中、清氣在下。
這解釋了為什麼靈樞的刺法常先說『取之上／取之下』。

**「得其人弗教，是謂重失」**（〈陰陽二十五人〉）：傳也有責任——該教不教是失職，不該說而說是造孽。
這與〈官能〉的「非其人勿傳」互為兩面，正好是你說的「傳承」。

## 4. 閱讀路徑：六站

通則不是從第一條背到最後一條。頁面新增一張表，每站給：**讀哪幾篇（可點）、為什麼、對應哪幾條通則**。

1. **先立框架**：骨度、脉度、經水、經脉 → 通則 1–3
2. **認名目**：決氣、營衛生會、本輸、九鍼十二原 → 4–8
3. **學會看**：邪氣藏府病形、五色、論疾診尺、外揣 → 9–13
4. **看病怎麼走**：百病始生、五變、病傳、陰陽二十五人 → 14–17
5. **再學治**：官鍼、小鍼解、終始、五禁 → 18–29
6. **最後讀傳承**：禁服、官能、玉版 → 30–33

每條通則下方另有「回原文」連結，直接跳該篇。

## 5. 品質控制（跟上一輪同一套，沒有放寬）

- 引文一律由句索引取出，腳本不接受手打；68 段引文與 `底本/靈樞經_句索引.json` 逐字相符。
- 敘述層的「」也驗：這一輪抓出 **20 處**自撰詞誤用「」（津液不足、表裡、條件→動作…），改為『』。
- `check_reader`：14 視圖、9 條必要樣式類別。
- `smoke_browser`：16 條路由、全站內部連結全數有效、首次確認頁與作答互動。
- `check_all`：19 項指標與基準差異 0。
