# 126 病候：四組模板

新增 `#/binghou`（導覽「病候」，第 5 項）：把〈厥病〉〈周痹〉〈水脹〉四組病候並排。
不是要人記病名，是要看見這些篇章共用的寫法。

## 1. 模板：病名 → 其候 → 治法或死生

四組都照這個次序：

| 組 | 條數 | 寫法特徵 |
|---|---|---|
| 厥頭痛 | 7 | 同一病名，六種證候各配不同經——**辨位**的示範 |
| 厥心痛 | 6 | 以五藏命名（腎／胃／脾／肝／肺心痛）＋真心痛——**辨藏**的示範 |
| 衆痹與周痹 | 2 | 先分定義，再給刺法；衆痹「更發更止」，周痹『隨脉上下』 |
| 五種脹 | 5 | 水、膚脹、鼓脹、腸覃、石瘕，逐個「此其候也」 |

**並排才看得出來的事**：厥頭痛六條都用『取之某經』收尾，厥心痛六條都用『某心痛也』命名。
同一個模板，兩種辨法。

## 2. 靈樞把界限寫進病候裡

- 真頭痛：「頭痛甚，腦盡痛，手足寒至節，死不治」
- 真心痛：「手足凊至節，心痛甚，旦發夕死，夕發旦死」

這兩條不是治法，是界線。放在同一頁，是要讓讀者看見：**靈樞不迴避「治不了」**。
（這也回應通則第四條的爭議：詞頻上素問說「死」更多，但靈樞把「死」寫在病候的最後一格。）

## 3. 取捨要說清楚

只收四組，其餘（周痹之後的眾痹細節、腸覃石瘕的治法、厥病的耳聾耳鳴段）未收。
頁面自己寫明『不假裝收齊』——這是本站的規矩：沒做完的部分要看得見。

## 4. 抽取方式

與通則不同：這裡的**句ID 是編者挑的**（挑哪幾句代表一病，是判斷），
但**文句一律由句索引取出**（引文不可錯）。所以錯只可能錯在『挑得不好』，不可能錯在「抄錯字」。

`scripts/build_binghou.py` 若指定的句ID 不存在，直接 `SystemExit`。

## 5. 驗證

- 4 組 20 條，句ID 全部存在。
- `check_reader`：16 視圖、10 組樣式類別。
- `smoke_browser`：**23 條路由**全過、站內連結全數有效。
- `check_all`：19 項差異 0。

## 6. 還沒做

- 厥病後段的耳聾、耳鳴、蟲瘕（蛟蛕）未收。
- 五種脹的治法（「可刺邪」之後）未收。
- 痹證只取〈周痹〉，〈痹論〉在素問（不在本站主體），靈樞的〈周痹〉已足示範。
- 病候尚未連回題庫；若要出題，宜用『給證候、問辨位／辨藏』的形式。

## 7. 重跑

```bash
python3 scripts/build_binghou.py
python3 scripts/build_reader.py
node    scripts/check_reader.js
python3 scripts/smoke_browser.py
python3 scripts/check_all.py --write && python3 scripts/check_all.py
```
