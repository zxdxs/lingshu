# 129 專題二：五邪與五刺；病候頁補到六組

整理後的第二輪專題。兩個小題，都收在既有頁面裡，不加新導覽項。

## 1. 五邪（〈五邪〉）：邪在五藏

病候頁新增『邪在五藏』一組，五條：邪在肺、邪在肝、邪在脾胃、邪在腎、邪在心。
每條都是『先敘病候，再給取法』，與其他組同一個模板。

照原文有兩處要說清楚：

- **「邪左脾胃」**：底本此句作「左」，其餘四藏皆作「在」。頁面照錄，並在註裡寫明——不改字，
  也不假裝它跟別句一樣。
- **邪在心的取法最短**：「視有餘不足而調之其輸也」——沒有具體穴名。這不是漏抄，
  是原文就寫到這裡。

## 2. 五刺（〈官鍼〉）：以應五藏

九鍼頁新增第二張表。五刺的對應非常整齊：

| 刺 | 應 | 取 |
|---|---|---|
| 半刺 | 肺 | 淺內而疾發鍼，無鍼傷肉，如拔毛狀，取皮氣 |
| 豹文刺 | 心 | 左右前後鍼之，中脉為故，取經絡之血 |
| 關刺 | 肝 | 直刺左右，盡筋上，取筋痹，慎無出血 |
| 合谷刺 | 脾 | 左右雞足，鍼于分肉之間，取肌痹 |
| 輸刺 | 腎 | 直入直出，深內之至骨，取骨痹 |

**注意層次差別**：九鍼是『按工具分』（鑱員鍉鋒鈹員利毫長大），十二節是『按病位分』，
五刺是『按五藏所主之體分』（皮脉筋肌骨）。三者不是同一套分類，頁面並列但不相混。

## 3. 病候頁補到六組、32 條

新增兩組：

- **邪在五藏**（5 條）
- **耳目與雜病**（7 條）：耳聾無聞、耳鳴、耳痛不可刺、蟲瘕蛟蛕、足髀不可舉、病注下血、風痹淫濼。

耳目那一組有兩條值得注意：

- 「耳痛不可刺者，耳中有膿，若有乾耵聹」——**禁忌寫在病候裡**，這是靈樞的習慣。
- 「風痹淫濼…不出三年死也」——又一條界線句。
