# 132 界限分級：靈樞不只兩級

一直以來，本站把『靈樞很坦白』當成一句判斷（通則第四條還被詞頻頂回來）。這一輪把它變成可數的事實：
**靈樞談界限，用五種不同的說法，句數相差很大。**

## 1. 五級與句數（全 81 篇，字面收）

| 級 | 說法 | 句數 | 意思 |
|---|---|---|---|
| A | 死不治 | **12** | 斷定死。最硬的一級 |
| B | 不治／不可治 | **16** | 說「治不了」，但不说死 |
| D | 可令少愈，不可已 | **1** | 最細的一級：能緩解，不能除 |
| C | 不可刺／勿刺／無刺 | **22** | 操作禁忌：不是病不可治，是此刻不可動手 |
| E | 難已／易已 | **7** | 不是「不可」，是「難／易」——第三種說法 |

合 **58 句**。一句只歸一級（順序 A→B→D→C→E，D 最細所以先認），所以數字互斥、可相加。

## 2. 三個發現

**① 「不可刺」比「死不治」多。** 22 對 12。靈樞更常說的是『現在別動手』，不是「沒救了」。
這與通則第四條那樁爭議有關：如果「坦白」指肯說界線，那靈樞最常說的是**操作層的界線**，不是預後層的。

**② D 級只有一句。**「頭痛不可刺者，大痹為惡，日作者，可令少愈，不可已」。
全書就這一句用「少愈」來描述療效上限——它比「不治」精確得多，卻只出現一次。
這種稀少本身是資訊：**靈樞沒有發展出『帶病生存』這類中間狀態的詞彙系統**，只有零星一筆。

**③ E 級只有 7 句。**『難已／易已』這種以難易描述療效的說法，比想像中少。
靈樞更傾向用『死／不治／不可刺』這種斬釘截鐵的說法，而不是『比較難治』。

## 3. 方法是字面的，取捨是公開的

- 只用字面比對：**死不治／不治／不可治／可令少愈／不可已／不可刺／勿刺／無刺／難已／易已**。
- 排除三種非界限用法：「迷惑而不治」（講神志）、「未得其術」（講醫者）、「非其説也」（否定前說）。
- 順序有講究：24-9-1 同時含「不可刺」與「可令少愈」，若不先認 D，它會被歸進 C，最細的一級就消失了。
  第一版正是這樣漏掉的，改成 D 先認才對。

## 4. 頁面

`#/limits`（已知限制）新增一節『靈樞自己怎麼分界限』：五級表 + 句數 + 兩例。位置在紅色安全框之後、
本站 34 條能力邊界之前——先看原書怎麼說，再看我們自己的邊界。

頁面文案寫明：**本站的『能力邊界』是自己的；靈樞也有它的。** 兩者並列，不混為一談。

## 5. 驗證

## 6. 還沒做

- 只做字面，沒有處理『間接界限』（如「百日死」這類帶日數的預後）。
- 各級沒有細分到病類（例如 C 級 22 句中，針刺禁忌與誤治之禁混在一起）。
- 還沒有與本站『能力邊界 34 條』做對照——那是另一種界限（我們的無知），與靈樞的界限（病的不治）不同層。
