# 133 界限分級補一級：帶時限的預後

上一輪做了五級，漏掉一類：**『多久會死』**。靈樞不只說「死不治」，也說「一日半死」「百日死」「不出三年死」。
這一輪補成第六級 F，並發現一件更有意思的事。

## 1. 六級（現況）

| 級 | 說法 | 句數 |
|---|---|---|
| A | 死不治 | 12 |
| **F** | **帶時限的預後（日／年／歲）** | **27** |
| B | 不治 | 11 |
| D | 可令少愈，不可已 | 1 |
| C | 不可刺／勿刺／無刺 | 22 |
| E | 難已／易已 | 7 |
| | 合計 | **80** |

F 比 A 還多（27 對 12）：**靈樞說「多久」的次數，是說「死不治」的兩倍多。**

## 2. 時限單位：幾乎全是「日」

F 級 27 句的時限單位分布：

| 單位 | 句數 |
|---|---|
| 日 | **23** |
| 年 | 1 |
| 歲 | 1 |
| 旦夕（旦發夕死等） | 2 |

**靈樞的預後是短尺度的。** 年與歲各只有一句（「不出三年死」「十歲死」），
其餘全是「一日半死」「三日死」「七日死」「十日死」「百日死」這種以日計的判斷。

這與通則第二條（時間尺度：靈樞用一日、素問用一甲子）互相印證——
**連「死期」這個最嚴肅的預後，靈樞也用日計算。** 一日之內能驗的事，才寫得進這本書。

## 3. 排除規則

- F 的句式：數字＋日／年／歲，其後八字內出現「死」；或「旦發夕死」「夕發旦死」「旦占夕死」。
- **排除問句**：「七日而死，何也？」是在問為什麼，不是預後。排除『何也／何如／奈何／何以』。
- 順序：A→F→B→D→C→E。F 放在 B 前，因為「百日死」比「不治」更精確。

## 4. 頁面

限制頁那張表由五行變六行，並加一句時限單位分布——這句話比表格更能說明靈樞的性格。

## 5. 驗證

- 80 句、六級互斥；時限單位可加總為 27。
- `check_reader`：16 視圖；`smoke_browser`：25 條路由全過。
- `check_all`：19 項差異 0。

## 6. 還沒做

- 「百日死」這類與具體病位的對應（哪一癰疽百日死、哪一病三十日死）沒有整理成表。
- F 級裡〈病傳〉的日數推演（一日傳肺、三日傳肝…）與單純的預後混在一起，未分開。
- 沒有處理「死徴」這種間接說法（如「所謂勿刺者，有死徴也」）。
