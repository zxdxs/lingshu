站上一直只能在「通讀」搜篇名、「題庫」篩題型。要查一個詞落在哪裡，得自己一頁一頁翻。
這一輪補上 `#/search`（導覽「搜尋」，查核組）。

## 2. 異體與繁簡：不讓「查不到」變成『原文沒有』

這站吃過檢索偽陰性的虧（`docs/42` B5 條：以通行字查底本常查不到，而查不到看起來就像『原文沒有』）。
所以搜尋**兩邊都正規化**：

- 建索引時，每條另存一個 `n` 欄：用 `export/異體映射.json`（29 組、62 字）把異體字換成正字；
- 查詢時，把輸入字串用同一張表換一次；
- 比對『原文或 `n`』任一邊命中即算。

實際效果：搜「脈度」也能命中寫作「脉度」的篇；搜「鍼」與「針」互通。

## 3. 介面

- 一個輸入框，輸入即篩（不用按 Enter）。
- 結果按類分組，最多顯示 60 條，每條一個連結。
- 沒命中時給提示：『試試單一個字，或換用原文的寫法』。
- 可用 `#/search?q=厥` 直接帶查詢（分享連結用）。

## 4. 已知限制（照實寫）

- **只做子字串比對**，沒有斷詞、沒有同義詞、沒有拼音。搜「頭痛」找不到「頭重痛」，除非字面相鄰。
- **異體表只有 62 字**，覆蓋不了全部異體與繁簡差異；遇到查不到，先懷疑索引，不要下『原文沒有』的結論。
- 索引存的是**摘要不是全文**（篇 40 字、題 44 字），所以字面在後段的詞查不到。要全文搜尋得靠 `export/題庫_全.csv` 與底本檔。
- 沒有排序（相關度），只有分組與原順序。
