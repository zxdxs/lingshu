# 140 刺法線 6/6：行鍼、刺節真邪、上膈、逆順

上一輪立七條線，氣機線先滿。這一輪補 **L3 刺法線**（2／6 → 6／6），四篇各給一條通則。

## 1. 四條新通則

**膈分上下：一在氣，一在蟲**（〈上膈〉）
同是『食入復出』，靈樞拆成兩條路：上膈在氣（食飲入而還出），下膈在蟲（食晬時乃出）。
「膈」不是一個病名，是一組症狀的統稱；治法分兩途。

**鍼入而氣應有六形**（〈行鍼〉）
同一根鍼，不同人反應不同：神動而氣先鍼行、氣與鍼相逢、鍼出而氣獨行、數刺乃知、發鍼而氣逆、數刺病益劇。
**六種反應不是手法差異，是體質差異**（重陽之人、頗有陰者）。
所以『為什麼我扎了沒感覺』這個問題，靈樞的答案在病人身上，不在針上。

**五節：按「去什麼」命名**（〈刺節真邪〉）
振埃（去陽病）、發矇（去府病）、去爪（關節肢絡）、徹衣（諸陽竒輸）、解惑（調陰陽）。
五節與九變、十二節、五刺都不同：不按工具、不按病位、不按五體，而按**要解決的目標**命名。
現在刺法有四套清單可並列：工具（九鍼）／病位（十二節）／五體（五刺）／目的（五節）。

**刺其未生，不刺方盛**（〈逆順〉）
「上工刺其未生者也，其次刺其未盛者也，其次刺其已衰者也」；「無刺熇熇之熱，無刺漉漉之汗，
無刺渾渾之脉，無刺病與脉相逆者」。
「上工刺其未生」常被引成養生口號，其實是**時機分級**：未生＞未盛＞已衰＞方盛。太早與太晚都算失誤。
