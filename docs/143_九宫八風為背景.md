# 143 九宫八風：背景知識不必自證

你指出我上一輪的排除理由有問題：**『無法用《靈樞》內部的證據驗證』**。
這句話本身就錯了——如果拿它當標準，陰陽、五行、藏象、營衛的循環也都不該收，因為它們同樣不能『用內部證據驗證』。
背景知識的定義就是**不自證、只共用**。

所以這一輪不是補一條通則，是換一個處理方式：**不抽為通則，另立一頁說明背景。**

## 1. 為什麼『無法內部驗證』是錯的標準

|  | 能不能用靈樞內部證據驗證 | 本站怎麼處理 |
|---|---|---|
| 引文是否逐字 | 能（句索引比對） | 機器驗 |
| 某條原則是誰說的 | 能（標歸／原／注） | 標記 |
| 陰陽五行 | 不能 | 當背景，說明用法 |
| 九宫八風 | 不能 | **也該當背景** |

把『不能驗證』當成「不可收」，等於要求背景知識先證明自己——那不是嚴謹，是誤用標準。
真正的分界不是『能不能驗』，而是**『是格式還是指斷』**：

- **格式**（宫名、日數、方位、八風病位表）：要知道，否則讀不懂原文在引什麼。
- **推斷**（占君相吏將百姓、預測吉凶）：可以存疑，本站只照錄，不代推演。

所以「背景」不是擋箭牌，也不是垃圾桶；它是一個**分層後的收錄方式**。

## 3. 方法頁跟著改

原本寫『未採部分：太一移日、九宫值日、占君相吏將百姓』，讀起來像『這篇沒用』。
現在改為**『背景層：不抽通則，但有專頁』**，並寫明：

> 九宫與太一移日是秦漢式法與曆法，屬作者時代的背景知識，非待驗證命題；
> 八風的『內舍—外在—氣主』與三虛已採為通則（32–34 條）。
> **背景不必自證，但要能讓讀者讀懂作者在引什麼。**

## 4. 這一輪的收穫（給自己）

上一輪的教訓是『不要整篇判』，這一輪的教訓是**『不要用錯的標準判』**。
兩個錯誤疊在一起：先用「整篇」的粗度，再用『能不能驗證』的錯尺。結果把一篇有病因學、有病位表的文本踢出體系。

判一條材料該不該收，應該問三件事：

1. 它是不是**格式**（讀者必須知道才能讀懂）？→ 收，立頁說明。
2. 它是不是**斷言**（可以被檢驗或反駁）？→ 收，標證據等級。
3. 它是不是**推演**（依賴一套外部規則才能成立）？→ 收其結構，標明不代推演。

九宫八風三層都佔到了，所以三種處理並用，而不是一刀切。
