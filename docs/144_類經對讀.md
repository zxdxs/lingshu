# 144 注家對讀：61 條通則在《類經》裡找得到

九宫那兩輪之後，我想清楚一件事：**背景層與注家層是兩件事，但都屬於『作者/後人怎麼理解』**。
這一輪補注家層——不是寫我的解釋，而是機器去找：**通則的引文，張介賓有沒有收進《類經》？**

## 1. 結果：61／65 條對得上

| 指標 | 數 |
|---|---|
| 通則條數 | 65 |
| 至少一段引文見於《類經》 | **61** |
| 引文命中（140 段中） | **112** |
| 對讀不符（自檢） | 0 |

做法：把《類經》（四庫本，`KR3e0085`）32 卷逐卷正規化，再拿每條通則的引文去比對；
比對用同一張異體表（`check_quotes.norm`），所以「為／爲」「虛／虚」「麤／粗」都算同一字。

## 2. 頁面怎麼呈現

每條通則的「回原文」下方多一行：

> 《類經》亦收此段（卷 8、14）；張介賓按類編排，故只給卷號。

- **只給卷號**，不給篇名——《類經》是按類（攝生、陰陽、藏象、脈色、經絡、標本…）重編的，
  不存在與《靈樞》一一對應的篇序。硬給篇名會造假。
- 沒有對上的 4 條，就不顯示這行。**沒有就沒有。**

## 3. 這一層的意義與限制

**意義**：證明這些原則不是我從孤句抽出來的——張介賓在明代就把它們收進類書，且多半收在同一個類目。
這是一種『外部見證』，但不是『權威認證』：類經收了，只說明它被認為重要。

**限制**（照實寫）：

- 只比對『同一段文字』，不比對『同一解釋』。類經的注文（張介賓的解釋）**沒有**納入比對。
- 只給卷號，不能定位到類目；要精確，得人工整理類經的類目結構。
- 四庫本類經與通行本可能有異文，本站只驗四庫本。

## 4. 順手修掉的第三個異體缺漏

引「論不知三虛，工反為粗」時對不上，查出底本寫「工反為**麤**」——麤是粗的異體。
異體表原本沒有這一組，已補。

這已經是第三次因為異體字漏收而『假性失配』（前兩次：墊/墮、來/来與虛/虚）。
**每一次都是引文稽核抓出來的，不是讀出來的**——這說明那套表值得繼續養，而不是等到出事再補。

## 5. 驗證

- `check_all` 新增指標 **『類經對讀不符』**（現 0）：重驗每一條標了『類經亦收』的引文，
  是否真的在該卷找得到。這條指標防的是『標了但沒對上』的漂移。
- 指標總數由 19 增至 **20**；基準差異 0。
- `check_reader` 18 視圖；`smoke_browser` 26 路由＋3 情境。
