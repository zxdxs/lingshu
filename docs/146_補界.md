# 146 補「界」：20 條原本只有一句話的原則

上一輪把注家都上了帳（只登記、不引用），這一輪回到原本的規劃——**加厚既有內容**。
具體做的是通則裡最容易被忽略的欄位：**界**。

## 1. 為什麼先補「界」

每條通則有四欄：原則、引（原文）、推演、用、界。「界」寫的是**不能推到哪裡**。
它是這個專案最該做好、也最容易偷懶的一欄——因為寫『原文未給，本頁不代補』最快，但那句話等於沒說。

盤點結果：65 條的「界」平均 28 字，最短 11 字。有些確實只寫了半句。

## 2. 這一輪補了最短的 20 條

| 例 | 之前 | 之後 |
|---|---|---|
| 45 九變 | 『實際操作需師授。』 | 『只給九個名稱與一句定義，未給操作細節、劑量與療程；九變與十二節、五刺的關係原文沒交代，本頁不代為配對。』 |
| 14 衛氣為浮氣 | 『是功能描述，不是解剖分層。』 | 『『不循經』不等於衛氣沒有路徑——〈衛氣行〉另給了一晝夜五十周的路線；兩處要並讀，不可用一句否定另一句。』 |
| 2 如環無端 | 『環是模型，不是解剖圖。』 | 『『如』是比擬：環是模型，不是解剖圖；原文未說環上有幾個固定站點，七站路線是本站依〈病傳〉整理的。』 |
| 50 病位四層 | 『與解剖分層不同。』 | 『四層是原文的框架（藏府／筋骨皮膚），與現代解剖分層沒有對應；同一病位在別篇可能有不同分法，不可互換。』 |

其餘 16 條同理：把「需師授」「未給」這種話，換成**具體說清楚缺的是什麼、以及不能拿它去推什麼**。

平均由 28 字提高到 **35 字**，最短 25 字。

## 3. 兩個新增的防線

- `check_all` 新增指標 **『通則界過短』**：任何一條「界」少於 20 字就計數（現 0）。
  這防的是未來新增條目時又把界寫成口號。
- 生成器仍會驗『敘述層引文』；補寫時又抓到 2 處自撰詞誤用「」，已改『』。

指標總數 **21**。

## 4. 過程中犯的一個錯（寫下來）

第一次批次替換時，我用 `"',\n"` 當界字串的結尾，但「界」是每條最後一欄，實際結尾是 `"'},\n"`。
結果切掉了 16 條——65 條瞬間變 49 條。已 `git checkout` 還原後重做，這次先印出條數再繼續。

**這是典型的『正則對了、錨點錯了』**：規則本身沒錯，是對檔案結構的假設錯了。
以後批次改結構化原始碼，先確認條目邊界，再動。

## 5. 剩下的規劃（照舊）

1. **補題**：通則與題庫『引文重疊』為 0 的約 19 條，仍待各補 2–3 題。
2. **類經注文**：張介賓的注解仍未分離，暫不動。
3. **張志聰集註**：已登記，待『取全文→去注分經→抽樣校對』三步。
4. **變體研究**：同一原則在不同篇的寫法差異（如標本在〈病本〉〈寒熱〉〈終始〉）。

下一輪我打算做 1（補題），因為它直接影響讀者能不能練。
