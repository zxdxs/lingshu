# 147 補題：23 條通則從『沒有一題引到』到『至少一題』

上一輪補完「界」，這一輪做規劃裡的另一項：**通則與題庫的引文重疊為 0 的 23 條，各補題**。

## 1. 做法：不是手寫題，是從原文挖空

`scripts/add_items_law.py` 的規則：

- 題面 = `《靈樞·篇名》『引文，其中一段換成 ____』`；引文**逐字取自句索引**，不改字。
- 答案 = 被挖掉的那一段，必為原文子串（`答案類型：原文`）。
- 挖空段取『以逗號分段中最長的一段』，且該段在句內唯一、不含冒號與「曰」、不以『岐伯／黃帝』開頭。
- 少數條目自動挖空不理想，用 `OVERRIDE` 人工指定（第 35、39、45 條）。

產生 **37 題**填空，總題數 1031 → **1068**。

## 2. 結果：重疊為 0 的條數 23 → 0

| 指標 | 之前 | 之後 |
|---|---|---|
| 通則中『引文重疊 0』 | 23 條 | **0 條** |
| 重疊總數 | 202 | **238** |
| 題數 | 1031 | 1068（填空 708 → 745） |
| 答案原文 | 669 | **706** |

現在每一條通則都至少有一道題，題面引的是它的原文。這是「讀→練」第一次全通。

## 3. 三道稽核都過了

- 題面引文：856 段、**不符 0**（新題的引文全部是原句子串）。
- 答案：逐字未命中 39，全部是既有的 15 條整理語＋24 條推算（已標類型），**新題 0 未命中**。
- `check_all` 21 項差異 0；新題都帶 `句` 欄（977/1068 有句ID）。

## 4. 過程中修掉的三個問題

1. **同題面重複**：第 17 與 19 條都引了同一句（4-22-3），第 22 與 35 都引 47-2-3，產生 2 組重複題面。
   已按題面去重（drop 2 題），並在文件記錄。
2. **第 45 條兩題一模一樣**：第一版的 OVERRIDE 對『所有引文』套同一個挖空，害得兩題都是〈官鍼〉輸刺。
   改成『第幾段引文 → 挖空』的對應後，第二題改用〈官鍼〉巨刺，正常。
3. **第 39 條原本放棄**（句子太短，挖空後剩不到 6 字）。改為人工指定挖「調右手太陽上」，成功。

## 5. 誠實的邊界

- 這些題只考『這一段原文你記不記得』，不考理解。層級全標 L0、bloom=remember，沒有假裝成高階題。
- 挖空段是我（程式）挑的，不是作者挑的；換一個挖法，難度會不同。
- 有 2 條只剩 1 題（去重後），不是每條都湊到 2 題。
