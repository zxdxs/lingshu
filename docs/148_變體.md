# 148 變體：同一原則的多種寫法

規劃裡的最後一項：**同一原則在不同篇換了什麼說法**。新增 `#/variant`（導覽「變體」，讀原文組）。

| 組 | 篇數 | 換的是什麼 |
|---|---|---|
| 「上工」的五種定義 | 5 | 命中率／結果／時機／能力——四把尺，時機出現兩次 |

## 2. 幾個具體的發現

**「上工」不是一個人，是一個標準。** 五處沒有一處定義『上工是誰』，全都用『做到什麼』來指。
而且「時機」出現兩次（〈逆順〉刺其未生、〈官能〉救其萌芽）——這是最受重視的一把尺。

**「治其本」同一篇裡就有「治其標」。**〈病本〉先給先後（先病後逆者治其本），
接著給輕重（先病而後中滿者，**治其標**），再給虛實（病發而有餘，本而標之）。
所以『治病必求於本』不能讀成『一律先治本』——原文自己就給了例外的判準。

**體質分類四套彼此不對應。** 二十五人（五行五色）、五態（性情）、五音（聲音）、藏府二十五變（形態），
每套都自稱能分類；〈通天〉甚至明說五態「不與」二十五人之數。硬把兩套對應，會造出原文沒有的体系。

**衛氣四句不衝突，但回答不同問題。** 「不循經」講性質、「二十五度」講分配、「五十周」講總量、
『月滿月空』講月週期。併成一句『衛氣一日五十周』就會漏掉月週期。

## 4. 與通則頁的分工

- **通則**抽「共同點」：65 條原則，跨篇成立的規矩。
- **變體**排『不同寫法』：同一個詞，各篇用不同方式在量。

兩者合看，才不會把靈樞讀成一本前後一致的手冊——**它本來就不是**。

## 5. 後續補到七組（同日）

原本只做四組，接著補了三組：

| 新組 | 內容 |
|---|---|
| 死期的四種寫法 | 斷定式（死不治）／旦夕式（旦發夕死）／日數式（一日半死）／條件式（膿不寫則塞咽，半日死）／上限式（可令少愈，不可已） |
| 刺法的四套清單 | 按工具（九鍼）／按病位（十二節）／按五體（五刺）／按目的（五節）——四張不同的地圖 |
| 「度」與「周」 | 〈營衛生會〉用「度」說衛、用「周」說營；〈衛氣行〉一律用「周」。用詞不統一，數字對得上 |

**「上限式」值得單獨看**：全書只此一例（頭痛不可刺者……可令少愈，不可已）。四種死期寫法之外，
靈樞還留了一個『不談死、只談療效天花板』的說法。

**「度」與「周」**：讀者常把「二十五度」當成角度；在這兩篇裡它是「周」的同義詞（一遍身體）。
但別篇的「度」可能真的是度量——所以還是那句：先問這一段用哪把尺。
