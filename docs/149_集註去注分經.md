# 149 張志聰《靈樞集註》：去注分經

## 為什麼做這一件

前面記在帳上的注家有五家，其中只有張志聰《黃帝內經靈樞集註》確認有公版全文
（康熙壬子 1672 張隱庵序）。帳上寫的是：『需下載公版全文→去注分經→與底本逐字校→再談對讀；
本輪只登記，不引用』。這一輪就做前三步的前兩步：取全文、去注分經。

## 來源與取用

- 來源：殆知閣·醫藏《黃帝內經靈樞集註》
  `https://daizhige.org/醫藏/黄帝内经灵枢集注.html`
- 取用日期：2025-10-23；存 `vendor/張志聰_靈樞集註/raw.html` 與 `text.txt`。
- 排印：殆知閣為**簡體**排印，且只有句號（無逗號）。注文照錄簡體，不改字。
- 全書結構：序 + 九卷 + 八十一篇。篇題作『九针十二原第一』至『痈疽第八十一』，
  篇內每隔一段有『卷二经脉第十』之類的書眉（跑頁），已排除。

## 方法：機器比對去注分經

1. 以本項目底本 81 篇經文為基準，逐篇與集註該篇全文做 `difflib.SequenceMatcher` 序列比對。
2. 比對得上的字是「經文」，比對不上的殘餘是「注文」。
3. 殘餘落在某一句之後，就把該段注文繫到那一句（句 id 取 `底本/靈樞經_句索引.json`）。
4. 字形比對用『一字對一字』正規化（繁簡＋異體併字），並記住正規化位置→原字位置，
   所以節錄時取回的是原排印字，不是正規化字。

## 結果

| 項 | 數 |
|---|---|
| 篇 | 81／81 篇都對上 |
| 可比對經文 | 65,085 字（逐篇比對率 91.1%–98.7%） |
| 繫上句的注 | 772 條 |
| 注文總字 | 205,721 字 |
| 通則引文有張注可對 | 23 段引、20 條通則（共 65 條） |

注文集中在少數篇：〈經脉〉〈經筋〉〈癰疽〉〈論勇〉〈通天〉等逐段有注；
有些篇（如〈小鍼解〉）全篇只有一條注——這與集註『釋難不釋易』的體例相符。

## 三條防線（已進 `check_all`）

- `集註疑漏經文 = 0`：每條注文的 4-gram 覆蓋率若 >0.6，表示對不上而被誤判成注的其實是經文。
- `集註低比對篇 = 0`：比對率低於 90% 的篇。
- `集註有注句 = 772`：數字漂移即代表底本或來源變了。

## 局限（照實寫）

一、殆知閣為簡體排印，照錄未改字，故注文作簡體——與站上經文的繁體不一致，這是取捨，不是失誤。
二、去注分經是機器比對，注文切口可能留有零碎字（例如音釋括注的尾巴、下一句的起頭）。
三、只取節錄（每條至多 200 字），**未與影印本逐字校**；Internet Archive 的〈靈樞經（清）張志聰集注〉
影印本（`02092717.cn`）尚未調閱。
四、注文只代表張志聰，不代表原文，也不是本站的歸納；要判斷一條通則站不站得住，仍回原文逐字核。

## 站上呈現

新視圖 `#/jizhu`（後改題「注家」，與類經注同頁）：先列 20 條有張注的通則（原文「」→ 張注），再列
『八十一篇各取一條』（每篇字數最多的注），最後是逐篇注文分布表與局限。
`data/張注.json` 存全部 772 條節錄；`reader/assets/data.js` 只帶統計、81 條示例與通則對讀，
避免資料檔暴增（重建後 645 KB）。

## 判例

- **機器比對不等於校勘。** 772 條是『比對結果』，不是『張志聰注的正確文本』。
  站上因此只寫「節錄」與『未與影印本逐字校』，不寫『張注原文如此』。
- **入庫才可以引用。** 前一輪寫『只登記、不引用』，這一輪入庫後才在注家頁改狀態、才上對讀頁。
