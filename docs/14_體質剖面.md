# 體質剖面（D 型）

> 出處：《靈樞》通天第七十二、衛氣失常第五十九、逆順肥瘦第三十八、天年第五十四。
> 用法：先看「形態」與「性情」，猜是哪一型；再對照治則。

---

## 一、五態人（通天）

### 太陰之人

- **性情**：貪而不仁，下齊湛湛，好內而惡出，心和而不發，不務於時，動而後之
- **形態**：黮黮然黒色，念然下意，臨臨然長大，膕然未僂
- **治則**：多陰而無陽，其陰血濁，其衛氣濇，陰陽不和，緩筋而厚皮，不之疾寫，不能移之

### 少陰之人

- **性情**：小貪而賊心，見人有亡，常若有得，好傷好害，見人有榮，乃反愠怒，心疾而無恩
- **形態**：清然竊然，固以陰賊，立而躁嶮，行而似伏
- **治則**：多陰少陽，小胃而大腸，六府不調，其陽明脉小而太陽脉大，必審調之

### 太陽之人

- **性情**：居處于于，好言大事，無能而虚説，志發於四野，舉措不顧是非，為事如常自用，事雖敗而常無悔
- **形態**：軒軒儲儲，反身折膕
- **治則**：多陽而少陰，必謹調之，無脱其陰而寫其陽

### 少陽之人

- **性情**：諟諦好自貴，有小小官則髙自宜，好為外交而不內附
- **形態**：立則好仰，行則好摇，其兩臂兩肘則常出於背
- **治則**：多陽少陰，經小而絡大，血在中而氣外，實陰而虚陽

### 陰陽和平之人

- **性情**：居處安静，無為懼懼，無為欣欣，婉然從物，或與不争，與時變化，尊則謙謙，譚而不治，是謂至治
- **形態**：委委然，隨隨然，顒顒然，愉愉然，䁢䁢然，豆豆然，衆人皆曰君子
- **治則**：其陰陽之氣和，血脉調

| 型 | 一句話特徵 |
|---|---|
| 太陰之人 | 貪而不仁 |
| 少陰之人 | 小貪而賊心 |
| 太陽之人 | 居處于于 |
| 少陽之人 | 諟諦好自貴 |
| 陰陽和平之人 | 居處安静 |

> **注意**：五態講的是性情與形貌的**整體傾向**，不是道德評價。

## 二、膏、脂、肉（衛氣失常）

| 型 | 判別 | 形 | 氣血 | 寒温 |
|---|---|---|---|---|
| 膏人 | 膕內不堅，皮緩 | 縱腹垂腴，其肉淖 | 多氣，多氣者熱，熱者耐寒 | 粗理者身寒，細理者身熱 |
| 脂人 | 膕內堅，皮滿 | 其身收小，其肉堅 | 血清，氣滑少，故不能大 | 細理者熱，粗理者寒 |
| 肉人 | 皮內不相離 | 身體容大，上下容大 | 多血，則充形，充形則平 | — |

> 原書作「人有肥、有膏、有內」，歷代多讀「內」為「肉」，「肥」通「脂」。

## 三、肥瘦壯嬰與刺法（逆順肥瘦）

| 型 | 判別 | 血氣 | 刺法 |
|---|---|---|---|
| 肥人 | 皮薄，肩腋項肉薄，厚皮而黒色，脣臨臨然 | 其血黒以濁，其氣濇以遲 | 深而留之，多益其數 |
| 瘦人 | 皮薄色少，肉亷亷然，薄脣輕言 | 其血清氣滑，易脱於氣，易損於血 | 淺而疾之 |
| 常人 | 端正敦厚 | 血氣和調 | 無失常數 |
| 壯士真骨 | 堅肉緩節，監監然，此人重 | 重則氣濇血濁；勁則氣滑血清 | 重：深而留之，多益其數；勁：淺而疾之 |
| 嬰兒 | 其肉脆 | 血少氣弱 | 以豪刺，淺刺而疾發鍼，日再可也 |

## 四、生命週期（天年）

| 齡 | 描述 |
|---|---|
| 十歲 | 五藏始定，血氣已通，其氣在下，故好走 |
| 二十歲 | 血氣始盛，肌肉方長，故好趨 |
| 三十歲 | 五藏大定，肌肉堅固，血脉盛滿，故好步 |
| 四十歲 | 五藏六府十二經脉皆大盛以平定，腠理始踈，榮華頽落，髪頗斑白，平盛不摇，故好坐 |
| 五十歲 | 肝氣始衰，肝葉始薄，膽汁始滅，目始不明 |
| 六十歲 | 心氣始衰，苦憂悲，血氣懈惰，故好臥 |
| 七十歲 | 脾氣虚，皮膚枯 |
| 八十歲 | 肺氣衰，魄離，故言善悮 |
| 九十歲 | 腎氣焦，四藏經脉空虚 |
| 百歲 | 五藏皆虚，神氣皆去，形骸獨居而終矣 |

> 天年的重點不是『幾歲該怎樣』，而是**把衰老看成有階段的過程**：四十歲腠理始疏、五十歲肝氣始衰、六十歲心氣始衰……每階段有不同弱點。
