# 150 類經注分離：張介賓的解釋從括號裡出來

## 為什麼做這一件

《類經》三十二卷，張介賓把素問、靈樞打散重編，經文後面緊接小字解釋，錄文時解釋放在括號裡。
先前只做到『通則引文在類經哪一卷』（65 條中 61 條、112 段），注文本身一直沒動；
`data/注家.json` 的缺口欄寫的是『注文（張介賓解）在括號內，尚未分離』。

這一輪把注文分離出來，並用同一套『注繫到句』的辦法，讓通則引文能對到張介賓的解釋。

## 來源

- `vendor/KR3e0085_類經`（四庫全書本，Kanripo 錄文，48 個卷檔）。
- 底本特徵：`(……)` 為注，括號外為經文；`<pb:…>` 為原書頁碼、`¶` 為行末，皆剝離。
- 注文無標點（只有○分隔），照錄不改。

## 方法

1. 逐卷把括號內外分開：括號外＝經文流、括號內＝注段（連同它在經文流中的位置）。
2. 位置一律換算到『正規化後』的座標（與 `check_quotes.norm` 同一套異體表），
   否則經文裡的○與標點會讓位置整體偏移——第一版就是這樣把隔壁句的注拉過來的。
3. 用通則引文去經文流找位置 `p`，只取注段起點落在 `p+len−8 … p+len+12` 之間者：
   注繫在它所注的那一句之後，句末附近的注才是這一句的注。
4. 純書名／篇名旁注（『素問靈蘭秘典論全○一』之類）濾掉。

## 結果

| 項 | 數 |
|---|---|
| 分離出的注段 | 11,130 段 |
| 通則引文可對到注 | **71 段 / 50 條**（通則共 65 條） |
| 注段起點偏移超過 ±12 字者 | 不收 |

對照：張志聰集註可對 23 段 / 20 條。兩家合計，65 條通則中有 52 條至少有一家注可讀
（有重疊，張志聰有的張介賓多半也有）。

## 三條防線（已進 `check_all`）

- `類經注段 = 71`：數字漂移即代表來源或比對窗變了。
- `類經注引不符 = 0`：每段注的句 id 必須是通則引文之一、卷號必須在 1–32、注不得短於 12 字。

## 局限（照實寫）

一、類經按類編排，**沒有靈樞篇序**，所以只能給類經卷號，不能給『卷幾之幾』的細目。
二、注文無標點、無句讀，照錄；長注截 240 字，中間跳接以「…」標示。
三、只取句末 ±（−8,+12）字內的注——這是保守取法，寧可少收，也不把隔壁句的注當成這一句的。
四、注文只代表張介賓，不代表原文；他引素問的地方，本站未逐一核對素問原文。
五、四庫本與其他刻本可能有異文，未校。

## 站上呈現

`#/jizhu` 改為「注家」頁，分兩節：

- 一、張志聰《靈樞集註》（清）：772 條注繫句、20 條通則、81 篇各取一條、逐篇分布。
- 二、張介賓《類經》注（明）：50 條通則、71 段引文對讀，附類經卷號。
