# 151 類經注補「類名」，Anki 牌組重建

## 一、類經注從「卷」細到「卷＋類」

上一輪類經注只給卷號（例如『類經卷 8』）。但類經的體例是『卷之下分門類』，
每卷卷首寫『類經卷八　明　張介賓　撰』，下一行就是門類名（如「經絡類」「藏象類」「鍼刺類」）。
把那一行讀出來，注的定位就能細一層：`類經卷 8　經絡類`。

做法：先按行處理（書眉、`<pb:>`、`¶` 全部剝離），找到「類經卷X…撰」那行，取它後面第一行作類名；
再把類名從正文流裡移除，免得它被當成經文。

71 段注全部補上類名：鍼刺類 24、藏象類 14、疾病類 13、經絡類 10、脉色類 6、運氣 4。
注意「運氣」這一類在四庫本作「運氣」（無「類」字），照錄不改——不替它補字。

`check_all` 的 `類經注引不符` 現在也檢查類名不得為空。

## 二、Anki 牌組重建：708 → 745

`export/靈樞_填空.apkg` 是舊版（708 張），而題庫已到 1068 題、填空 745 道。
重跑 `scripts/build_anki_deck.py`，牌組重建為 **745 張**。

驗法（不靠 Anki 應用程式）：

- 解開 `.apkg`（就是 zip），取出 `collection.anki2`；
- 查 sqlite：`notes = 745`、`cards = 745`、牌組模型名『靈樞填空（可對答案）』；
- 抽查 note 欄位：`《靈樞·本輸》「肺出於____」｜少商｜肺之井穴`。

**這仍不是『Anki 實機』**：沒在 Anki 應用程式裡匯入、沒按過一次。
`data/發布資訊.json` 的 `Anki實機` 仍是「未測」，但說明改成『牌組已重建並驗過 collection（745 notes／745 cards）』，
免得下一個人以為還是舊的 708 張。

## 記在帳上

1. 類經的「篇題」也能抓（例如「十二官」「本神」『天年常度』），但機器抓法會把
   經文片段誤認成篇題（首版就抓到『帝曰善脾不主時』），所以這輪只到「類」，不到「篇」。
   要做，得先立更嚴的判定（篇題後緊接「(素問…○N)」形式的出處注），並抽樣驗。
2. 太素（楊上善注）仍經注混排。它的錄文沒有任何標記，只能靠『與素問／靈樞經文比對』來分割；
   分錯就會把注當成原文，風險比類經高一個量級。要做，得先寫出可驗收的比對法，再談上站。
