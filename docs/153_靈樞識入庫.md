# 153 靈樞識：第三家注（日本江戶）

## 為什麼收這一本

帳上五家注，馬蒔《靈樞注證發微》一直訪不到可靠的公版全文；但日本江戶時代丹波元簡的
《靈樞識》在殆知閣有全文。這本書的體例特殊：

> 以經文短句立條；條下先轉引馬蒔（马云）、張介賓（张云）、張志聰（志云）之說，再下己見（簡案）。

所以收它一舉兩得：一是丹波自己的考證，二是**間接看到馬蒔**——但只能算轉引。

## 來源與體例

- 殆知閣·醫藏《靈樞識》（『日 丹波元珍』，即丹波元簡），2025-10-23 抓取。
- 存 `vendor/丹波元簡_靈樞識/raw.html`。
- 六卷、81 篇；每篇以『卷N／篇名第N』的書眉分段，內文 3,641 條。
- 條目與注之間以空格分隔（殆知閣排印保留了這個分隔），這是本輪能機械分條的關鍵。

## 方法

1. 切篇：以『篇名第N』定篇序（81 篇都對上）。
2. 切條：以每段第一個空格前的短句作『條目』（經文），其後為注。
3. 條目可能由數截短句組成（如『营气之道 内谷为宝』），由長到短試併，取能在底本該篇
   經文流中找到的那一個——第一版只取第一截，結果『营气之道』對到別處，注被切錯。
4. 條目在經文流的位置換算成句 id；通則引文取『引文範圍內』的條目注。

## 結果

| 項 | 數 |
|---|---|
| 條目 | 3,641 |
| 對回底本句 | **1,403（約 39%）** |
| 通則引文可對注 | **59 段 / 42 條**（通則 65 條） |
| 有條目能繫上的篇 | 77／81 |

繫上率不高的原因：靈樞識不是每句都立條（立條者多為疑難句），且條目字形與底本有異；
低繫上的篇如〈熱病〉89 條繫 11、〈雜病〉49 條繫 4、〈論勇〉17 條繫 1。

## 三條防線（已進 `check_all`）

- `靈樞識繫上 = 1403`：數字漂移即代表來源或切條法變了。
- `靈樞識引不符 = 0`：引句 id 須在通則、注不得為空（此書多為短校記，故不設長度下限）。

## 局限（照實寫）

一、**『马云』『张云』『志云』是轉引**，不是本站直引馬蒔、張介賓、張志聰原書；
頁面與資料都標了『轉引』。要直引馬蒔，仍需原書。
二、條目以短句立目，未立條之句在本站沒有靈樞識可對，不代表丹波沒有意見。
三、39% 繫上率＝機器可對上的比例，不是他注釋的覆蓋率。
四、未與影印本或日本刻本對校；殆知閣錄文可能有誤字。
