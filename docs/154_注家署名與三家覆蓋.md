# 154 注家署名細分與三家覆蓋

## 一、《靈樞識》的注再切一層

上一輪把《靈樞識》整段當「一條注」放上站。但它的注其實是**一疊聲音**：
「马云。」「张云。」「志云。」「简案、」——那是四個人在說話，其中三個是被轉引的。

這一輪按標記把每段注切成小段，各自署名：

| 署名 | 含義 | 出現次數（59 段節錄中） |
|---|---|---|
| 馬蒔（轉引） | 靈樞識引馬蒔《注證發微》 | 25 |
| 張介賓（轉引） | 引《類經》注 | 43 |
| 張志聰（轉引） | 引《靈樞集註》 | 13 |
| 甲乙經 | 校勘時引甲乙經異文 | 19 |
| 丹波元簡 | 簡案，他自己的考證 | 13 |
| 版本校 | 「张本」「志本」等版本異文 | 1 |
| 未署名 | 段首引他書（如潘氏《醫燈續焰》）未帶標記 | 5 |

切法：以標記為切點，標記前的文字歸前一段（無標記則記「未署名」）。段首的「马云。」等字樣照錄不刪，
因為它是原書的標示方式，刪了反而看不出轉引。

## 二、三家覆蓋：65 條通則裡，有幾條真的有注可讀

把三家的資料對起來算：同一條通則，張志聰《集註》、張介賓《類經》注、丹波元簡《靈樞識》各有沒有注能繫上。

| 有注的家數 | 條數 |
|---|---|
| 三家都有 | **11** |
| 兩家 | **32** |
| 只有一家 | **15** |
| 三家都沒有 | **7** |
| 合計有注 | **58／65** |

三家都沒有的 7 條，多半是通則引文落在注家不立條、或注文與引文相距太遠的地方。
這 7 條不是「沒有注」，是『本方法取不到注』——差別寫在頁面上。

## 站上呈現

`#/jizhu`（注家）：

- 靈樞識一節改為逐段署名（家名以標籤顯示），一句引文下可能有二三段不同人的話。
- 新增『三家覆蓋』表：每條通則標出哪幾家有注，頁首給分佈數字。

## 防線

- `注家有注條 = 58`、`三家皆無 = 7`（兩者相加須為 65，`check_all` 兩個數字都在）。
- `靈樞識引不符 = 0`。

## 局限

一、轉引就是轉引：馬蒔、張介賓、張志聰的話經靈樞識轉手，可能節刪，不能當原書引用。
二、只切 59 段節錄（通則引文可對到的部分），未對全書 1,321 條逐條署名。
三、未署名段（5 處）可能是丹波自己引他書，也可能是原文脫標記——不硬判，記「未署名」。
