# 156 甲乙經逐條對應：句 → 條，差異只列不判

## 做的是哪一步

上一輪只做到『篇次落點』（靈樞某篇 → 甲乙經某篇，4-gram 重合）。這一輪往下走一層：
**靈樞的每一句，去甲乙經找最相近的一條**，並把文字差異列出來。

不做的事先講清楚：不判是非（誰對誰錯），也不宣稱這就是甲乙經作者的自注出處。

## 方法

1. 甲乙經按句末標點（。！？）切成 **5,316 條**，每條記卷、篇。
2. 靈樞 3,289 句，長度 ≥10（併字後）者 2,592 句可比。
3. 用 6-gram 倒排索引取候選條（上限 150 條），再以 `difflib` 相似度取最佳。
4. **相似度 ≥0.85 才收**；併字後完全相同者記「同文」，其餘記「近似」。
5. 差異用 opcode 切段列出；字形／通假類（府／腑、大／太、著／着、鬲／膈、踈／疏、抟／搏、悗／闷、閇／闭、浓／厚、跷／𫏋、已／以、亦／也）**另計**，不進差異表。

## 結果

| 項 | 數 |
|---|---|
| 可比句 | 2,592 |
| 對上（≥0.85） | **927** |
| 其中同文 | 142 |
| 其中近似 | 785 |
| 字形／通假類差異段 | 71 |
| 全站引用句有對應 | **130／336** |

範例（近似，差異照列）：

- 靈樞「能參合而行之者，可以為上工，上工十全九…」／甲乙「…可以为上工，十全其九；行二者为中工，十全其七…」→ 差異：甲有「上工」乙無、乙有「其」甲無。
- 靈樞「取之委陽者，屈伸而索之」／甲乙『委阳者，屈伸而取之』→ 甲「索」／乙「取」。
- 靈樞「小腹尤堅」／甲乙『少腹尤甚坚』→ 甲「小」／乙「少」、乙多「甚」。

## 站上呈現

標明『差異未判定』，並註明字形／通假類已另計。

## 防線

- `甲乙經條對應 = 927`、`甲乙經條不符 = 0`：句 id 須在句索引、卷號 1–12、相似度 ≥0.85、兩邊文非空。

## 局限（照實寫）

一、相似度 ≥0.85 是門檻，不是正確率；0.85–0.9 的對應可能是『同一段的不同改寫』，也可能是錯配。
二、字數差很大的句子（甲乙刪節或合併）不會被收，故 927 不是『甲乙經收了 927 句』，而是『能穩定對上 927 句』。
三、字形／通假的分類是**編者判定**（見上列 12 組），不是客觀標準；其餘差異未分類。
四、甲乙經本文含後人夾注，未分離，因此少數「差異」其實是夾注混入。
五、未與宋刻、明刊影印本對校。
