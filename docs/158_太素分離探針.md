# 158 太素經注分離：先驗方法，不先產資料

## 為什麼先驗

太素是現存最早的靈樞注（隋·楊上善），價值最高，風險也最高：
它的錄文**沒有任何經／注標記**，經文與注連排。若分錯，就會把楊上善的話當成《靈樞》原文貼上站——
那比「沒有注」嚴重得多。所以這一輪只做一件事：**證明這條路可不可走**，不產站上資料。

## 方法

太素的經文來自素問與靈樞，所以：

> 能在底本裡找到的字 → 經文候選；找不到的連續片段 → 注候選。

具體做法（`scripts/probe_taisu.py`）：

1. 底本語料：素問 24 卷文本 ＋ 靈樞 81 篇，全部用『繁簡＋異體併字』正規化。
2. 建 8-gram 集合。
3. 太素逐卷、逐字標記：從該位置起的 8-gram 是否見於語料。
4. 連續覆蓋 ≥8 字 → 經文段；其餘 → 注候選。長度 ≤2 字的洞併回經文（異文造成）。
5. 三道檢查：
   - **經文密度**：抽出的經文段中，4-gram 見於底本的比例（越高越可信）。
   - **注密度**：注候選段中，4-gram 見於底本的比例（越低越乾淨；這也就是『漏抽經文』的比例上限）。
   - **回對底本**：抽出的經文能覆蓋某一底本篇多少（recall）。

## 抽樣看切口（機器切出來的注段）

以下三段是『未覆蓋段』的原文（節錄），看得出是楊注與蕭延平校記，不是《靈樞》原文：

```

云氣人有衛氣地有草蔖千古反草名也又死草也平按雲氣原抄云字下半不全只餘上半雨字按素問陰陽應象大論云地氣上為云
幕當為膜亦幕覆也膜筋十二經筋及十二筋之外裹膜分肉者名膜筋也人身上有二十六形應天地之形也
```

## 判定：可以走，但要設三道閘

1. **注密度 ≤0.15** 才收：整體 0.07，個別段落若經文味太重，寧可不要。
2. **切掉平按**：蕭延平校記不是楊注，必須分開（2,975 處）。
3. **切掉書眉與篇題**：卷題、類目（如「陰陽合」）混在段首，要先移除。

預期可用的注：約 26 萬字的注候選，扣掉平按與書眉後，仍是目前最大的一家注。
