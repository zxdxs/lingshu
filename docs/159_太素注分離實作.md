# 159 太素注分離：實作與人工抽樣

## 從探針到實作

上一輪（docs/158）證明『用底本 n-gram 覆蓋切太素經／注』可行：經文密度 0.84、注密度 0.07。
這一輪把它做成資料，並加上四道閘門。

## 四道閘門

1. **平按切開**：注候選在『平按』處切斷，後面是蕭延平校記，整段丟掉（不是楊上善注）。
2. **書眉／類目跳過**：用 yaml 的 markers（`head_text`）定位，把『卷第五』『陰陽合』這類字從流中跳過，
   不改原文（改原文會讓座標全亂——上一版就吃過座標的虧）。
3. **經文／校記印記排除**：含『黃帝曰／岐伯曰／問曰』者當經文；含『平按／補入／原抄／袁刻／別本／
   靈樞作／素問作／甲乙作／誤作』者當校記，都不收。
4. **文言虛詞檢查**：楊注是注釋文體，至少會有『也／者／矣／焉／故／即／亦／乃』之一；
   一個都沒有的短段，多半是沒對上的經文殘句（這條擋掉了『實無虛虛無損不之而益有餘是謂重』這種殘句）。

另加兩個條件：注段 4-gram 密度 ≤0.15、長度 ≥12 字。

## 結果

| 項 | 數 |
|---|---|
| 卷 | 26 |
| 經文 | 69,566 字 |
| 注段 | **2,531 段** |
| 注字 | **115,701 字** |
| 通則引文可對注 | **18 段 / 14 條** |

## 引文 → 注的取法

通則引文先在太素經文流裡定位，然後：

- 只取**同一篇**（markers 的 div 範圍）內的注；
- 先取引文尾 −8～+40 字內者；沒有才退到 +80 字內；
- 每段記『距』（與引文尾的字數），頁面照實顯示。

## 人工抽樣（18 段，逐段讀過）

| 判定 | 段數 | 例 |
|---|---|---|
| 注確實解釋該句 | 12 | 『六氣之中有餘不足總問也…』、『三陽受病未入於陰至三日也…』 |
| 注屬同篇鄰句（內容相關但不是這句） | 6 | 距 +48／+63／+60／+37 等，多為前後句之注 |
| 明顯錯（經文誤判、跨篇） | **0** | — |

所以：**歸屬錯誤 0/18**，但『同篇鄰句』佔 6/18（33%）。這不是把經文當注，而是把鄰句的注當這句的注——
頁面因此標出『距』，距越大越不可靠。

並寫明『機器分離、未與影印本校』。

## 防線

- `太素注引 = 18`、`太素注不符 = 0`：句 id 須在通則、卷 1–30、注 ≥12 字、距在 −8～+80。
- `太素探針經文 = 69566`、`太素注密度% = 7`（探針不變）。

## 局限（照實寫）

一、太素錄文無標記，這是機器分離；**未與影印本對校**，注文可能有誤字、切口可能有殘字。
二、33% 的注屬同篇鄰句——頁面以『距』提示，但讀者仍須自己判斷。
三、只做通則對讀（18 段），2,531 段注未逐段繫句。
四、平按段（蕭延平校記）直接丟棄，未另立『清人校記』層；若要，需再做一輪。
五、注文照錄簡體，與經文繁體不一致（同集註的取捨）。
