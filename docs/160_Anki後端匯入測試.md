# 160 Anki 後端匯入測試：745 卡真的進得去

## 之前卡在哪

`發布待決` 一直是 1（Anki 實機未測）。先前的驗法是『解開 .apkg 這個 zip，看 collection.anki2 裡的 notes／cards』——
那是**自己讀檔**，不是 Anki 自己讀檔。所以一直不敢把這一欄改掉。

## 這次怎麼驗

1. 用 `pip install anki` 裝 Anki 官方後端（26.9.3，不是自己寫的解析器）。
2. 用 `anki.collection.Collection.import_anki_package()` 走**Anki 自己的匯入流程**。
3. 用 `Card.question()`／`Card.answer()` 走**Anki 自己的卡片渲染**。
4. 檢查：note 數、card 數、牌組名、卡型名、模板、欄位、前三張卡的文字、答案頁是否含安全提醒。

寫成 `scripts/verify_anki.py`，可重跑：

```
pip install anki
python3 scripts/verify_anki.py
```

## 局限（照實寫）

一、這是**後端**測試，不是 GUI 測試：版面、字型、夜間模式、點擊『顯示答案』的實際體驗，仍未驗。
二、Anki 後端版本（26.9.3）與本機 Anki.app（2.1.47）不同版本；`.apkg` 向後相容，但舊版 Anki 開啟新版匯出的牌組可能有差異（未測）。
三、只渲染前三張卡；全 745 張未逐張目視。
四、`anki` 套件不進 `vendor/`（檔案大），需另裝；`scripts/verify_anki.py` 沒裝時會直接失敗，不會假裝通過。
