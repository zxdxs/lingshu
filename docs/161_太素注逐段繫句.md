# 161 太素注逐段繫句：2,531 段各歸哪一句

## 上一輪只做了 18 段

docs/159 只把『通則引文可對到的』18 段注繫上句子。其餘 2,513 段注沒有索引，
在站上等於不存在。這一輪補齊：**2,531 段全部嘗試繫句**。

## 方法

1. 每段注取『它前面那一段經文』的尾巴 40 字（注緊接在該段經文之後）。
2. 以 4-gram 找候選句：
   - 靈樞：候選是 3,289 句，直接算 difflib 相似度；
   - 素問：卷太長（3,000 字以上），直接比會趨近 0，所以用『位置索引』取視窗（長度＝尾巴長度）再算。
3. 相似度 **≥0.7** 才算繫上；記錄「比」（相似度）與「距」（注起點與句末字數）。

## 防線

- `太素索引段 = 2531`、`太素索引不符 = 0`：屬只能是靈樞／素問／未繫；靈樞者句 id 須存在；
  素問者須以「素問卷」開頭；比 0–1、注 ≥12 字。
- `太素注引 = 18`、`太素注不符 = 0`（通則對讀）不變。

## 局限（照實寫）

一、29% 未繫：太素有些經文不在素問／靈樞底本內（缺卷、佚文、異文過大），硬繫會造假，所以留空。
二、相似度 ≥0.7 是門檻，不是正確率；抽樣看到『同篇鄰句』型的誤繫，故頁面同時顯示「比」。
三、素問只記到「卷」，沒有篇（素問底本 24 卷、77 篇，但太素對應的篇次未建立）。
四、注文仍是機器分離，未與影印本校。
