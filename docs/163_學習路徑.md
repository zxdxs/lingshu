# 163 學習路徑：先讀哪一篇

## 為什麼做這件事

81 篇、3,289 句、1,068 題，但站上原本只有三個入口（主題、通則、題庫）。第一次來的人會問：
**『我該從哪一篇開始？』**這一直是自學者最缺、而站上沒有的東西。

## 三條路線

### 一、七日入門：一天一條任務線

用既有的七條任務線（L1 病因發病、L2 診法、L3 刺法、L4 病候、L5 體質、L6 氣機、L7 傳承方法）當七天。
每天讀該線的 4–6 篇，驗收寫成一句『口頭說得出』的話，例如第 3 天：

> 能依『病位／工具／目的』各舉一種刺法，並說出『中而不去』的忌。

### 二、臨證取徑：從證候退回去

依看病順序：先認證候 → 再定刺法 → 查禁忌 → 看傳承。
給已有基礎的人複習：不是重讀一遍，而是把『看到證候時，腦中該依序問什麼』跑一次。

### 三、主題速覽：五個入口

只有一小時的人：身體、氣血、病從外入、表現、判斷，各給一句驗收。

## 進度怎麼算（不手填）

閱讀器本機有兩種紀錄：`STATE.read`（哪些篇標了已讀）與 `STATE.log`（哪些題答過）。
每一步顯示『已讀 x/y、答題 a/b』，**完成**的門檻是：

> 讀過該步八成篇、且答過該步一半題。

這是刻意設高的：「看過」不算完成。換裝置不會帶走紀錄（本站不連網）。

## 站上呈現

新視圖 `#/path`（導覽「路徑」），三張路線卡，每步一列：步名／要讀哪幾篇（可點）／進度／驗收。
每張卡下方給整條線的完成步數與答題總數。

## 防線

- `路徑數 = 3`、`路徑步數 = 16`、`路徑不符 = 0`（篇序須在 1–81、每步要有名稱與驗收）。
- `check_reader` 增加 `/path` 視圖；`smoke_browser` 增加 path 路由、導覽連結數 19 → 20。

## 局限（照實寫）

一、這是**編者的次序**（歸），不是原書次序，也不是任何流派的教学次第；換一位老師排法會不同。
二、步驟時間（30–40 分鐘、1–2 小時）是粗估，沒有實測。
三、驗收句是「說得出」，本站無法自動判定；進度只反映『讀過／答過』，不反映「懂」。
四、主題速覽那條線沒有逐篇連結，只有主題頁入口。
