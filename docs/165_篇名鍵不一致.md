# 165 一個鍵的錯：9 篇在 `靈樞識` 統計裡消失

## 怎麼發現的

這一輪本來要補『32 篇沒有模組』。列出待補清單時想看〈經别〉的句子，發現 `底本/靈樞經_句索引.json` 裡
**〈經别〉一句都沒有**。查下去：句索引的 `pian` 用的是『規範篇名』（經別），底本的 `篇名` 用的是
刻本的異體（經别）。同一個字，兩個寫法，join 就斷了。

受影響的 9 篇：

| 底本篇名 | 句索引鍵 |
|---|---|
| 經别 | 經別 |
| 營衛生㑹 | 營衛生會 |
| 周痺 | 周痹 |
| 决氣 | 決氣 |
| 平人絶榖 | 平人絕穀 |
| 五癃津液别 | 五癃津液別 |
| 隂陽清濁 | 陰陽清濁 |
| 隂陽繫日月 | 陰陽繫日月 |
| 隂陽二十五人 | 陰陽二十五人 |

## 影響了什麼

《靈樞識》的建置腳本用『底本篇名』去句索引撈句子，於是這 9 篇的條目**整批繫不上**，統計被低估。
修正（改用 `篇名_規範`）前後：

| 項 | 修正前 | 修正後 |
|---|---|---|
| 有條目的篇 | 68 | **76** |
| 條目 | 3,357 | **3,641** |
| 繫上底本句 | 1,321 | **1,369** |
| 馬蒔轉引 | 539 | **569** |

其他摘要（張介賓 749→775、甲乙經 341→354、丹波簡案 217→221、張志聰 188→195）也一併更新。

## 修法

1. `scripts/build_lingshushi.py` 改用 `篇名_規範` 當鍵。
2. `check_all` 的 `馬蒔轉引不符` 接受兩種寫法（否則修正後反而 30 條「不符」）。
3. 新增指標 `篇名鍵不一致 = 9`：把這 9 篇固定下來，數字一變就紅——避免下次又有人按錯鍵。

## 教訓

- **異體字不能當 join 鍵**。這本書的刻本用字（别、㑹、决、絶、榖、隂）與專案自己的規範字不同，
  任何跨檔案的 join 都要先問『用哪個鍵』。
- 這類錯不會報錯、不會缺檔，只會讓統計**安靜地少一截**。所以要有『鍵不一致』這種數字釘住。
