# 166 D 型模組：第一批六篇

## 為什麼

81 篇裡有 32 篇沒有專屬模組（模組＝把一篇的骨架抽成一頁可複習的結構）。
先前只靠通則、病候、題目撐，讀者讀完一篇沒有一個『回頭看這篇在講什麼』的東西。

## 做法：原文不手打

`scripts/build_module_d1.py` 把內容寫成『句 id ＋ 解』，**原文由句索引按 id 取出**，
並斷言『這個 id 屬於這一篇』。這樣：

- 引文不可能與底本不一致（`check_all` 的 `模組原文不符` 會再核一次）；
- 句子若因改版換了 id，腳本會直接失敗，不會靜默留錯。

每篇給：一句（歸納）、分層（3–4 層，每層＝一個句 id ＋ 一句解）、原文要點（2–3 句）、
誤讀（最容易被讀錯的地方）、相連通則（自動比對通則引文句）。

## 誤讀欄的幾個例子

- 經水：把「刺深六分」當成所有人的標準——原文自己說那是「取其中度」。
- 脉度：把「關格」當一個病名——原文先分關、格，再合稱。
- 外揣：把「司外揣內」當成猜病的執照——原文前提是「不失其形」。
- 背腧：把『按之痛解』當手法——原文是「欲得而驗之」，取穴驗證用。
- 衛氣：把本標當氣走路線——它們是上下兩端的取穴處。
- 五禁：把五禁當針灸日曆——「甲乙日」只是十干配日的示例，本篇沒給換算。

## 局限

一、這是編者的結構（歸）：分層的切法、誤讀的選擇，都是一種讀法，不是原文自帶的目錄。
二、「連通則」是機器比對（通則引文句落在本篇），不是概念上的必然關聯。
三、模組目前**不在閱讀器上顯示**（舊模組也沒有專頁），只進覆蓋統計；要不要開一頁呈現，是下一個決定。
