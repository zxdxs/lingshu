# 167 D 型模組第二批：八篇短篇

## 這批補了什麼

第一批六篇之後，接著補八篇短篇：〈五邪〉〈周痺〉〈論痛〉〈逆順〉〈賊風〉〈動輸〉〈上膈〉〈寒熱〉。
模組篇數 **55 → 63**（模組原文條目 286 → 320，`模組原文不符` 仍 0）。

## 做法

把建置邏輯抽成 `scripts/module_lib.py`，各批只寫內容（SPEC）：原文由句索引按句 id 取出，
腳本斷言『這個 id 屬於該篇』，並自動比對通則引文句。內容仍是『一句／分層／原文要點／誤讀／連通則』。

## 幾個「誤讀」欄的取捨

- 五邪：不是風寒濕燥火五種病因，而是『邪在五藏』的五種情況。
- 周痹：不是『全身游走痛』；關鍵是「隨脉」「不能左右」——它沿脉走。
- 論痛：勝毒不是『能吃苦藥』，是從胃厚、骨大、肥瘦推能否承受毒藥。
- 逆順：「上工治未病」在本篇是刺法語（趁未盛、已衰），不是養生口號。
- 賊風：把「似鬼神」當靈樞承認鬼神是誤讀；下一句就說看不見、聽不到。
- 上膈：「上膈」「下膈」是症狀名（食入還出／食晬時乃出），不是解剖位置。
- 寒熱：「反其目視之」是專對瘰癧的死生判法，不可移用。

## 局限

一、分層的切法與「誤讀」的選擇是編者判斷（歸），不是原文自帶的目錄。
二、「連通則」是機器比對（通則引文句落在本篇），不是概念必然關聯；〈五邪〉〈周痺〉目前沒有通則引用，故為空。
三、模組仍不在閱讀器上顯示，只進覆蓋統計。
