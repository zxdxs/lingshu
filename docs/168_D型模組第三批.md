# 168 D 型模組第三批：四篇長篇

## 這批選了四篇「重」的

前兩批都是短篇。這批挑四篇長篇／樞紐篇：〈九鍼十二原〉（1,577 字，全書開篇）、
〈經别〉（604 字，十二經別的骨架）、〈本藏〉（1,673 字，藏府形質之學）、
〈五音五味〉（803 字，五音分類與鬚理）。

模組篇數 **63 → 67**（模組原文條目 320 → 342，`模組原文不符` 仍 0）。

## 四篇的骨架

### 1 九鍼十二原（七層）

立經之由 → 守形守神 → 補寫手法 → 九鍼形用 → 氣至 → 五腧二十七氣 → 十二原。
一句：把『針為什麼有效』從器講到氣。

誤讀：把「粗守形，上守神」讀成『形不重要』；原文是形也要守，上工只是多一層守氣機。

### 11 經别（四層）

為什麼（「學之所始，工之所止」）→ 一經之例（足太陽之正）→ 一合（足厥陰之正合少陽）→ 六合。

誤讀：把經別當『另一套經脉』。它是正經在體腔內的分支（離、合、出、入），不是獨立循環。

### 47 本藏（六層）

常平（血和／衛氣和／志意和／寒温和）→ 二十五變 → 一藏之例（心小／心大）→
以外知內（色理反推）→ 六府之應 → 結論（視其外應，以知其內藏）。

誤讀：把「二十五變」當二十五種病；它是五藏 × 五種形質的組合，講『同一藏，形不同則病不同』。

### 65 五音五味（五層）

調經 → 五味所屬（穀畜果色味時）→ 鬚之理（衝任與血）→ 宦者與天宦 → 六經常數。

誤讀：把五音配經當音樂治療；本篇是體質分類與取經的對應表。

## 局限

一、長篇只切 4–7 層，取的是骨架，不是逐句講解；細節仍在原文與題庫。
二、「連通則」是機器比對（通則引文句落在本篇）；〈經别〉沒有通則引用，故為空。
三、模組仍不在閱讀器上顯示，只進覆蓋統計。
