# 175 靈樞識模糊備援，素問篇題的第二種寫法

## 一、靈樞識：加上模糊備援

〈靈樞識〉的條目繫句原本只做『逐字比對』：把條目（經文短句）拿去該篇經文流裡找完全相同的一段。
找不到就留空——3,641 條裡有 2,272 條空著。

這一輪加一層備援：逐字找不到時，用條目的 4-gram 取候選位置，再比 difflib 相似度（≥0.85）。
理由與太素那邊一樣：**異文與缺筆會讓逐字比對失敗，但整段相似度仍在**。

| 項 | 之前 | 現在 |
|---|---|---|
| 繫上底本句 | 1,369 | **1,403** |
| 有條目能繫上的篇 | 76 | **77** |
| 通則引文可對注 | 59 段 / 42 條 | **60 段 / 43 條** |
| 馬蒔轉引 | 569 | 569（未變） |

家別分佈（1,403 條之內）：張介賓 789、甲乙經 364、馬蒔 323、丹波元簡 226、未署名 222、
張志聰 201、千金方 25、版本校 20、外台秘要 13、巢氏病源 9。

仍空著 2,238 條，其中 1,039 條本身沒有『條目／注』的分隔（是接續行），無法用條目去比。
不硬湊。

## 二、素問篇題：抓到第二種寫法

`scripts/build_suwen.py` 原本只認「…篇第N」的篇題寫法。但 SBCK 轉錄裡有另一種：「…論二十六」
（沒有「第」、也沒有「篇」），於是 26〈八正神明論〉、46〈病能論〉、50〈刺要論〉被漏掉。

改成『篇名以 論 或 篇 收尾，序號前可有『第』也可無』，並用『必須以 論／篇 收尾』擋掉
「…四八」「凡五五」這類誤抓（第一版放寬後誤抓了三行經文，靠這條條件擋住）。

結果：**仍是 77 篇、78,396 字，未變**——因為那三篇的篇題行在 SBCK 轉錄裡根本不存在（只出現在
卷首目錄，而目錄在清理時已被丟棄）。所以這次修的是『判定邏輯的正確性』，不是補到篇數。
72〈刺法論〉全本亡佚，補不了。

要真正補到 80 篇，得換一個有完整篇題的底本（或從他本補文），並標明來源不同——那是另一輪的事，
不混進現有 corpus。

## 局限（照實寫）

一、模糊備援的門檻 0.85 是經驗值；未逐條抽驗新增的 34 條。
二、條目若無空格分隔（接續行），本輪不處理，仍是空。
三、素問三篇缺文是「底本缺」，不是程式錯；已在 `docs/117` 與 `stats.缺篇名` 標明。
