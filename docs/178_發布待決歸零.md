### 一、後端（我做，`scripts/verify_anki.py`）

用 Anki 官方後端（`anki` 套件 26.9.3）實際匯入 `export/靈樞_填空.apkg`：

```
notes=745  cards=745
牌組：Default、靈樞經 · 自學
模板：填空｜欄位：題面、答案、可接受、說明、出處
卡 1：Q=《靈樞·本輸》「肺出於____」 對答案 少商
     A=…答案：少商 肺之井穴… 僅供在有帶教資格的執業中醫師指導下使用
✓ 通過
```

這一層能證：檔案格式、牌組、卡片型、模板、欄位、答案頁內容（含安全提醒）。
不能證：版面好不好看、字型有沒有跑、按鈕在 GUI 裡的手感。
