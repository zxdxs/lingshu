# 術語卡（C 型）

> 只取**篇內義**——即該詞在這一篇裡的定義。
> 同一詞在別篇、或在後世可能有不同意思，那是另外兩欄，不可混用。

---

## 一、本神十義（《本神第八》）

| 術語 | 篇內義 |
|---|---|
| **精** | 故生之來 |
| **神** | 兩精相搏 |
| **魂** | 隨神往來者 |
| **魄** | 並精而出入者 |
| **心** | 所以任物者 |
| **意** | 心有所憶 |
| **志** | 意之所存 |
| **思** | 因志而存變 |
| **慮** | 因思而遠慕 |
| **智** | 因慮而處物 |

> 這十個詞是一條發生鏈：精→神→魂→魄→心→意→志→思→慮→智。不是十個孤立的名詞。

## 二、決氣六氣（《決氣第三十》）

| 術語 | 篇內義 |
|---|---|
| **精** | 岐伯曰：兩神相搏，合而成形，常先身生 |
| **氣** | 何謂氣？岐伯曰：上焦開發，宣五穀味，熏膚，充身，澤毛，若霧露之溉 |
| **津** | 何謂津？岐伯曰：腠理發泄，汗出溱溱 |
| **液** | 何謂液？岐伯曰：穀入氣滿，淖澤注于骨，骨屬屈伸，洩澤，補益腦髓，皮膚潤澤 |
| **血** | 何謂血？岐伯曰：中焦受氣取汁，變化而赤 |
| **脉** | 何謂脉？岐伯曰：壅遏營氣，令無所避 |

## 四、使用規則

1. 背卡時**先背篇內義**，不要一開始就摻後世解釋。
2. 「精」「氣」「血」這類詞，在《靈樞》不同篇有不同定義——遇到衝突，先確認是哪一篇。
3. 本表未收他篇義與後世義，這是**刻意留白**，不是遺漏。
