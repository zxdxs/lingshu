# 183 郵件與微信：與傷寒站、聲韻站同一套聯絡方式

## 為什麼

維護者三個站（傷寒站 `solve-lab.cn`、聲韻站 `shenglv.org.cn`、本站）是同一個人，
先前只有一個 email，讀者要加微信得去別的站找。這一輪把「微信」補上，三站一致：

| 管道 | 內容 | 來源 |
|---|---|---|
| Email | `hello@solve-lab.cn` | 三站相同（聲韻站 about 頁也是這個） |
| 微信 | **課孫翁**（掃碼加好友） | 二維碼取自聲韻站 `assets/wx-qrcode.jpg`（同一維護者） |
| GitHub Issue | `github.com/zxdxs/lingshu/issues` | 本站新增（只有本站有 repo） |

## 站上怎麼呈現

`#/contact` 的『怎麼聯絡』卡現在有三列：

1. **郵箱**：`hello@solve-lab.cn`（附件、截圖、長文、整份校表都收）
2. **GitHub Issue**：公開可追蹤，單點勘誤最快
3. **微信**：顯示「課孫翁」＋二維碼圖（`assets/wx-qrcode.jpg`，504×834），
   並註明『與傷寒站、聲韻站同一個維護者、同一個微信；加好友請註明靈樞』

二維碼以 `<img class="qr">` 呈現，寬 180px；線上與離線（`reader/index.html`）都走相對路徑，
兩邊都能顯示。已用瀏覽器驗證 `img.complete=true`、`naturalWidth×Height=504×834`。

## 防線

`check_reader` 的 contact 檢查多了兩條：

- `data/聯絡.json` 裡有 `qr` 的項目，其 `wechat` 文字必須出現在頁面；
- 頁面必須有 `.qr` 元素（避免只寫文字、圖掉了沒人知道）。

## 局限

一、二維碼是圖片，換微信或二維碼過期時要換檔（`reader/assets/wx-qrcode.jpg`），程式不會知道。
二、微信是私人聯絡方式，公開在站上意味著可能被大量加好友；目前沒有分流或自動回覆。
三、二維碼來源是聲韻站（同一維護者），若那站換圖，本站不會自動同步。
