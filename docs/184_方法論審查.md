# 184 方法論審查：採用什麼、不採用什麼

對象：《灵枢经数字化整理方法论》（45 頁，以下稱『方法論』）。這一輪做兩件事：審查它，並把可落地的部分做成站上的『治理』頁。

## 一、總評

方法論的骨架是對的，而且解決了本站最心虛的一處：**它把『不知道』變成一等公民**。

三個強項：

1. **分檔（A/B/C）＋五問**：每一條結論都要回答『屬於哪一層、證據是什麼、什麼會推翻它』。本站原本有 〔原〕〔注〕〔歸〕〔空〕 四種標記，但沒有『什麼會推翻它』這一欄——這是最大的缺口，這輪補上了。
2. **兩存與懸置（both_preserved／suspended）**：不是拖著不辦，是明說『現有證據不足以取捨』。本站太素注、甲乙經差異、素問補篇本來就是這樣處理，只是沒有登記成冊。
3. **元規則**：預登記證偽條件、反例優先、研究日誌、可復現。這幾條讓方法論自己也可被檢驗，不是姿態。

兩個盲點（對本站這種單人、靜態、無後端的專案）：

1. **假設有團隊與 CI**：V-01～V-31、schema 硬檢、reviewed_by、snapshot、vocab_version 全量 stale——這些要有資料庫、構建流程與多人角色。本站是一位編者、純靜態、GitHub Pages，硬套會變成『文件寫了但沒人跑』。
2. **度量可能反向誘導**：確定性預算若被當成績效（suspended 越少越好），會逼出『表演性斷言』。方法論自己警告了（『預算不得單向追求 published 上升』），但沒有給『如何避免』的機制。

## 二、逐條對照

| 方法論 | 本站 | 做法 |
|---|---|---|
| 文本性質先行（層累教本） | **採用** | 通則頁與方法頁都寫『不是一次寫成的教科書』；不追求唯一原貌。 |
| 知識類型三分（描述／規範／技藝） | **部分** | 原文層不動；『技藝邊界』寫在限制頁（手感、得氣不可完全文本化）。 |
| 四層規律（語言／文本／醫理／生理） | **部分** | 引文只做語言／文本層；醫理層的歸納標〔歸〕；不做生理層推論。 |
| 三檔（可確證／可推論／不可判定） | **採用（改名）** | 本站用 〔原〕＝可確證、〔注〕＝早期／後世成說、〔歸〕＝可推論、〔空〕＝不可判定。 |
| 五問模板 | **採用** | 治理頁的檔位＋未決登記簿每條都有『證偽條件』與『影響』。 |

| 目的四分＋檢索 | **部分** | 教學（本站主體）／文獻（校勘頁）分開；臨床目的**刻意不做**（安全）。 |

| R-02 兩存與裁決 | **部分** | 差異／補篇／太素注皆標『未判定／兩存』，但沒有 dispute_ref 檔案；這輪用未決登記簿代替。 |
| R-03 措辭約束 | **採用** | 『』＝靈樞原文（機器核）；『』＝注家／他書；編者話明寫『歸』。 |

| R-06 覆蓋分級（A/B/C 篇） | **不採用** | 81 篇已全數有基本解讀層（通則／病候／模組），再做 A/B/C 分級是重複分類。 |
| R-07 能力可測 | **部分** | 題目有句 id 回鏈（91.5%）；『不可判定辨識題』尚未建，作答資料為空。 |
| R-08 反例與失敗留檔 | **部分** | 未決登記簿＋CHANGELOG 的『曾以為何、因何改判』；反例庫未獨立成檔。 |
| R-09～R-11 分軸與層累 | **不採用** | 本站不做層累歸集：不判年代、作者、先後、原篇結構。這是刻意縮小主張。 |
| 信封 schema／V-01～V-31 | **部分** | 採其欄位精神（id／kind／layer／grade／statement／falsifier／refs／status／resolution），不建 JSON Schema 與 CI 硬檢；用 `check_all` 的 64 項指標代替。 |

## 三、這輪實際改了什麼

1. **新增 `#/govern`（治理）頁**：檔位對照（本站四標記 ↔ 方法論五檔）、確定性預算、未決登記簿、方法論採納表。
2. **新增 `data/未決.json`**：12 條未決（blocked 6、suspended 6、兩存 3），每條有說明、證偽條件、影響。
3. **新增 `scripts/build_governance.py`**：預算數字由既有資料算出（題數、有句 id、通則、界、未決），不手填。
4. **`check_all` 加 5 項**：未決數、blocked、suspended、兩存、枚舉與證偽合法性；`check_reader` 與 `smoke_browser` 加 `/govern`。

## 四、我不同意方法論的地方（寫出來供討論）

1. **『唯一枚舉』與教學站的張力**：方法論要求 grade 五值是全篇唯一枚舉，這對資料庫是對的；但本站是給人讀的，讀者記不住 A_字書直證／A_經文內證的差別。所以本站保留四標記，並在治理頁給對照表——**顯示用四種，登記用五檔**，不假裝兩者同一。
2. **兩存沒有期限**：R-02 讓衝突可以兩存，但沒有『多久沒裁決就必須降級或關閉』的機制。本站的做法是把『誰能解』寫進每條未決（例如『需影印本』『需真人作答』），讓它至少可被追。
3. **狀態機對單人過重**：draft→collated→reviewed→published 假設有角色分工；本站只有一位編者，所以只用 published／suspended／blocked，reviewed_by 從缺——治理頁照實寫。
4. **層累可以不做的理由要寫清楚**：方法論把『不可判定是成果』說得很好，但沒有說『不做層累』也是合法選擇。本站明說：不做，是因為做了也只能給假設，而本站的讀者不需要那個假設。

## 五、下一步（若要更貼近方法論）

1. 為 65 條通則各寫一條**具體**證偽條件（目前只有『界』；證偽需要『什麼證據會推翻』）。
2. 建『不可判定辨識題』題型（R-07）：給三個讀法，問哪一個不可判定、為什麼。
3. 把 `data/未決.json` 的 12 條逐條連到相關頁面（通則、注家、校勘），讓讀者在原地看到『這裡有一條未決』。
4. 若日後有多人審核，再上 reviewed_by 與 stale 傳播。
