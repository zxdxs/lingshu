# 186 誦讀加拼音

## 做了什麼

誦讀頁（`#/recite`）每一句現在可顯示**逐字拼音**（帶聲調），用 `<ruby>` 標在字上方；
一個「拼音」勾選框可整頁開關，狀態存在本機。

- 句 ID 仍在左側，拼音在字上方，原文不動。
- 開關切換只改 class（`.no-py rt{display:none}`），不重繪朗讀清單。
- 拼音與漢字**逐字對齊**：非漢字（標點、數字）不標；對齊由腳本驗。

## 怎麼生成

`scripts/build_pinyin.py`：

1. 取 `底本/靈樞經_句索引.json` 的 3,289 句。
2. 用 pypinyin（0.55）逐字轉帶聲調拼音。
3. 先套一張**校訂表**（只收『讀錯會影響意思』的常見條目）：

| 類型 | 例 |
|---|---|
| 詞組 | 五藏 wǔ zàng、藏象 zàng xiàng、少陰 shào yīn、中風 zhòng fēng、惡血 wù xuè、更發 gēng fā、乾薑 gān jiāng、內穀 nà gǔ、大淵 tài yuān |
| 單字 | 寫 xiè（即「瀉」）、俞 shù（即「腧」）、溺 niào |

4. 統計對齊與未收字。

## 結果

| 項 | 數 |
|---|---|
| 句 | 3,289 |
| 對齊失敗 | **0** |
| 未收字 | 5（㡬、䝉、㤣、䊸、㬷——pypinyin 未收，保留原字） |
| 資料 | `data/拼音.json`（355 KB），進 `data.js` 後 1.27 MB |

## 防線

- `拼音句 3289`、`拼音對齊失敗 0`、`拼音未收字 5`（`check_all`）。
- `smoke_browser` 的誦讀路由要求 ≥10 個 `<ruby>`；真瀏覽器實測篇 40 有 314 個 ruby／314 個 rt、拼音開關預設開。

## 照實說的（重要）

一、**拼音不是定本**。校訂只收了幾十條常見多音字，其他照生成器；經文裡還有大量古讀、異讀（見 xiàn／jiàn、數 shuò／shù、與 yǔ／yù、內 nèi／nà），沒有逐條考證。
二、**音釋層沒有整合**：底本卷末的反切（如「音某」「某某反」）是另一套證據，本輪沒有把它變成拼音。
三、未收的 5 個罕字保留原字，等於不標音。
四、拼音只做在誦讀頁；讀原文頁不標（避免把整頁原文擠成兩行高）。

## 下一步（若要更準）

1. 把底本音釋（反切）抽成表，與 pypinyin 結果比對，衝突處以音釋為準並記在校訂表。
2. 為『多音字清單』做一個小頁面（字、書中出現處、兩種讀法、依據），讓讀者自己判斷。
3. 若要做全文標音，需先決定『讀原文頁要不要 ruby』——那會改變整頁行高。
