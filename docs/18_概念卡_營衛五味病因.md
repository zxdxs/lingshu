# 概念卡：營衛・五味・病因

> 出處：《靈樞》營衛生會第十八、五味第五十六、百病始生第六十六。

---

## 一、營衛與睡眠（營衛生會）

- **營**：其清者為營……營在脉中
- **衛**：其濁者為衛……衛在脉外
- **營衛大會**：營周不休，五十而復大會，陰陽相貫，如環無端
- **衛氣晝夜**：衛氣行于陰二十五度，行于陽二十五度，分為晝夜
- **老人不夜瞑**：老者之氣血衰，其肌肉枯，氣道澀，營氣衰少而衛氣內伐，故晝不精，夜不瞑
- **壯者晝精夜瞑**：壯者之氣血盛，肌肉滑，氣道通，營衛之行不失其常
- **奪血者無汗**：血之與氣異名同類；奪血者無汗，奪汗者無血

> 這一組對普通人的價值最高：**睡眠不是「睡不著」三個字，而是營衛運行的問題**。壯者氣血盛、氣道通，故晝精夜瞑；老者氣血衰、氣道澀，故晝不精夜不瞑。

## 二、三焦（營衛生會）

### 上焦

上焦出于胃上口，並咽以上，貫膈而布胸中，走腋，循太陰之分而行，還至陽明，上至舌，下足陽明，常與營俱行于陽二十五度，行于陰亦二十五度，一周也。

### 中焦

中焦亦並胃中，出上焦之後。此所受氣者，泌糟粕，蒸津液，化其精微，上注于肺脉，乃化而爲血，以奉生身，莫貴于此，故獨得行于經隧，命曰營氣。

### 下焦

下焦者，別迴腸，注于膀胱而渗入焉。故水穀者，常并居于胃中，成糟粕而俱下于大腸，而成下焦，渗而俱下，濟泌別注，循下焦而渗入膀胱焉。

> 要訣：**上焦如霧，中焦如漚，下焦如瀆。**

## 三、五味（五味）

**五味所走**：

| 味 | 先走 |
|---|---|
| 酸 | 肝 |
| 苦 | 心 |
| 甘 | 脾 |
| 辛 | 肺 |
| 鹹 | 腎 |

**五藏所禁**（重要：這是「忌口」的經典依據）：

| 藏 | 禁 |
|---|---|
| 肝病 | 禁辛 |
| 心病 | 禁鹹 |
| 脾病 | 禁酸 |
| 腎病 | 禁甘 |
| 肺病 | 禁苦 |

**五穀五味**：

秔米甘、麻酸、大豆鹹、麥苦、黃黍辛

> 注意：五禁是『病時之禁』，不是人人皆忌。沒有病的人不必按此忌口。

## 四、病因三部（百病始生）

| 病因 | 所傷 | 病起 |
|---|---|---|
| 喜怒不節 | 傷藏 | 病起於陰 |
| 清濕 | 襲虚 | 病起於下 |
| 風雨 | 襲虚 | 病起於上 |

> **關鍵句**：風雨寒熱，不得虚，邪不能獨傷人。卒然逢疾風暴雨而不病者，盖無虚，故邪不能獨傷人。此必因虚邪之風，與其身形，兩虚相得，乃客其形。

「兩虛相得，乃客其形」——邪氣本身不足以致病，必須**身形之虛**與**虛邪之風**相遇。

### 邪氣傳舍

| 舍 | 候 |
|---|---|
| 皮膚 | 皮膚緩則腠理開，邪從毛髮入，毛髮立則淅然，故皮膚痛 |
| 絡脉 | 痛於肌肉，其痛之時息，大經乃代 |
| 經 | 洒淅喜驚 |
| 輸 | 六經不通，四肢則肢節痛，腰脊乃强 |
| 伏衝之脉 | 體重身痛 |
| 腸胃 | 賁嚮腹脹，多寒則腸鳴飱泄、食不化，多熱則溏出麋 |
| 腸胃之外、募原之間 | 留著於脉，稽留而不去，息而成積 |

> 這是一條由淺入深的路徑：皮膚→絡脈→經→輸→伏衝之脈→腸胃→募原之間，最後成積。
