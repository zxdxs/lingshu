# 診法卡（觀察）

> 出處：《靈樞》論疾診尺第七十四、五色第四十九。
> ⚠️ **本文是歷史觀察系統的整理，不是自我診斷工具。** 身體不適請就醫。

---

## 一、尺膚診（論疾診尺）

| 尺膚所見 | 主病 |
|---|---|
| 滑而澤脂 | 風也 |
| 濇 | 風痹也 |
| 粗如枯魚之鱗 | 水泆飲也 |
| 熱甚、脉盛躁 | 病温也；其脉盛而滑者，病且出也 |
| 寒、其脉小 | 泄、少氣 |
| 炬然 | 先熱後寒者，寒熱也 |
| 先寒 | 久大之而熱者，亦寒熱也 |
| 緩急、小大、滑濇 | （總綱）審此五者與肉之堅脆，而病形定矣 |

**分部獨熱／獨寒**：

| 部位 | 主 |
|---|---|
| 肘所熱 | 腰以上熱；手所獨熱者，腰以下熱 |
| 肘前熱 | 膺前熱；肘後獨熱者，肩背熱 |
| 臂中熱 | 腰腹熱 |
| 肘後熱 | 腸中有蟲 |
| 掌中熱 | 腹中熱；掌中寒者，腹中寒 |

## 二、目診（論疾診尺）

| 目色 | 在藏 |
|---|---|
| 赤 | 心 |
| 白 | 肺 |
| 青 | 肝 |
| 黃 | 脾 |
| 黑 | 腎 |

## 三、血脈之色（論疾診尺）

| 色 | 主 |
|---|---|
| 多赤 | 熱 |
| 多青 | 痛 |
| 多黑 | 久痹 |

## 四、五色主病（五色）

- **青黑為痛**
- **黃赤為熱**
- **白為寒**

## 五、明堂五部（五色）

- **明堂**：鼻也
- **闕**：眉間也
- **庭**：顔也
- **蕃**：頰側也
- **蔽**：耳門也
- **庭**：首面也

## 六、色部對應（五色）

| 部位 | 應 |
|---|---|
| 庭 | 顔也；蕃者，頰側也；蔽者，耳門 |
| 庭 | 首面 |
| 闕上 | 咽喉 |
| 闕中 | 肺 |
| 下極 | 心 |
| 直下 | 肝 |
| 肝左 | 膽 |
| 方上 | 胃 |
| 中央 | 大腸 |
| 挾大腸 | 腎 |
| 當腎 | 臍 |
| 面王以上 | 小腸 |
| 面王以下 | 膀胱子處 |
| 中央 | 膝 |
| 巨分 | 股裏 |
| 巨屈 | 膝臏 |

## 七、危候（五色）

- 赤色出兩顴，大如母指者，病雖小愈，必卒死
- 黒色出於庭，大如母指，必不病而卒死

---

## 使用說明

1. 這一組卡的價值不是『學會看相』，而是**學會觀察的粒度**：同一個「熱」，可以分肘、手、臂、掌、魚際。
2. 讀的時候問自己：作者是根據什麼把「這裡熱」連到「那裡病」的？這個連結今天還成立嗎？
3. 不要用來自診。這是最重要的一條。
