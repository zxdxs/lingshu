## 二、九刺（官鍼）

| 序 | 名 | 法 |
|---|---|---|
| 一 | 輸刺 | 刺諸經滎輸藏腧也 |
| 二 | 逺道刺 | 病在上，取之下，刺府腧也 |
| 三 | 經刺 | 刺大經之結絡經分也 |
| 四 | 絡刺 | 刺小絡之血脉也 |
| 五 | 分刺 | 刺分肉之間也 |
| 六 | 大寫刺 | 刺大膿以鈹鍼也 |
| 七 | 毛刺 | 刺浮痹皮膚也 |
| 八 | 巨刺 | 左取右，右取左 |
| 九 | 焠刺 | 刺燔鍼則取痹也 |

## 三、十二節（官鍼）

| 序 | 名 | 法 |
|---|---|---|
| 一 | 偶刺 | 以手直心若背，直痛所，一刺前，一刺後，以治心痹 |
| 二 | 報刺 | 刺痛無常處也，上下行者，直內無拔鍼，以左手隨病所按之，乃出鍼復刺之 |
| 三 | 恢刺 | 恢刺直刺傍之，舉之前後，恢筋急，以治筋痹 |
| 四 | 齊刺 | 直入一，傍入二，以治寒氣小深者 |
| 五 | 揚刺 | 正內一，傍內四，而浮之，以治寒氣之愽大者 |
| 六 | 直鍼刺 | 引皮乃刺之，以治寒氣之淺者 |
| 七 | 輸刺 | 直入直出，稀發鍼而深之，以治氣盛而熱者 |
| 八 | 短刺 | 刺骨痹，稍摇而深之，致鍼骨所，以上下摩骨 |
| 九 | 浮刺 | 傍入而浮之，以治肌急而寒者 |
| 十 | 陰刺 | 左右率刺之，以治寒厥 |
| 十一 | 傍鍼刺 | 直刺傍刺各一，以治留痹久居者 |
| 十二 | 賛刺 | 直入直出，數發鍼而淺之，出血，是謂治癰腫 |
