## 一、五禁（五禁）

| 日干 | 禁 |
|---|---|
| 甲乙日 | 刺頭，無發矇于耳內 |
| 丙丁日 | 振埃于肩喉廉泉 |
| 戊巳日 | 刺腹，去爪寫水 |
| 庚辛日 | 刺闗節于股膝 |
| 壬癸日 | 刺足脛 |

## 二、五奪（五禁）

- 一奪：形肉已奪
- 二奪：大奪血之後
- 三奪：大汗出之後
- 四奪：大泄之後
- 五奪：新産及大血之後

> 五奪皆不可寫（瀉）。

## 三、五逆（五禁）

- 一逆：熱病永静，汗已出，脉盛躁
- 二逆：病泄，脉洪大
- 三逆：著痹不移，䐃肉破，身熱，脉偏絕
