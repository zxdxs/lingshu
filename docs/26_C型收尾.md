# C 型收尾：津液、五官、夢象

> 出處：《靈樞》五癃津液別第三十六、五閱五使第三十七、淫邪發夢第四十三。

---

## 一、津液五別（五癃津液別）

| 因 | 所化 |
|---|---|
| 天寒衣薄 | 溺與氣 |
| 天熱衣厚 | 汗 |
| 悲哀氣并 | 泣 |
| 中熱胃緩 | 唾 |

> 津與液之別：三焦出氣，溫肌肉、充皮膚者為**津**；流而不行者為**液**。

| 陽氣盛 | 大火而燔焫 |
| 陰陽盛 | 相殺 |
| 上盛 | 飛 |
| 下盛 | 墮 |

| 肺氣盛 | 恐懼、哭泣、飛揚 |
| 心氣盛 | 善笑、恐畏 |
| 脾氣盛 | 歌樂 |
| 腎氣盛 | 腰脊兩解不屬 |

---

## 使用說明

1. 夢象這一組，當作**古人觀察身心關聯的方式**來讀，不要當成診斷依據。
2. 『十二盛者，至而寫之；十五不足者，至而補之』——原書的處理原則是瀉盛補虛。
3. 五官與五病候，是望診的經典對應，可與《五色》並讀。
