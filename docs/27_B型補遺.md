# B 型補遺：五亂、病傳、水脹

> 出處：《靈樞》五亂第三十四、病傳第四十二、水脹第五十七。

---

## 一、五亂（五亂）

| 亂於 | 證 | 治法 |
|---|---|---|
| 心 | 煩心宻嘿，俛首靜伏 | 手少陰、心主之輸 |
| 肺 | 俛仰喘喝，接手以呼 | 手太陰滎、足少陰輸 |
| 腸胃 | 為霍亂 | 足太陰、陽明；不下者，取之三里 |
| 臂脛 | 為四厥 | 先去血脉，後取其陽明、少陽之榮輸 |
| 頭 | 為厥逆，頭重眩仆 | 天柱、大杼；不知，取足太陽滎輸 |

**五亂治法總表**：

| 氣在 | 取 |
|---|---|
| 心 | 手少陰、心主之輸 |
| 肺 | 手太陰滎、足少陰輸 |
| 腸胃 | 足太陰、陽明；不下者，取之三里 |
| 頭 | 天柱、大杼；不知，取足太陽滎輸 |
| 臂足 | 先去血脉，後取其陽明、少陽之榮輸 |

> 「徐入徐出，謂之導氣；補寫無形，謂之同精」——五亂不是有餘不足，是『亂氣相逆』，所以治法是導氣，不是補瀉。

## 二、病傳（病傳）

| 首發 | 傳變 | 死期 |
|---|---|---|
| 心 | 一日而之肺，三日而之肝，五日而之脾，三日不已 |  |
| 肺 | 三日而之肝，一日而之脾，五日而之胃，十日不已 |  |
| 肝 | 三日而之脾，五日而之胃，三日而之腎，三日不已 |  |
| 脾 | 一日而之胃，二日而之腎，三日而之膂膀胱，十日不已 |  |
| 胃 | 五日而之腎，三日而之膂膀胱，五日而上之心，二日不已 |  |
| 腎 | 三日而之膂膀胱，三日而上之心，三日而之小腸，三日不已 |  |
| 膀胱 | 五日而之腎，一日而之小腸，一日而之心，二日不已 |  |

> 「諸病以次相傳，如是者，皆有死期，不可刺也；間一藏及二三四藏者，乃可刺也。」

## 三、水脹（水脹）

| 病 | 候 |
|---|---|
| 水 | 始起也，目窠上微腫，如新臥起之狀，其頸脉動，時咳，陰股間寒，足脛瘇，腹乃大；以手按其腹，隨手而起，如裹水之狀 |
| 膚脹 | 寒氣客于皮膚之間，□□然不堅，腹大，身盡腫，皮厚，按其腹窅而不起，腹色不變 |
| 鼓脹 | 腹脹身皆大，大與膚脹等也，色蒼黃，腹筋起 |
| 腸覃 | 寒氣客于腸外，與衛氣相摶，瘜肉乃生；始如雞卵，稍以益大，至其成如懷子之狀，按之則堅，推之則移，月事以時下 |
| 石瘕 | 生于胞中，寒氣客于子門，子門閉塞，惡血當寫不寫，衃以留止，日以益大，狀如懷子，月事不以時下 |
