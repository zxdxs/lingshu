# 癰疽與邪客

> 出處：《靈樞》癰疽第八十一、邪客第七十一。

---

## 一、癰疽名候（癰疽）

抽取 **14** 條。

| 部位 | 名 | 候 |
|---|---|---|
| 嗌中 | 猛疽 | 猛疽不治，化爲膿；膿不寫，塞咽，半日死 |
| 頸 | 天疽 | 其癰大以赤黒，不急治，則熱氣下入淵腋，前傷任脉，內薰肝肺，薰肝肺十餘日而 |
| 肩及臑 | 疵癰 | 其狀赤黒，急治之，此令人汗出至足，不害五藏 |
| 腋下赤堅者 | 米疽 | 治之以砭石，欲細而長，踈砭之，塗已豕膏，六日已，勿裹之 |
| 胸 | 井疽 | 其狀如大豆，三四日起，不早治，下入腹，不治，七日死矣 |
| 膺 | 甘疽 | 色青，其狀如穀實、□□，常苦寒熱，急治之，去其寒熱；十嵗死，死後出膿 |
| 脇 | 敗疵 | 敗疵者，女子之病也 |
| 股脛 | 股脛疽 | 其狀不甚變，而癰膿摶骨，不急治，三十日死矣 |
| 尻 | 鋭疽 | 其狀赤堅大，急治之；不治，三十日死矣 |
| 膝 | 疵癰 | 其狀大癰，色不變，寒熱如堅，石勿石，石之者死；須其柔，乃石之者，生 |
| 脛 | 兔齧 | 其狀赤至骨，急治之，不治害人也 |
| 內踝 | 走緩 | 其狀癰也，色不變，數石其輸而止其寒熱，不死 |
| 足上下 | 四淫 | 其狀大癰，急治之，百日死 |
| 足傍 | 厲癰 | 其狀不大，初如小指發，急治之，去其黒者；不消輒益，不治，百日死 |

> 癰與疽之別：癰者「熱勝則肉腐，肉腐則為膿」，皮薄以澤；疽者「熱氣淳盛，下陷肌膚，筋髓枯」，皮堅如牛領。

## 二、八虛（邪客）

| 藏 | 邪留 |
|---|---|
| 心 | 兩肘 |
| 肝 | 兩腋 |
| 脾 | 兩髀 |
| 腎 | 兩膕 |

> 「凡此八虛者，皆機關之室，真氣之所過，血絡之所遊。邪氣惡血，固不得住留；住留則傷筋絡骨節，機關不得屈伸，故痀攣也。」

## 三、不寐與半夏秫米湯（邪客）

**病機**：衛氣獨衛其外，行於陽，不得入於陰；行於陽則陽氣盛，陽蹻陷，不得入於陰，陰虚，故目不瞑

**治則**：補其不足，寫其有餘，調其虚實，以通其道而去其邪

**方**：流水千里以外者八升，揚之萬遍，取其清五升煮之，炊以葦薪，置秫米一升、治半夏五合，徐炊，令竭為一升半，去滓，飲汁一小杯，日三

> 這是《靈樞》極少數的方劑記載，治「目不瞑」。注意：方中半夏有毒性，須炮製，不可自行服用。
