# 禁服與五味論

> 出處：《靈樞》禁服第四十八、五味論第六十三。

---

## 一、人迎寸口（禁服）

| 人迎倍數 | 病位 |
|---|---|
| 一倍 | 足少陽 |
| 二倍 | 足太陽 |
| 三倍 | 足陽明 |
| 一倍 | 手少陽 |
| 一倍 | 手心主 |
| 二倍 | 手少陰 |
| 三倍 | 手太陰 |

> 平人：寸口主中，人迎主外，兩者相應，俱往俱來，若引繩大小齊等；春夏人迎微大，秋冬寸口微大。

## 二、五味所走（五味論）

| 味 | 走 | 多食之害 |
|---|---|---|
| 酸 | 筋 | 癃 |
| 鹹 | 血 | 渇 |
| 辛 | 氣 | 洞心 |
| 苦 | 骨 | 變嘔 |
| 甘 | 肉 | 悗心 |

> 這一組講的是『五味偏嗜』的具體後果，不是『五味養生』。原文的語氣是「多食之，令人…」——重點在**過量**。
