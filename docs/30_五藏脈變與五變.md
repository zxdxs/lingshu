# 五藏脈變與五變

> 出處：《靈樞》邪氣藏府病形第四、五變第四十六。

---

## 一、五藏脈變（邪氣藏府病形）

每一藏有十二種脈象變化：急甚／微急、緩甚／微緩、大甚／微大、小甚／微小、滑甚／微滑、濇甚／微濇。

| 藏 | 脈 | 病 |
|---|---|---|
| 心 | 急甚 | 瘛瘲 |
| 心 | 微急 | 心痛引背，食不下 |
| 心 | 緩甚 | 狂笑 |
| 心 | 微緩 | 伏梁，在心下，上下行，時唾血 |
| 心 | 微大 | 心痹引背，善淚出 |
| 心 | 小甚 | 善噦，微小爲消癉 |
| 心 | 滑甚 | 善渴 |
| 心 | 微滑 | 心疝引臍，小腹鳴 |
| 心 | 濇甚 | 瘖 |
| 心 | 微濇 | 血溢，維厥，耳鳴，顛疾 |
| 肺 | 急甚 | 癲疾 |
| 肺 | 微急 | 肺寒熱，怠惰，咳唾血，引腰背胸，若鼻息肉不通 |
| 肺 | 緩甚 | 多汗 |
| 肺 | 微緩 | 痿瘻，偏風，頭以下汗出不可止 |

| 脾 | 微濇 | 內㿉，多下膿血 |
| 腎 | 急甚 | 骨癲疾 |

| 腎 | 滑甚 | 癃㿉 |

> 這一組的教學價值：同一個「急」，甚與微對應的病完全不同。「甚」是極端、結構性；「微」是偏向、功能性。

## 二、五變（五變）

| 體質 | 易病 |
|---|---|
| 肉不堅，腠理踈 | 風厥 |
| 五藏皆柔弱 | 消癉 |
| 小骨弱肉 | 寒熱 |
| 粗理而肉不堅 | 痹 |
| 皮膚薄而不澤，肉不堅而淖澤 | 腸中積聚 |

> 原文以木之堅脆比喻：同一陣風，吹在不同的木上，折的枝不同。「人之有常病也，亦因其骨節皮膚腠理之不堅固者，邪之所舍也。」
