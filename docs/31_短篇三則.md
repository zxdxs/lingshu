# 短篇三則：上膈、憂恚無言、寒熱

> 三篇都是『病—機—治』的短篇，各做一張卡。

---

## 膈證（上膈）

- **辨析**：氣為上膈：食飲入而還出；蟲為下膈：食晬時乃出
- **病機**：喜怒不適、食飲不節、寒溫不時 → 寒汁流於腸中 → 蟲寒 → 積聚守於下管 → 衛氣不營 → 邪居 → 癰成 → 下管約
- **治法**：微按其癰，視氣所行，先淺刺其傍，稍內益深，還而刺之，毋過三行；已刺必熨，令熱入中；後以鹹苦化穀
- **禁忌／預後**：毋過三行（不可過度）

## 卒然無音（憂恚無言）

- **辨析**：咽喉＝水穀之道；喉嚨＝氣之上下；會厭＝音聲之戶；口唇＝音聲之扇；舌＝音聲之機；懸雍垂＝音聲之關；頏顙＝分氣所泄；橫骨＝神氣所使，主發舌
- **病機**：寒氣客於厭，則厭不能發，發不能下，開闔不致，故無音
- **治法**：寫足少陰血脈（濁氣乃辟）；取天突（會厭之脈上絡任脈）

## 寒熱瘰癧（鼠瘻）（寒熱）

- **辨析**：在頸腋者，皆鼠瘻寒熱之毒氣，留於脈而不去
- **病機**：本在藏，末上出於頸腋之間；浮於脈中而未內著肌肉、外為膿血者，易去
- **治法**：從其本引其末；審按其道以予之，徐往徐來以去之；小如麥者，一刺知，三刺而已
- **禁忌／預後**：反目視之，赤脈上下貫瞳子：見一脈一歲死，二脈二歲死，三脈三歲死；不貫瞳子者可治

---

## 一點說明

這三篇字數都不到 250，但結構完整。它們證明：**短不等於沒價值**——『病—機—治』三欄就足以構成一個可教學的單元。
