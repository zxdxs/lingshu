# 46 概念的本質：汗、經絡

> 目的：不問『書上關於 X 說了什麼』，只問『靈樞把 X 當成什麼東西』。
> 方法：只取原文三類句子——定義句、功能句、邊界句；然後分三層寫：**原文怎麼說／我的歸納／原文沒說**。
> 語料：`data/概念_汗_語料.csv`（60 句）、`data/概念_經絡_語料.csv`（20 句）、`data/概念_經脈_語料.csv`（48 句）。

# 一、汗

## 1. 原文怎麼說

### （1）定義句：汗不是一個東西，是津的出口

〈決氣〉全篇在定義六氣，輪到「津」時說：

> 何謂津？岐伯曰：**腠理發泄，汗出溱溱，是謂津。**

這是全書最關鍵的一句。它沒有定義「汗」，而是**用汗來定義津**：能從腠理發出、成為汗的那部分，就叫津。

同一篇定義「液」時，用的是「淖澤注于骨……皮膚潤澤」，**不從汗走**。可見在靈樞的分類裡：

- **津**＝可外泄為汗者
- **液**＝注骨、補腦髓、潤皮膚而不外泄者

汗不是與津液並列的東西，**汗是津的動詞形態**。

### （2）功能句：汗的開闔由天時與腠理決定

〈五癃津液別〉把人體的液分為五：

> 天寒衣薄，則為溺與氣；**天熱衣厚，則為汗**；悲哀氣并，則為泣；中熱胃緩，則為唾。

同篇講機制：

> 天暑衣厚則腠理開，故汗出。

所以汗的產生，原文給的條件只有兩個：**天時（熱）與衣厚（外因）→ 腠理開**。它沒有說『陽氣蒸騰』『心液外泄』這類後世語彙。

### （3）邊界句：汗與血同源

〈營衛生會〉：

> 夫血之與氣，異名同類……故**奪血者無汗，奪汗者無血**。

這句話的份量在於：它把汗與血放在**同一個存量**上。失血多的人發不出汗，汗出太多的人血會不足——不是比喻，是同一資源的兩個出口。

### （4）預後句：熱病中，汗是邪有出路的證據

〈熱病〉：

> 脉尚盛躁而**不得汗**者，此陽脉之極也，**死**；脉盛躁**得汗靜**者，**生**。

〈邪客〉治失眠：

> 覆杯則卧，**汗出則已矣**。

汗在此不是症狀，而是**正氣能逐邪外出的證明**。得汗＝通路還在；不得汗＝通路已閉。

## 2. 我的歸納

**靈樞的「經絡」，本質是一套『以不可見的主幹來解釋可見的表面現象』的分區系統。**

四個要點：

1. **經脈預設不可見**（伏行分肉，深而不見），其虛實由氣口測知。
2. **可見性是分界線**：浮而常見者為絡脈；但經脈有一處例外——足太陰踝上，因皮薄無所隱。
3. **它的首要用途是判斷與處置**（決死生、處百病、調虛實），不是運輸。
4. **經—絡—孫是分形結構**，且各段「各有所主」，所以刺絡脈要看它結在哪裡。

第 2 點是修正後的版本。先前我只寫『可見的都是絡脈』，漏了那個例外——而那個例外恰恰是最有趣的：**原文自己承認有一處經脈看得到，並給了幾何理由（無所隱／皮薄）。**

## 3. 原文沒說的

這一節比上面更重要。

| 後世常見說法 | 靈樞有無 | 實際出處 |
|---|---|---|
| **汗為心之液** | **無** | 《素問·宣明五氣》『五藏化液：心為汗』 |
| 陽加于陰謂之汗 | **無** | 《素問·陰陽別論》 |
| 五藏各有其汗 | **無** | 同上，屬素問系統 |
| 汗血同源 | 有，但說法不同 | 靈樞作「奪血者無汗，奪汗者無血」，是**存量關係**，不是「同源」的生成論 |

本專案已用字串核對：靈樞全書無「心之液」『陽加于陰』『五藏化液』三語。

> 也就是說，今天最常被引用來解釋汗的那句話，**不在靈樞**。要講『汗為心之液』，得引素問，不能掛在靈樞名下。

## 4. 常見誤解

1. **把汗當成『排毒的水』**——靈樞沒有「毒」的概念框架；汗是津的外泄，奪汗會傷血。
2. **把「汗出則已」當成『出汗就好』**——原文的「得汗」指邪有出路，前提是正氣尚能作汗；虛人強迫發汗，正是「奪汗者無血」。
3. **把五藏配汗**——那是素問的體系，靈樞的五液是溺、汗、泣、唾、水脹，按**誘因**分，不按藏府分。

# 二、經絡（經脈／絡脈／孫絡）

## 1. 原文怎麼說

### （1）功能句：經脈的定義是一句功能宣告

〈經脈〉開篇：

> **經脉者，所以能決死生，處百病，調虚實，不可不通。**

注意它沒有說『經脈是氣血運行的通道』。它說的是三件事：**決死生、處百病、調虛實**——經脈是**判斷與處置的依據**，不是一根管子。

「不可不通」的「通」，在這個語境裡更接近『必須通曉』，而非『必須保持暢通』。同篇下文全是「肺手太陰之脉，起于中焦……」的循行記載，是在教你怎麼通曉它。

### （2）邊界句：可見性——但有一個例外

〈經脈〉有兩處講這件事，**必須合看**。

其一（篇末雷公問）：

> 雷公曰：何以知經脉之與絡脉異也？黃帝曰：**經脉者，常不可見也**，其虛實也，以氣口知之；**脉之見者，皆絡脉也。**

其二（篇首）：

> **經脉十二者，伏行分肉之間，深而不見**；其常見者，**足太陰過於外踝之上，無所隱故也**。諸脉之浮而常見者，皆絡脉也。

（上引依底本作「外踝」。太素作「內踝」，詳下文校勘。）

第一處是通則，第二處給出了**唯一的例外**：十二經脈都伏行於分肉之間，只有足太陰經過踝上那一段看得見（底本作「外踝」，據太素當作「內踝」，見下），因為該處「無所隱」——沒有肌肉可以遮住它。

楊上善注把這個例外說得更清楚：

> 十二經脈及諸絡脈，其不見者謂**十一經**也；其可見者謂足太陰經上行至於踝上，**以其皮薄故見**也；諸餘絡脈皆……

所以正確的表述是：

- **十一經**深伏不見；
- **足太陰踝上一段**因皮薄而可見，是經脈中唯一的例外；
- 其餘**浮而常見者，皆絡脈**。

這裡有一個校勘問題必須交代：

> **底本作「外踝」，太素作「內踝」。**

足太陰脾經行於**內踝前廉**，外踝則為足太陽、足少陽所過。也就是說，底本的「外踝」與「足太陰」自相矛盾，太素的「內踝」才與經文相合，且楊注只說「踝上」而不言內外。

又，張介賓《類經》節引此段時，**逕刪去『足太陰過於踝上』一句**，只留『十二經脈伏行分肉之間深不可見，其脈之浮而可見者皆絡脈』。例外被抹平了——這正是為什麼只讀類經會得到『可見者皆絡脈』的簡化結論。

我最初的歸納也只到這一層，是這一段補正了它。

### （3）層級句：經 → 絡 → 孫，三層

〈脈度〉：

> **經脉為裏，支而横者為絡，絡之別者為孫。**

一句話給了拓撲結構：主幹在裏，分支橫出者為絡，絡再分者為孫。

同篇又給了一個總量：

> 凡都合一十六丈二尺，**此氣之大經隧也**。

「經隧」是氣行的通道，有長度可計。這裡的「氣」是營衛之氣。

### （4）「經絡」作為合稱時，指的是「各有所主」

〈小鍼解〉：

> 皮肉筋脉各有所處者，言**經絡各有所主**也。

〈官鍼〉豹文刺：

> 中脉為故，以取**經絡之血**者。

所以「經絡」合稱時，重點不在結構，而在**分區與分工**：每一段經絡各管一片。

## 2. 我的歸納

**靈樞的「經絡」，本質是一套『以不可見的主幹來解釋可見的表面現象』的分區系統。**

三個要點：

1. **經脈不可見，絡脈可見**——這是原始界定，比任何『氣血通道』的比喻都更貼近原文。
2. **它的首要用途是判斷與處置**（決死生、處百病、調虛實），不是運輸。
3. **經—絡—孫是分形結構**，且各段「各有所主」，所以刺絡脈要看它結在哪裡。

## 3. 原文沒說的

| 後世常見說法 | 靈樞有無 | 說明 |
|---|---|---|
| 經絡是氣血運行的通道 | 部分 | 原文有「經隧」「氣之大經隧」，但**定義句講的是功能（決死生處百病），不是運輸** |
| 十二經脈＋奇經八脈的完整體系 | 部分 | 靈樞有十二經＋督任蹻維的散見記載，但**『奇經八脈』這一組名與完整論述不在靈樞** |
| 經絡堵塞致病 | 無此語 | 原文說「不可不通」，但「通」多作「通曉」解；「不通」指氣血不行，不是現代「堵塞」 |
| 經絡可以解剖驗證 | 無（但有一處例外） | 原文明言經脈「深而不見」，惟足太陰踝上「無所隱故」可見——它承認有一處看得到，並說明為什麼 |

> 最容易被忽略的一點：**靈樞自己說經脈看不見。** 後世爭論『經絡有無實體』，其實原文已經給了立場：可見的是絡脈，經脈常不可見，只能從氣口測其虛實。

## 4. 常見誤解

1. **把「經脈」當「血管」**——原文把可見的血管歸給絡脈，經脈是不可見的那一層。
2. **把「通」當「疏通」**——「不可不通」在〈經脈〉的語境是『不可不通曉』，通篇接著講循行，是在教人認識它。
3. **把經絡當一套靜態管線**——原文的經絡是**分區的、各有所主的**，所以刺法要「按其所過之經」。

# 三、這套方法能推廣到哪些概念

依同樣三步（定義句／功能句／邊界句＋原文沒說），可陸續做：

| 候選 | 為什麼值得做 | 現成語料 |
|---|---|---|
| **氣** | 全書最高頻、最含混；靈樞對「氣」的分類（營、衛、宗、真、濁、清）本身就是一套本體論 | 需先抽 |
| **神** | 本神篇十義已建卡，但「神」與『魂／魄／意／志』的邊界尚未寫 | 已有模組 |
| **血** | 與汗、營、氣三者關係錯綜；「血者神氣也」一句可深挖 | 需抽 |
| **津液** | 與汗高度相關，可與本篇合併成『水液系統』 | 已有模組 |
| **藏府** | 「藏」與「府」的區分在靈樞有明確功能定義 | 已有實體表 |
| **邪** | 虛邪、正邪、奇邪、客氣的分層 | 需抽 |

## 四、方法上的自我限制

1. **「本質」是我歸納的，不是原文自陳。** 原文沒有說『汗的本質是出口狀態』。這是讀後的組織，可能過度。
2. **只用了靈樞**，未系統比較素問。凡標『原文沒說』者，只表示**靈樞沒有**，不表示素問也沒有——相反的兩例（心為汗、陽加于陰）我已註明出自素問。
3. **未用注家。** 楊上善、張介賓對這些句子的解釋未納入；`docs/35` 的類經注層可用，但本次未展開。
4. **語料以句為單位**，跨句的論證（如整篇的結構）可能被切斷。
5. **未經專家審閱。** 『經脈不可見』的解釋、以及「通」作「通曉」解，都是有爭議的讀法，須中醫文獻專家判定。
