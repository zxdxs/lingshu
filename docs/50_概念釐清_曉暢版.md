# 50 概念釐清（曉暢版）

## 開頭：為什麼讀內經會卡住

每個字都認得，合起來不確定它在說什麼。

原因不止一個，但有一個很少被指出來：**這本書幾乎不定義它最常用的詞。**

我數過。「氣」出現七百多次，正面解釋只有二十來句；「脈」出現三百多次，真正的定義**只有一句**；「邪」一百七十多次，連一句都沒有。

反而是「虛」和「實」——各出現一百次上下——有二十句在反覆界定。

為什麼？因為**定義是為了區分**。虛實分不清就沒法下針，所以使勁講；而氣、血、脈、邪是整個系統的背景詞，作者默認你懂。

所以想弄懂這些詞，不能等它給定義，只能看它**怎麼用**。下面就是照這個辦法整理的。

---

## 一、陰陽：有名字，沒有形體

先從最根本的開始，因為這一句會改變你讀後面所有內容的方式。

> **陰陽者，有名而無形**，故數之可十，離之可百，散之可千，推之可萬。（〈陰陽繫日月〉）

**白話**：陰陽這東西，有名字，沒有形體。所以你可以把它數成十個、拆成一百、散成千、推成萬。

這句話厲害在哪裡？它等於說：**陰陽不是兩種東西，是一套分法。**

不是天上有一個陰、地上有一個陽；而是你看任何一件事，都可以問『它的陰面在哪、陽面在哪』。同一件事換個層次，陰陽就換一組。所以它可以「散之可千，推之可萬」——因為它本來就不是固定的東西。

**我的理解是**：陰陽是座標，不是材料。它不佔空間，只定位置。

這一點在讀後面的內容時很有用。凡是看到「陰陽」二字，先問：這裡是在分哪一對？——表裡、晝夜、藏府、血氣，都是不同的分法，不要當成同一組。

**要注意**：很多人引『陰陽者，天地之道也』來說這是靈樞的話。不是。那句在素問，靈樞沒有。靈樞講陰陽，講的是**認識方法**，不是宇宙起源。

## 二、精與神：一個在身體之前，一個在條件之後

### 精：先有它，才有身體

> 兩神相搏，合而成形，**常先身生，是謂精**。（〈決氣〉）
>
> 故**生之來謂之精**。（〈本神〉）

**白話**：男女之精相合，形成形體，而這個東西**總是在身體之前就存在**，這叫精。或者說：生命從哪裡來，那個「來處」就叫精。

兩句話講的是同一件事——**精在「身」之前**。

所以精不是身體裡的一種精華液，而是**發生的起點**。這跟後世說「腎藏精」不衝突，但層次不同：後者講它住在哪，前者講它在時間上的位置。

### 神：六句話，六個意思

這是全書最麻煩的一個詞。同樣是「神」，靈樞在不同地方給了不同的等式：

| 出處 | 原文 | 白話 |
|---|---|---|
| 〈小鍼解〉 | 「神者，正氣也」 | 神就是正氣（與邪相對） |
| 〈本神〉 | 「兩精相搏謂之神」 | 男女之精相合，產生神 |
| 〈平人絕穀〉 | 「神者，水穀之精氣也」 | 神是水穀的精華 |
| 〈天年〉 | 「失神者死，得神者生」 | 神在，人活；神去，人死 |
| 〈天年〉 | 「血氣已和，榮衛已通，五藏已成，神氣舍心，魂魄畢具，乃成為人」 | 血氣和了、營衛通了、五藏成了、魂魄齊了，神才出現 |
| 〈營衛生會〉 | 「血者，神氣也」 | 血的身分就是神氣 |

這六句**不能互相代入**。正氣不是水穀精華；水穀精華不是男女之精相合來的；而「得神者生」的那個神，又不能化約成任何一種物質。

那怎麼辦？

**我的理解是**：靈樞的「神」不是一個東西，而是**一個隨場合換層級的說法**。

- 講扎針時，神＝正氣，是可以補瀉的對象
- 講生命起源時，神＝兩精相搏的結果
- 講養生時，神＝水穀精華，可以充養
- 講生死時，神＝生命的有無，不能操作

而〈天年〉那一句最特別：它說神是**等所有條件都齊了才出現的**。

血氣和、營衛通、五藏成、魂魄具——四件事都到位，神才「舍心」，人才「成為人」。

所以神不是被放進身體裡的，是**湧現**出來的。

**要注意**：這六個意思是我分的層，原文沒有這樣歸類。可能分得太整齊了。

## 三、魂與魄：差別不在高低，在跟誰走

> 隨神往來者謂之魂，並精而出入者謂之魄。（〈本神〉）

**白話**：跟著神來來去去的，叫魂；跟精一起出入的，叫魄。

這一句把魂魄的差別講得很清楚，而且和大家常聽到的說法不太一樣。

常聽到的說法是『魂屬陽、魄屬陰，魂比魄高級』。但原文不是這樣分的——它分的是**依附對象**：魂跟著神，魄跟著精。

所以魂屬「神」那一支，魄屬「精」那一支。不是誰高誰低，是**跟的老闆不同**。

〈本神〉接著往下排了一串：心、意、志、思、慮、智。這是一條**認知生成的鏈條**，從『接觸外物』（任物）一路到『處理外物』（處物）。

**要注意**：這裡要更正一個常見說法——『五藏配五神是素問的』並不對。〈九鍼論〉就寫著：「五藏：心藏神，肺藏魄，肝藏魂，脾藏意，腎藏精志也。」靈樞有配，只是用的字是「藏」。

## 四、氣：像霧，像露

> 何謂氣？岐伯曰：**上焦開發，宣五穀味，熏膚，充身，澤毛，若霧露之溉，是謂氣。**（〈決氣〉）

**白話**：上焦把它打開，把五穀的味道宣散出去，熏皮膚、充身體、潤毛髮，**像霧和露水在灌溉一樣**，這叫氣。

這個比喻值得停一下。

它沒有說氣在「流動」，它說氣在**灌溉**。霧和露有什麼特點？瀰漫、滲透、無孔不入，但又不是水。它沒有一個固定的形狀，卻能到達每一個地方。

這就解釋了為什麼氣可以「熏膚、充身、澤毛」——它不是一個內容物在管子裡跑，而是**一種分布狀態**。

還有一句更要緊的，在講脈診的時候：

> 言實與虛若有若無者，**言實者有氣，虛者無氣也**。（〈小鍼解〉）

**白話**：說實和虛好像有又好像沒有——實就是有氣，虛就是沒有氣。

注意，這是「有」和「無」，不是「多」和「少」。

後世講「氣虛」，我們習慣理解成『氣少了一點』。但靈樞在這一處給的是「無」。當然，臨床上不會真的完全沒有氣，所以這是**定義上的極端**，不是日常描述。但這個極端的設定很重要：它告訴你虛實的性質是**存在與否**，不是程度深淺。

**要注意**：靈樞對「氣」只有一處總定義——〈決氣〉「上焦開發，宣五穀味，熏膚，充身，澤毛，若霧露之溉，是謂氣」，而且是功能性描述。除此之外，它按來源分（穀氣、天氣、地氣）、按分布分（營、衛、宗）、按性質分（清、濁），沒有第二處。

## 五、血：兩種身分

> 何謂血？岐伯曰：**中焦受氣取汁，變化而赤，是謂血。**（〈決氣〉）
>
> **營衛者，精氣也；血者，神氣也。**故血之與氣，異名同類焉。故**奪血者無汗，奪汗者無血**。（〈營衛生會〉）

**白話**：什麼叫血？中焦接受氣、取出汁，變化成紅色，這叫血。……營衛是精氣，血是神氣。所以血和氣，名字不同，其實同類。所以失血的人發不出汗，出汗太多的人血會不足。

第一句講**怎麼來**：受氣、取汁、變紅。是一條生產線。

第二句講**是什麼**：神氣。而且它跟營衛並列：

```
營衛 ＝ 精氣
血   ＝ 神氣
```

這不是『血裡含著神』，是**血的身分就是神氣**。

有了這個等式，「奪血者無汗」才講得通：血和氣是同一份存量的兩種說法，從任何一個出口大量流失，另一個就跟著不夠。

**要注意**：後世常說『血為氣之母』『氣為血之帥』。這兩句靈樞都沒有。靈樞給的是**同一性**（異名同類），不是母子關係。這兩種講法差別很大：母子是兩個東西的關係，同一性是同一個東西的兩面。

## 六、脈：不是管子，是界

> 何謂脈？岐伯曰：**壅遏營氣，令無所避，是謂脈。**（〈決氣〉）
>
> **經脈十二者，伏行分肉之間，深而不見。**（〈經脈〉）

**白話**：什麼叫脈？把營氣堵住、讓它無處可躲，這叫脈。……十二條經脈，藏著走在肌肉與肌肉之間，很深，看不見。

這兩句合起來，會推翻一個很常見的印象。

我們習慣把脈想成水管：有管壁，裡面流著氣血。但原文不是這樣說的。

第一句說脈的功能是「壅遏」——**堵**。如果是管子，該說「容納」；原文說的是「令無所避」，是逼著它無處可逃。管子的作用是通過，界的作用是約束。

第二句說它的位置是「分肉之間」——**肉與肉之間**。不在肉裡，不在肉上，在兩塊肉中間的那個縫裡。

那個縫是什麼？是關係，不是東西。兩塊肌肉分開才有那個縫；它不屬於任何一塊肌肉。

所以**脈是靠位置成立的，不是靠質料成立的**。

這一層讀通了，後面很多話就順了。比如為什麼說『經脈常不可見』——因為它在縫裡，被肉蓋著。而看得見的那些，原文判給了絡脈。

## 七、津與液：一個往外，一個往內

> 何謂津？岐伯曰：**腠理發泄，汗出溱溱，是謂津。**
>
> 何謂液？岐伯曰：**穀入氣滿，淖澤注于骨，骨屬屈伸，洩澤，補益腦髓，皮膚潤澤，是謂液。**（並〈決氣〉）

**白話**：什麼叫津？毛孔打開，汗嘩嘩地出來，這叫津。什麼叫液？穀物入胃、氣滿了，滑潤的東西注進骨頭，讓關節能屈伸，補腦髓，皮膚滋潤，這叫液。

這裡有一件很容易被忽略的事：**原文不是用汗來舉例，是用汗來定義津。**

它沒有先說『津是什麼』，再說『津可以變成汗』；它直接說：能從毛孔出去變成汗的那部分，就叫津。

而液完全不同——液的路線是往裡的：注骨、補腦髓、潤皮膚。它不從毛孔走。

所以津和液的區別，不是稠和稀，是**方向**：一個往外，一個往內。

**要注意**：後世常說『汗為心之液』。靈樞沒有這句。它出自素問（『五藏化液：心為汗』）。靈樞講五液，講的是溺、汗、泣、唾、水脹，是按**什麼原因引起的**來分，不是按哪個臟來分。

## 八、營衛：同一份精氣的兩種走法

> **營出于中焦，衛出于下焦。**（〈營衛生會〉）
>
> **營衛者，精氣也。**（〈營衛生會〉）
>
> 衛氣者，出其悍氣之慓疾，而**先行於四末分肉皮膚之間**而不休者也。（〈邪客〉）

**白話**：營從中焦出，衛從下焦出。營衛就是精氣。衛氣這種東西，帶著強悍快速的氣，先跑到四肢末端、肌肉皮膚之間，不停。

三句話給了三個層次的分別：

1. **從哪裡出**：營從中焦（受氣取汁），衛從下焦（悍氣疾行）
2. **怎麼走**：衛「先行」，而且走到皮膚；營走在脈中
3. **是什麼**：兩個合起來就是「精氣」

第三點最容易被忽略：**營衛不是兩種氣，是同一份精氣的兩種運行方式。**

所以「調營衛」不是『補兩樣東西』，是調整同一份精氣怎麼分布、怎麼走。

**要注意**：靈樞講衛氣，很少講「衛氣虛」。它講的多是運行出問題——『不入於陰』「留於腹中」這一類。用「虧虛」的思路去讀衛氣，會讀不進去。

## 九、藏與府：看動詞

> **五藏者，所以藏精神血氣魂魄者也；六府者，所以化水穀而行津液者也。**（〈本藏〉）

**白話**：五藏，是收藏精神血氣魂魄的地方；六府，是消化水穀、輸送津液的地方。

靈樞分藏府，靠的是**動詞**：

- 藏：藏
- 府：化、行、受

不是位置（都在肚子裡），不是形狀（實心或中空），是**功能動詞**。藏是倉庫，府是流水線。

**要注意**：很多人拿『五藏者，藏精氣而不寫也，故滿而不能實；六府者，傳化物而不藏，故實而不能滿也』來講藏府。那一段是素問的（〈五藏別論〉），靈樞沒有。

靈樞也分藏府，但用的是「藏／化」，不是「藏／寫」。這個差別不小：前者講的是**做什麼**，後者講的是**滿不滿、實不實**。

## 十、三焦：如霧、如漚、如瀆

> 三焦者，**中瀆之府也**，水道出焉，屬膀胱，**是孤之府也**。（〈本輸〉）
>
> **上焦如霧，中焦如漚，下焦如瀆**，此之謂也。（〈營衛生會〉）

**白話**：三焦，是中間那條水道，水從這裡出去，連著膀胱，它是個「孤府」（沒有配對的府）。上焦像霧，中焦像泡著的東西，下焦像水溝。

三焦在靈樞裡，形體上幾乎是空的。它叫「孤之府」——六府都有表裡配對，只有它沒有。描述它的方式，全靠三個比喻：霧、漚、瀆。

霧是瀰漫，漚是浸泡發酵，瀆是溝渠。三個詞都是**狀態和過程**，不是器官。

**我的理解是**：三焦在靈樞裡，最像是**一個功能性的三段**，而不是一個解剖實體。原文用「孤」這個字，其實已經承認了它的特殊。

**要注意**：三焦是什麼，是中醫史上最大的爭論之一。這裡只說靈樞怎麼用它，不裁決它到底是什麼。

## 十一、虛實：有氣與無氣

> 所謂虛則實之者，**氣口虛而當補之也**；滿則泄之者，**氣口盛而當寫之也**。（〈小鍼解〉）
>
> 言實與虛若有若無者，**言實者有氣，虛者無氣也**。（〈小鍼解〉）

**白話**：所謂虛就要補，是說脈口虛就該補；滿就要泄，是說脈口盛就該瀉。……說實和虛好像有又好像沒有，是說實就是有氣，虛就是沒有氣。

操作上，虛實是**脈口的盛與虛**；本體上，是**有氣與無氣**。

**要注意**：靈樞沒有把虛實系統地分成『氣虛、血虛、陰虛、陽虛』。那套四分法是後世慢慢建起來的。靈樞講虛實，主要圍繞脈象和針刺。

## 十二、邪：不是敵人，是來路

**白話**：靈樞裡「邪」出現一百七十多次，其中六十多次直接寫成「邪氣」，另外還有正邪、奇邪、虛邪。

唯一的解釋性句子在〈口問〉：「凡此十二邪者，皆奇邪之走空竅者也」——這是在說十二種症狀都屬於『奇邪走空竅』，不是在下定義。

**我的理解是**：靈樞的「邪」不是一個獨立存在的東西，而是**氣的狀態或來路**：

- 與正氣相對的，叫邪氣
- 從虛風來的，叫虛邪
- 走空竅的，叫奇邪

邪是**來路**，病是**結果**。兩者不是一回事。

**要注意**：靈樞沒有把邪人格化成「外敵」。它更像是在說『這個氣不對勁』，而不是『有個壞東西進來了』。

## 十三、三條線

把上面這些串起來，有三條線。

**第一條：生成線。** 精 → 神 → 魂／魄。條件齊備，神才出現。

**第二條：循環線。** 血 → 氣 → 汗。三者同源，所以「奪血者無汗，奪汗者無血」。任何一個出口開太大，都從同一個存量裡扣。

**第三條：中介線。** 經脈在分肉之間，外合十二經水、內屬五藏六府；三焦是中瀆，水道出焉。它們都是中間項——不屬於任何一端，卻讓兩端相通。

**我的理解是**：靈樞對「中介」的偏愛，可能是這本書最深的一個結構特徵。

---

## 十四、哪些話不是這本書說的

下面這些都是常聽到的說法，但**靈樞裡沒有**：

| 說法 | 實際出處 |
|---|---|
| 汗為心之液 | 素問·宣明五氣 |
| 陰陽者，天地之道也 | 素問·陰陽應象大論 |
| 五藏藏精氣而不寫，六府傳化物而不藏 | 素問·五藏別論 |
| 血為氣之母／氣為血之帥 | 後世 |
| 奇經八脈 | 難經以後 |

反過來，有一句常被當成素問的，其實在靈樞：

> 陰陽者，有名而無形。（〈陰陽繫日月〉）

這一條我自己在寫之前也搞錯了。

為什麼要列這個表？不是為了考據癖。是因為**掛錯書，就會用錯脈絡**。把『汗為心之液』當靈樞的話，你就會用五行藏象去解釋汗；但靈樞解釋汗，用的是腠理開闔和津的走向。兩條路不一樣。

---

## 十五、怎麼用這份東西

1. **先接受『有些詞沒有定義』。** 氣、血、脈、邪都是這樣。不要去找那句不存在的總定義。
2. **看它跟誰對舉。** 營對衛，津對液，藏對府，經對絡。對舉的地方就是邊界所在。
3. **看它的動詞。** 是「藏」還是「化」？是「壅遏」還是「容納」？動詞比形容詞可靠。
4. **區分「原文」和「後世」。** 上面第十四節那張表可以用來擋掉一半的混淆。
5. **我的解釋只是解釋。** 凡是『我的理解是』，你都可以不同意。

## 附：這份東西是怎麼做出來的

不是憑印象挑句子。做法是：

1. 把八十一篇切成句子
2. 對每個概念，抽出四類材料：定義句、動態句（含行、伏、出、入等）、共現概念、前後接字
3. 從材料裡找張力——哪裡說法不一致、哪裡特別具體、哪裡完全空白
4. 才開始寫

工具在 `scripts/concept_dossier.py`，語料在 `data/概念檔案/`。二十七個概念的檔案都在裡面，你可以自己翻。
