# 53 皮肉筋脈骨：靈樞給身體的第一個比喻

續 `docs/52`。皮、肉、筋、骨四者合計出現五百八十次，一句實質定義都沒有——但〈經脈〉開篇就給了它們一幅圖。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍與我自撰的詞。

---

## 一、開篇就是一座建築

〈經脈〉開頭，黃帝講人怎麼生成，六句話：

> 人始生，先成精，精成而腦髓生，**骨爲榦，脉爲營，筋爲剛，肉爲牆，皮膚堅而毛髮長**，穀入于胃，脉道以通，血氣乃行。

**白話**：人開始生成，先有精；精成了，腦髓就生出來；骨像主幹，脈像經營，筋像剛勁的索，肉像牆，皮膚堅實而毛髮長出來；穀物入胃，脈道就通了，血氣開始運行。

這是全書對身體最完整的一次比喻，而且它是一個**建築隱喻**：

| 原文 | 比喻 | 功能 |
|---|---|---|
| 骨爲**榦** | 主幹 | 立起身體 |
| 脉爲**營** | 經營、周流 | 輸布 |
| 筋爲**剛** | 剛勁的索 | 約束、牽引 |
| 肉爲**牆** | 牆垣 | 蓄藏、護衛 |
| 皮膚**堅** | 外殼 | 固外 |

張介賓注得很直接：『骨為榦，猶木之有榦、土之有石，故能立其身』『肉為牆，肉象墻垣，故能蓄藏血氣』。

**我的理解是**：這不是五種組織的清單，是一套**營造順序**。先立主幹（骨），再通管線（脈），再上索具（筋），再砌牆（肉），最後封外殼（皮膚）。五者各司一職，合起來才「成形」。

而且注意最後一句：「穀入于胃，脉道以通，血氣乃行」——**材料（穀）進來了，這座建築才開始運轉。** 前面講的是結構，後面講的是營運。

## 二、五合與五應：兩套對應，一處矛盾

〈本藏〉把皮肉筋骨接上了藏府，但用了**兩套**講法。

### 第一套：五合——『某者，某其應』

> 肺合大腸，大腸者，**皮**其應；心合小腸，小腸者，**脉**其應；肝合膽，膽者，**筋**其應；脾合胃，胃者，**肉**其應；腎合三焦膀胱，三焦膀胱者，**腠理毫毛**其應。

**白話**：肺與大腸相合，大腸對應的是皮；心與小腸相合，對應的是脈；肝與膽相合，對應的是筋；脾與胃相合，對應的是肉；腎與三焦膀胱相合，對應的是腠理毫毛。

### 第二套：五應——直接講「某應某」

同一篇又說：

> **肺應皮**
>
> **心應脉**
>
> **脾應肉**
>
> **肝應爪**
>
> **腎應骨**

### 矛盾在哪

兩套對不起來：

| 藏 | 五合所應 | 五應所應 |
|---|---|---|
| 肺 | 皮 | 皮 ✓ |
| 心 | 脈 | 脈 ✓ |
| 脾 | 肉 | 肉 ✓ |
| **肝** | **筋** | **爪** ✗ |
| **腎** | **腠理毫毛** | **骨** ✗ |

前三者一致，後兩者換了。

**我的理解是**：這不是錯簡，是**兩個不同的觀察層次**。

「合」講的是**表裡配偶**（肺—大腸、肝—膽……），所應者是那個配偶關係在體表的對應。
「應」講的是**診候**（從外面看裡面），所以要挑看得見、摸得著的東西——爪甲看得出厚薄色澤，骨看得出密理厚皮。

換句話說：**「合」回答『它屬於誰』，「應」回答『怎麼看出來』。** 肝的筋看不見，但爪甲看得見；腎的骨在裡面，但皮理毫毛看得見。

同篇接著就是證據：『肝應爪，爪厚色黃者膽厚……腎應骨，密理厚皮者三焦膀胱厚』。它用爪甲判斷膽，用皮理毫毛判斷三焦膀胱。**所應者其實是『可觀察的代理』。**

## 三、四者各論

### 皮：最外面的一層，所以刺得最淺

皮是肺之應（見上）。它對應的刺法也最淺：

> 一曰**半刺**，半刺者，淺內而疾發鍼，無鍼傷肉，如拔毛狀，**以取皮氣，此肺之應也**。
>
> 七曰**毛刺**，毛刺者，**刺浮痹皮膚**也。（並〈官鍼〉）

**白話**：半刺，淺淺扎進去趕快拔出來，不傷肉，像拔毛一樣，用來取皮氣，這是肺的對應。毛刺，用來刺皮膚表面的痹。

注意「無鍼傷肉」和「如拔毛狀」——**皮有它自己的刺法，特點是絕不深入。** 這說明皮在靈樞裡不是包裝紙，是一個有獨立功能的層。

### 肉：牆，也是分肉之間

（詳見 `docs/52` 第二節。）

肉的功能是「牆」——蓄藏。但靈樞講「肉」，更常講的是 **「分肉之間」**：那個肌肉與肌肉之間的縫。

它是經脈走的地方（「伏行分肉之間」），是穀氣出來的地方（「已入分肉之間，則穀氣出」），有專門的「分刺」。

**我的理解是**：肉在靈樞裡有兩個身分——作為整體，它是牆；作為間隙，它是通道。**牆與縫，是同一種組織的兩面。**

### 筋：唯一有獨立系統的

皮、肉、骨都沒有專篇，**筋有**——〈經筋〉一整篇。

這一篇的體例和〈經脈〉很像（按手足三陰三陽分），但走的是另一套路線：不是『起於某處、屬某藏』，而是『起於某處、**結**於某處』。全篇用「結」字串起來。

治法也不同：

> **燔鍼劫刺，以知爲數，以痛爲輸**。（〈經筋〉）

**白話**：用燒過的針快速刺，以見效為度，以痛處為穴。

**我的理解是**：筋的病不在藏府，在**牽引與結聚**。所以治法是「以痛為輸」——哪裡痛就刺哪裡，不像經脈要辨證取穴。

筋與肝的關係，〈經脈〉說得直接：「肝者，筋之合也」「筋者，聚于陰氣而脉絡于舌本也」。

### 骨：唯一可以量的

骨有專篇，但和其他三者不同——〈骨度〉是一篇**測量手冊**：

> 人長七尺五寸者，其骨節之大小長短各幾何？（〈骨度〉）

然後逐段給尺寸（見 `docs/37`）。

**我的理解是**：骨在靈樞裡的特殊性，在於它是**唯一可以客觀測量的結構**。皮可以看，肉可以摸，筋可以按，但只有骨能給出確定的寸數。所以它成了度量的基準——「先度其骨節之大小廣狹長短，而脉度定矣」。

骨與腎的關係：「腎應骨」（〈本藏〉）；骨的生成：「精成而腦髓生」（〈經脈〉）。

## 四、原文沒說的

| 常見說法 | 靈樞 |
|---|---|
| 皮、肉、筋、骨、脈的實質定義（由什麼構成） | **沒有**。只有比喻與功能 |
| 五體與五藏的完整配屬 | **有**：九鍼論「心主脉，肺主皮，肝主筋，脾主肌，腎主骨」。本藏另給兩套（五合、五應），彼此不合 |
| 骨為幹、脈為營、筋為剛、肉為牆、皮膚為城 | 前四項有，**『皮膚為城』沒有**——原文作「皮膚堅而毛髮長」 |
| 解剖學描述 | **沒有**。除了〈骨度〉的尺寸與〈腸胃〉的容量 |

最後一條值得說：靈樞對身體的興趣不在『它長什麼樣』，而在『它怎麼運作』與『怎麼從外面看出裡面』。所以它給的是比喻、是對應、是刺法，不是解剖圖。

## 五、一個我自己的教訓

寫這一節時，我先用「骨為幹」去查底本，查不到，一度以為這一段不在靈樞。

其實在——只是底本寫作「**骨爲榦**」（爲、榦都是異體）。我用通行字去搜，就漏了。

這已經是本專案第幾次踩同一個坑了：**異體字讓搜尋失效，而失效看起來像『原文沒有』。** 差一點就把『靈樞沒有這段』寫進文件。

後來是靠太素與類經的引文才發現的——它們把這段完整引出來，還註明是靈樞經脈。**見證本不只是校字用的，它們還能救回你以為不存在的東西。**
