## 二、三個要點

### （1）「生成」與「身分」是兩回事

〈決氣〉講**怎麼造出來**：

> 中焦受氣取汁，變化而赤，是謂血。

〈營衛生會〉講**它是什麼**：

> 血者，神氣也。故血之與氣，異名同類焉。

這兩句不能互相取代。製造流程回答「從哪來」，同一性斷言回答「算什麼」。

**我的理解是**：正因為有第二句，第一句的產物才不只是『紅色的液體』——它同時是神氣。這也是為什麼「奪血者無汗」能成立：同一個東西，兩個名字。

### （2）存量關係，不是生成關係

> 奪血者無汗，奪汗者無血。

很多人把它讀成『血汗同源』，然後推論『汗為血所化』。

但原文的句式是『奪……者無……』，講的是**存量**：從血的帳戶扣多了，汗的帳戶就空。這是**守恆**，不是**生成**。

**我的理解是**：生成關係是『A 變成 B』；存量關係是『A 和 B 從同一池子裡取』。靈樞說的是後者。

### （3）灌注次序，與結構描述方向相反

〈癰疽〉講血的灌注：

> 血和則**孫脉先滿溢，乃注於絡脉；皆盈，乃注於經脉**。

方向是：孫 → 絡 → 經（**由小到大**）。

而〈脈度〉講結構：

> 經脉為裏，支而横者為絡，絡之別者為孫。

方向是：經 → 絡 → 孫（**由大到小**）。

**這不是矛盾，是兩種描述。** 一個講**結構的分支**，一個講**充盈的次序**。

但要注意：這也意味著『經脈是主幹，絡脈是分支』只是結構上的說法；**在充盈的動態裡，血是先填滿末梢，再回灌主幹的**。

**我的理解是**：這一對描述合起來，才是完整的循環——像水先注滿毛細，才漲回主渠。

## 三、與其他概念的接點

| 接點 | 內容 | 出處 |
|---|---|---|
| 血 ↔ 神 | 血者，神氣也（**同一性**，非比喻） | 營衛生會 |
| 血 ↔ 氣 | 異名同類；奪此失彼 | 營衛生會 |
| 血 ↔ 營 | 營氣泌津液，注脈化血 | 邪客 |
| 血 ↔ 津液 | 皆水穀所化（**歸納**，非原文直述） | 決氣、營衛生會並參 |
| 血 ↔ 脈 | 脈壅遏營氣；血在脈中灌注 | 決氣、癰疽 |
| 血 ↔ 汗 | 存量互通 | 營衛生會 |

**注意最後一行之外，還有一條虛線**：血與津液的「同源」是我並參兩篇得出的，原文沒有直說。這條在概念地圖裡也標為虛線。

## 四、限制

1. **〔我的理解是〕全部是歸納。** 原文沒有說「七層」『存量關係』『由小到大』。
2. **七層是我切的。** 可以切得更細（例如把「血脫」拆成證候與脈象）或更粗。
3. **「血氣」是否算血的層次，可以討論。** 它其實是「血＋氣」的合稱，我放在第七層是為了完整，不是說它等於血。
4. **未處理血與精的關係**（〈本神〉有「精傷則骨痠痿厥」，但未直接論血精關係）。
5. **未用注家。**
