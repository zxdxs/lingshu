# 85 評分器：把『同一個字』變成程式聽得懂的話

續 `docs/83`。那一篇只處理了 88 題單字答案；這一篇處理整批填空題，並補上真正能判分的東西。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、上一輪留下的洞

`docs/83` 建了 `data/同義答案表.csv`，22 條，只覆蓋 88 題單字答案。

但填空題一共 **600 題**：

| 答案長度 | 題數 | 上一輪有變體嗎 |
|---|---:|---|
| 1 字 | 88 | 有 24 題（其餘字形無異體） |
| 2 字以上 | 512 | **沒有** |

而且更根本的問題是：CSV 裡有一欄『可接受答案』，**但沒有任何東西在讀它**。Anki 不讀，題庫也不評分。它只是給人看的。

〔歸〕一份『可以接受』的清單，如果沒有判分器，等於一句客氣話。

---

## 二、兩個機制，各管一段

| 機制 | 做什麼 | 給誰用 |
|---|---|---|
| **列舉**：`可接受答案` 欄 | 把已知等價寫法一題一題列出來 | 下載 CSV 自己出題的人 |
| **正規化**：`scripts/grade.py` | 比對前先把字收斂成同一個 | 寫程式判分的人 |

兩者不是重複，是兩種介面：一個給人看，一個給程式跑。

---

## 三、正規化怎麼做

```python
def normalize(s):
    s = NFKC(s)                      # 全形→半形
    s = 去掉標點空白
    s = VAR.get(ch, ch) for ch          # 異體字收斂
```

三行，但每一行都有理由：

1. **NFKC**：學員從 PDF 複製，常帶全形數字（３）、全形括號。
2. **去標點空白**：原文的「，」「。」不是答案的一部分。
3. **異體收斂**：這一步讓「脉」「脈」「衇」變成同一個字。

於是：

| 學員寫 | 正解 | 判定 | 理由 |
|---|---|---|---|
| 隂谷 | 陰谷 | ✅ | 異體 |
| 陰谷。 | 陰谷 | ✅ | 標點 |
| 清氣 | 清 | ❌ | 多一個字 |
| 腎 | 腎 | ✅ | 同字 |

**『多一個字』仍然不收**——這條線從 `docs/83` 到現在沒有動：字形可以變，意思不可以加。

## 四、列舉也補齊了

生成器現在在產題時，用本庫異體字表逐字換寫，算出每一題的等價寫法：

```
Q-LS002-脾-合  陰之陵泉 → 可接受：隂之陵泉
Q-LS002-腎-合  陰谷     → 可接受：隂谷
```

結果：**130 題有可接受答案**（其中 24 題來自同義表、106 題來自異體換寫）。題庫全表的第 15 欄現在有實際內容，不再只是單字題的點綴。

## 五、自我測試

評分器最怕『看起來會動』。所以寫了 `--selftest`，用題庫自己考自己：

| 測項 | 樣本 | 結果 |
|---|---:|---:|
| 正解必過 | 600 | 600 ✅ |
| 異體寫法必過 | 178 | 178 ✅ |
| **同篇其他題的答案必不過** | 13,182 | **誤收 0** ✅ |

第三項是關鍵：拿同一篇裡別題的答案去填，**一題都沒被誤收**。這證明「寬容」沒有寬到把不同意義的答案吃進來。

跑法：

```
python3 scripts/grade.py
填空題 600｜正解通過 600｜異體樣本 178｜負樣本 13182（誤收 0）｜失敗 0
```

## 六、給 Anki／前端的東西

正規化邏輯在 Python 裡，Anki 用不到。所以另外輸出 `export/異體映射.json`：

```json
{
 "說明": "異體等價組：同組字在評分時視為同一個字",
 "映射": {
   "于": ["于", "扵", "於"],
   "為": ["為", "爲"],
   "陰": ["陰", "隂"]
 }
}
```

**29 組。** 前端要做的只有三件事：NFKC、去標點、查表替字——和 `grade.py` 完全一樣，兩邊不會分歧。

## 七、還沒解決的

1. **簡體只覆蓋 22 條（單字題）。** 512 題多字答案如果有人用簡體作答，仍會被判錯。要做就得建一張完整的繁簡表，而這正是 `docs/83` 拒絕 OpenCC 的理由（乾／干會出事）。**暫時把它當成『本教材以繁體作答』的明示前提。**
2. **沒有錯字容錯。** 「三斗五升」寫成『三斗五鬥』會被判錯。這是刻意的：容錯與放水只差一線，而這批題的答案是原文，寧可嚴格。
3. **Anki 端還是要自訂模板。** 我只給了映射與規則，沒給 .apkg。使用者得自己在 Anki 的填空卡模板裡寫 JS。**這一輪沒有做出『開箱即用』的 Anki 卡片。**
4. **負樣本只取自同篇答案。** 它能抓『收了不該收的』，不能證明『所有錯答都被擋』——例如學員寫一個同義改寫（「根本」對「本」），會被判錯，而這是我要的結果，不是漏判。

---

## 八、一句話

上一輪我列了一張『可以接受』的清單；這一輪才把它接到會判分的東西上。**清單是承諾，正規化才是兌現**——而自我測試的第三欄（負樣本誤收 0）是唯一能證明它沒有寬到失守的證據。
