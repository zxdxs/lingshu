# 87 節引還原：163 段裡還原了 126 段

續 `docs/86`。那一輪留下一個選項：『163 段節引要不要還原』。這一篇動手，並說明為什麼只能還原一部分。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、問題在哪裡

`docs/82` 把題面引文分三類：真錯（已清零）、夾註（已清零）、壓縮／拼接（163 段，標記為節引）。

「節引」的處理是加一句說明，不是修。它誠實，但代價是：**163 道題的引號裡，沒有一句可以逐字對回原文。**

例如：

```
《靈樞·本輸》：『肺溜於____，為滎。』
```

原文是「肺出於少商……溜于魚際……為滎」。「肺」與「溜於」在原文裡不相鄰，是模板把兩個片段黏起來的。

---

## 二、還原的辦法：把引文起點移到最近的邊界

不重寫內容，只換**引文的起點**：從答案往前找最近的「為／爲」（找不到就找『出／溜／注／行／入／過』），切到答案為止。

```
原文：肺出於少商，少商者，手大指端內側也，為井木；溜于魚際，魚際者，手魚也，為滎。
舊：  『肺溜於____，為滎』     ← 拼接
新：  「為井木；溜于____」      ← 逐字（經名移到引號外：肺經）
```

同樣的辦法用在五處模板：

| 模板 | 舊 | 新 |
|---|---|---|
| 本輸五輸穴 | 『肺溜於____，為滎』 | 肺經：「為井木；溜于____」 |
| 邪氣藏府病形 | 『心脉微急，為____』 | 心脉：「微急，為____」 |
| 陰陽二十五人 | 『大角之為人，比於____』 | 「大角之人，比於____」 |
| 雜病 | 『厥挾脊而痛至頂』，取____ | 「……腰脊强取____」 |
| 五亂 | 『氣在心者，取之____』 | 「氣在於心者，取之____」 |

〔歸〕關鍵不是『改得漂亮』，是**讓切點落在原文的句讀邊界上**。只要起點與終點都在原文裡，中間就不可能有拼接。

---

## 三、三個必須一起修的細節

### （1）經名不能留在引號裡

原文的「溜于」「注于」「行于」「入于」前面沒有藏名——藏名只在每組的第一句出現。

所以把經名移到引號外：**《靈樞·本輸》肺經：「為井木；溜于____」**。引號內逐字，引號外是題幹。

### （2）太／大：穴名的異寫

底本作「大淵」「大衝」「大谿」，教材作「太淵」「太衝」「太谿」。

加了別名表：題面按底本（大淵）挖空，答案欄保留教材寫法（太淵），並把另一種寫法放進『可接受答案』。三題因此多了一組可接受答案。

### （3）朿／束

底本「朿骨」，教材「束骨」——一個字的異體，補進異體字表後，膀胱經的五輸題才切得出來。

## 五、剩下 37 段：不是不修，是還不到

分佈在 15 篇，每篇 1–5 段：五亂 5、論疾診尺 4、官鍼 4、終始 4、順氣一日 3、陰陽二十五人 3、衛氣行 3，其餘各 1–2。

三種情況：

1. **模板用的是「整理過」的標籤**，不是原文句子（例如官鍼『病在大膿』、論疾診尺『目白色者』）。
2. **原文本身有殘缺或異寫**，硬切會切出半句（例如癲狂『狂言驚笑』）。
3. **答案太長、切點太遠**，切出來會失去辨識度。

〔歸〕這 37 段我選擇留著並標記，而不是硬切。**能逐字的就逐字，不能的至少承認。**

## 七、一句話

節引的問題不在『少引了幾個字』，在**引號許諾了逐字，而它沒有做到**。這一輪做的不是把話補全，是把切點挪到句子邊界上——**同樣的內容，換一個切法，它就變成真的了。**
