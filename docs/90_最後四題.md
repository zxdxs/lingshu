# 90 最後四題：標籤、補句、與一篇走錯的

續 `docs/88`。那一輪結尾留了『4 題以標籤作引文』；這一輪處理它們。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

| `Q-LS002-MER-太衝` | 腧穴「太衝」歸屬於哪一經？ | 「太衝」是穴名標籤，不是原文句 | 改為『太衝』 |

〔歸〕三種病要三種藥：標籤改引號、缺句補句、不是這本書的拿掉。**不能用同一招處理。**

## 二、脈度那一題：為什麼要補「從手至頭」

原題把「手之六陽」與「長」接在一起：

```
『手之六陽，長____』          ← 拼接
「手之六陽，從手至頭，長____」  ← 底本原句
```

補回來之後，題面變長，但它現在可以逐字對回原文——而且「從手至頭」本身就是這題要考的知識（脈度走向）。

---

## 三、歲露論那一題：又一個『不是靈樞』

「衛氣一日一夜常大會於風府」這句，查遍 81 篇都沒有。它在《素問·瘧論》。

有意思的是：**這句話在模組裡有「原文」欄**，而且寫得整整齊齊。模組自己也是錯的——它把素問的句子當成靈樞收進來了。

〔歸〕這說明一件事：**模組的「原文」欄不是保證，只是意圖。** 要保證，只能逐句回底本核。這次是靠 `docs/88` 那套逐段比對抓出來的。

處置：剔除。同篇其餘六題（三虛、三實、月滿、月郭空等）的「問」是自撰的問句，全部改為『』，不再假裝是原文。

題數 912 → **911**。

## 四、順手修掉一個假數字

`docs/88` 之後，生成器的輸出一直印『題面節引 6 題』，但題庫裡實際上 0 題帶標記。

原因：**標記在剔除之前執行**——那 6 題標記的正好是後來被剔掉的 6 題（目色 4、金形 2）。標了，然後刪了，計數卻留著。

把剔除移到標記之前，輸出變成：

```
生成 911 題；題面節引 0 題；有可接受答案 335 題
```

〔歸〕這是一個很小但很典型的錯誤：**兩個步驟的順序，決定計數的意義。** 標記在刪除之前，等於在數不存在的東西。
