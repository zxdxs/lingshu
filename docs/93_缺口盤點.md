# 93 還有哪些值得做：一次缺口盤點

不是新研究，是把整個專案翻一遍，找出**到現在還沒想到、或想到了沒做**的事。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

## 一、先講最刺眼的一條

**我從頭到尾只驗過題面的引文，沒驗過答案。**

這件事直到寫這篇才想到。查下去：

```
填空題 593｜答案不在所標篇目 45（7.6%）
```

分佈：

| 篇 | 條數 | 型態 |
|---|---:|---|
| 陰陽二十五人 | 20 | 答案是把原文兩截併起來的標籤（『左足少陽之上』） |
| 營氣 | 12 | 答案寫經名全稱（「足陽明胃」），原文只作「足陽明」 |
| 四時氣、終始、本輸等 | 13 | 大字／太字異寫、跨句拼接 |

〔歸〕題面 645 段全逐字，**答案卻有 45 條不是原文字串**。這不是錯，是**從沒定義過『答案要不要逐字』**——而這個定義，決定了這批題是「背原文」還是「記概念」。

## 三、我認為最該先做的三件

### 第一：答案層的政策與稽核（#1）

因為它是**唯一還沒被驗過的一層**，而且一驗就出現 45 條。

要處理的不是 45 個錯字，是**一個沒被定義的問題**：填空題的答案，要求『原文逐字』還是『概念正確』？

- 若要求逐字：二十五年人的 20 題要改成挖整句（題面變長），營氣 12 題要改答案寫法。
- 若接受概念：那就要在題目上標明『答案為整理語』，不能讓它看起來像原文。

〔歸〕兩種都可以，但**不能不選**——現在是第三種：題面嚴格逐字、答案默許改寫，讀者無從得知界線在哪。

### 第二：防漂移（#2 #3 #4 #5 #6 #7）

這六條全是『便宜且會持續惡化』的：

- `git init` + 首次提交（十分鐘）；
- 一個 `make check` 跑四支稽核＋計數比對；
- README 數字改由腳本產生，不再手寫；
- 篇名統一（脈度／脉度 等三組）；
- 重複題面去重；
- README 自動列出全部 docs。

〔歸〕這些不是內容工作，是**讓內容不再無聲腐爛**。現在的狀態是：每次改動都可能讓某個數字過時，而沒有人會發現。

### 第三：覆蓋與題型（#8 #9）

- 16 篇只有 1–2 題，等於沒練；
- 53% 是 remember，apply 只有 8%——這批材料最該練的『看到證候能判斷』，幾乎沒有題。

這一條成本最高（要設計新題型、可能要做案例題），但**對自學者的實際幫助最大**。

## 四、更遠但值得記下的

- **甲乙經**：目前校勘靠『蕭延平引甲乙』間接得知，若能取得全文，三源變四源。
- **同文篇對照表**：靈樞與素問重疊的篇（病本＝標本病論、刺節真邪部分等），是跨書閱讀最實用的入口，成本低。
- **學習路徑**：以『一日行程』『五藏病變』為主題的 8–10 週課表，把 81 篇重新排序。
- **列印版**：把每篇的 L0＋音釋＋模組要點排成 A4，很多人還是用紙。

## 五、一句話

這份清單裡最貴的一條不是『缺甲乙經』，是**『答案層從來沒有政策』**——因為它不需要花錢、不需要訪書，只需要有人停下來問一句：這 593 個答案，到底要逐字，還是要正確就好。
