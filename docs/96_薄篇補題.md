# 96 薄篇補題：先把空白填掉

續 `docs/93` 的第三優先（覆蓋與題型）。這一輪只做覆蓋的一半，並說明為什麼題型沒有動。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、問題長什麼樣

81 篇、900 題，平均 11.5 題／篇。但平均數會騙人：

```
16 篇各只有 1 題
本輸 128 題（14%）
```

〔歸〕這不是『分配不均』，是**十六篇等於沒練**。自學者讀完〈周痹〉，只有一道題可以檢驗自己。

---

## 二、做法：一個模組，32 條

新增 `data/模組_薄篇.json`：十六篇各取**兩句原文**，每句只挖一處。

| 篇 | 取句（例） |
|---|---|
| 6 壽夭剛柔 | 「在內者，五藏為陰，六府爲陽」／「病在陰之陰者，刺陰之滎輸」 |
| 20 五邪 | 「邪在肺，則病皮膚痛，寒熱，上氣喘」／「皆調于三里」 |
| 27 周痹 | 「周痹者，在于血脉之中，隨脉以上」／「痛雖已止，必刺其處」 |
| 47 本藏 | 「五藏者，所以藏精神血氣魂魄者也」／「衛氣者，所以温分肉，充皮膚」 |
| 58 賊風 | 「此皆嘗有所傷于濕氣，藏于血脉之中」／「視之不見，聽而不聞」 |
| 68 上膈 | 「氣爲上膈者，食飲入而還出」／「微按其癰…先淺刺其傍」 |
| 80 大惑 | 「五藏六府之精氣，皆上注於目而為之精」／「目者，五藏六府之精也」 |

選句標準只有三條：

1. **該篇的樞紐句**（不是冷僻句）；
2. **答案在句中唯一**（不會有兩個空可填）；
3. **句與答案都能逐字回底本**。

第三條是機器驗的：32 條全部通過，才寫進檔案。

---

## 三、驗證

| 檢查 | 結果 |
|---|---|
| 32 條引文逐字 | 0 不符 |
| 32 條答案為原文 | 是（答案類型：原文 +32） |
| 評分器 | 615 填空全過、負樣本 12,710 誤收 0 |
| 重複題面 | 0 |

題數 900 → **932**；填空 583 → 615。

---

## 四、效果與限度

| 指標 | 前 | 後 |
|---|---:|---:|
| 最少的篇 | 1 題 | **3 題** |
| 平均 | 11.1 | 11.5 |
| remember 佔比 | 52% | **50%** |
| understand 佔比 | 38% | 40% |
| apply 佔比 | 8% | 8% |

〔歸〕**三題仍然很少。** 這一輪做到的是『不再空白』，不是「練得夠」。要讓十六篇達到平均水準，每篇還需 8–9 題，而且不能全是填空。

---

## 五、為什麼題型沒有一起動

`docs/93` 把『題型偏記憶』與『覆蓋不均』列在同一條，但它們的解法完全不同：

- 覆蓋：只要肯讀原文、肯逐句核對，可以機械地補。
- 題型：apply 與 evaluate 的題目需要**臨床情境**——『此人此證，當取何經、先治何臟』。這種題的干擾項必須是『同樣合理但錯』的選項，不是隨機抽其他條文。

〔歸〕我可以寫出形式上的應用題（例如把禁忌條文改問句），但那種題**看起來是應用，實際上還是背誦**。真正需要的是懂臨床的人來設計案例——這是 `docs/42` 列的『AI 無能為力』之一。

所以這一輪只補覆蓋，並在題型上留白：**寧可承認只做了半件事，不要用形式上的應用題假裝做完了。**

---

## 六、下一步（若要繼續）

1. **把十六篇補到 5–6 題**（再取 3–4 句／篇），仍是機械工作，成本低。
2. **選 2–3 篇做「案例題」樣板**（例如五心痛、五亂、厥病），由懂臨床的人寫 5 題，作為其餘篇的模板。
3. **難度分層**：目前的 remember／understand 比例是自然結果，不是設計結果；若要按難度排序學習，得先有人作答。

---

## 七、一句話

『覆蓋 81/81』這句話原本是真的，但它的意思是『每篇至少一題』——**一題的覆蓋，跟沒有一樣。** 這一輪把十六個 1 變成 3，然後停下來，因為下一個數量級不是靠機械補題能解決的。
