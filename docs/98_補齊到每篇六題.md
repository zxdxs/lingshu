# 98 補齊到『每篇至少六題』

續 `docs/97`。那一輪把十六篇補到六題，但補完之後又冒出新的低點：13、35 只有 3 題，23 有 4 題。這一輪把地板抬到六。
**引號規矩同前**：「」只給《靈樞》原文，經機器驗證；『』給其他典籍、注家與我自撰的詞。

---

## 一、一個會反覆出現的現象

補完十六篇，最低的變成另十篇：

```
13 經筋 3｜35 脹論 3｜23 熱病 4｜38、46、48、57、61、63、75 各 5
```

〔歸〕這不是「補不完」，是**補題會不斷暴露新的低點**。只要標準是『相對平均』，永遠補不完；標準要改成**絕對下限**。

所以這一輪的目標不是『追上平均 12.7』，是『**每一篇至少六題**』——一個可以宣告完成的地板。

## 四、Bloom 的真相

```
remember 470（46%）｜understand 463（45%）｜apply 79（8%）｜evaluate 19（2%）
```

補了 30 題，remember 一題沒動——因為新題都是『讀原文、填關鍵詞』，屬於 understand。

〔歸〕**補覆蓋不會改善題型分佈。** 這兩件事的關係是：補覆蓋讓『每篇都有題』，補題型讓『每題都有用』。前者可以機械做，後者不行。

---

## 五、到這裡可以停下的理由

1. **地板已達標**：81 篇 ≥6 題，可宣告完成。
2. **繼續補的邊際效益低**：從 6 到 12 只是更多同型題，不會產生新的學習行為。
3. **下一個真正的門檻是題型**：apply 只有 8%，而這需要人寫案例（`docs/97` 的管線已備）。
