# 匯出檔說明

三個檔案，用途不同。

| 檔案 | 內容 | 用途 |
|---|---|---|
| `anki_靈樞.csv` | 911 張卡片 | 匯入 Anki 背誦／自測 |
| `靈樞_填空.apkg` | 593 張填空卡 | 直接匯入 Anki，正面可輸入並即時判定（異體容錯） |
| `題庫_全.csv` | 911 列全欄位 | Excel 篩選、檢查、二次加工 |
| `索引.csv` | 834 條實體 | 查『某穴／某經／某藏府出現在哪幾篇』 |

---

## 一、Anki 匯入

1. Anki → 檔案 → 匯入
2. 選 `anki_靈樞.csv`
3. 欄位對應：**欄位 1 → 正面，欄位 2 → 背面，欄位 3 → 標籤**
4. 牌組型別選「基礎」

檔案開頭有三行指令，Anki 2.1.50 以上會自動讀取：

```
#separator:Comma
#html:true
#tags column:3
```

若你的 Anki 版本較舊而不認得這三行，把它們刪掉再匯入，並手動指定欄位。

### 標籤結構

每張卡帶五到六個標籤，可用來建篩選牌組：

| 標籤 | 例 | 用途 |
|---|---|---|
| `篇_ＸＸ` | `篇_本輸` | 按篇複習 |
| `型_ＸＸ` | `型_mcq` | 按題型 |
| `層_ＸＸ` | `層_L0` | L0＝原文直引，L1＝歸納 |
| `Bloom_ＸＸ` | `Bloom_remember` | 按認知層級 |
| `類_ＸＸ` | `類_注→經` | 按知識類型 |

例如只想練理解題：`tag:Bloom_understand`。
只想練有註家依據的：`tag:類_注→經`。

## 二、題型在卡片上長什麼樣

**填空**（587 張）

> 正面：`《靈樞·本輸》：『肺出於____，為井。』`
> 背面：`少商`　／　《靈樞·本輸》

**選擇**（291 張）

> 正面：`腧穴「少商」歸屬於下列哪一經？`
> 　　　`A. 腎　B. 心　C. 小腸　D. 肺`
> 背面：`正解：D. 肺`　／　《靈樞·本輸》

選項順序依 `item_id` 決定性洗牌——**每次匯出順序相同**，不會今天 D 明天 B。

**辨誤**（19 張）

> 正面：陳述一句常見誤解
> 背面：是否成立、據何而言

## 三、需要知道的事

### 卡片本身帶著限制

- **L1 卡片（51 張）** 背面標 `自撰（無外部權威）` 或 `有註家對應注可參`。前者是專案自己概括的，可信度低於後者，請自己掂量。
- **注→經 卡片（111 張）** 題幹很長——因為注文未截斷。這是刻意的：截斷會讓題目失去線索。讀不完可以直接跳過，不影響其他卡。
- **78 張單字答案**（如「精」「氣」）靠模糊評分，自測時答對同義詞也算對。
- 有校記的篇目，卡片背面會附底本校記。

### 這些卡片沒有經過實測

難度、區辨度、是否有用，**全部未知**。沒有任何真人做過這些題。

這不是客套：`docs/42` 把『無真人試讀』列為六項『AI 無能為力』之一。你現在做的，就是第一次實測。

### 不要當臨床依據

所有『某病取某穴』的內容都沒有療效驗證。卡片是讀古書的工具，不是診療手冊。

## 四、索引怎麼用

`索引.csv` 五欄：類別、名、篇序、篇名、位置。

```
類,名,篇序,篇名,位置
腧穴,少商,2,本輸,77
經脈,肺手太陰,10,經脉,0
藏府,肺,1,九鍼十二原,...
九鍼,員利鍼,1,九鍼十二原,566
篇,本輸,2,本輸,經文 1837 字／題 128
```

- 查某穴：篩「名」= 少商 → 看它在哪幾篇出現、位置。
- 查某篇的規模：篩「類」= 篇 → 看經文字數與題數。
- 位置欄是該篇正規化經文中的字元位移，可配合原文定位。
